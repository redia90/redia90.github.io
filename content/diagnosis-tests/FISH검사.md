# FISH 검사 — HER2 유전자 증폭 확인 (ISH)

## 개요
FISH(Fluorescence In Situ Hybridization, 형광 제자리 부합법)는 종양 세포의 **HER2 유전자 복제 수**를 형광 표지로 확인하는 검사다. 유방암에서 [[면역조직화학검사(IHC)|IHC]]가 **HER2 2+ 애매**로 나왔을 때 양성/음성을 확정하는 **보조 검사**로 쓰인다. [[HER2표적치료|허셉틴]] 등 표적치료 적응증 결정의 마지막 관문이며, FISH 결과가 모호하면 치료 선택지가 크게 달라진다.

## 검사 방법

### 원리
1. 종양 조직 슬라이드에 **HER2 유전자 표지 형광 프로브** (적색) 결합
2. **17번 염색체 동원체(CEP17) 표지 프로브** (녹색) 결합
3. 형광 현미경으로 세포핵 안의 신호 수 계수
4. **HER2/CEP17 비율** + 평균 HER2 신호 수로 판정

### ISH 종류
- **FISH**: 형광 — 표준
- **CISH** (Chromogenic ISH): 색소 — 일반 광학 현미경
- **SISH** (Silver ISH): 은 — 일반 광학 현미경
- 모두 동등한 정확도, 병원 장비에 따라 선택

## HER2 판정 흐름 (IHC + FISH 통합 다이어그램)

```
[[면역조직화학검사(IHC)|HER2 IHC]] 시행
  ↓
IHC 0   → HER2 음성 (FISH 불필요)
         단, HER2-ultralow 임상시험 검토 가능 → [[HER2-low치료]]
  ↓
IHC 1+  → HER2 음성 = [[HER2-low치료|HER2-low]]
         (FISH 불필요, [[HER2-low치료|엔허투]] 적응증 후보)
  ↓
IHC 2+  → FISH **필수** — 본 페이지의 판정 기준 적용
         ├─ FISH 증폭 (+) → HER2 양성 → [[HER2표적치료]]
         └─ FISH 비증폭 (−) → HER2-low → [[HER2-low치료]]
  ↓
IHC 3+  → HER2 양성 (FISH 보통 생략)
         → [[HER2표적치료]] 표준
```

> 💡 [[HER2-low치료|DESTINY-Breast04]] 이후 IHC 0/1+/2+/FISH- 환자도 ADC 적응증 후보 — **FISH는 IHC 2+에서만 결정적**이지만 IHC 정밀 재판독은 모든 환자에 중요해졌다.

## 판독 기준 (ASCO/CAP 2018·2023)

| 결과 | HER2/CEP17 비율 | 평균 HER2 신호 | 판정 |
|------|------------------|------------------|------|
| **Group 1** | ≥ 2.0 | ≥ 4.0 | **양성** |
| **Group 2** | ≥ 2.0 | < 4.0 | 추가 판독 (IHC 함께 검토) |
| **Group 3** | < 2.0 | ≥ 6.0 | 추가 판독 |
| **Group 4** | < 2.0 | 4.0 ≤ HER2 < 6.0 | 추가 판독 |
| **Group 5** | < 2.0 | < 4.0 | **음성** |

> 💡 Group 2~4는 **재판독·재검사·IHC 종합** 후 결정. 단순 컷오프로 끝나지 않음.

### Group 2~4 모호군 임상 결정 흐름

ASCO/CAP 2018 권고:

| 그룹 | 1차 검토 | 2차 검토 | 최종 판정 흐름 |
|------|----------|-----------|------------------|
| **Group 2** (비율 ≥2.0, HER2 <4.0) | IHC 재검토 | IHC 3+ → 양성 / IHC ≤2+ → 음성 | 추가 검사·세포 수 확장 권고 |
| **Group 3** (비율 <2.0, HER2 ≥6.0) | IHC 재검토 | IHC 3+ → 양성 / IHC ≤2+ → 음성 | 동일 |
| **Group 4** (비율 <2.0, HER2 4.0~6.0) | IHC 재검토 | 대부분 음성 | 추가 임상 변수 종합 |

**실무 권고**:
- 동일 슬라이드에서 추가 세포 20개 계수
- 새 슬라이드로 재검사 (검체 이질성 평가)
- IHC 점수와 종합 판단
- 임상 양상(서브타입·예후·환자 나이)과 맞지 않으면 **세컨드 오피니언** 검토

### 2026 임상 데이터에서 HER2 판독의 중요성

- **JNCI 2026 후향 (524명)**: T-DXd 치료 환자에서 순차 생검 사이 **HER2 IHC 불일치 약 20%** — 불일치군에서 치료 결과 나쁨 → [[2026임상연구업데이트]]
- **DESTINY-Breast05 (NEJM 2026)**: HER2+ 잔존병변 → T-DXd 3년 iDFS 92.4%. **HER2 확정 정확도가 치료 선택의 근간** → [[HER2표적치료]]
- **DESTINY-Breast09 (NEJM 2026)**: 전이성 1차에서 T-DXd+퍼투주맙 PFS 40.7개월 — HER2 정확 판정 환자만 적용 가능
- 시사점: **재발·전이 시 전이 병소 재검사**가 ADC 시대에 더 중요. IHC 0/1+/2+/3+ 모두 정밀 재판독 가치.

## 임상적 의의

### IHC 2+ → FISH 흐름
1. [[면역조직화학검사(IHC)|IHC]] 시행
2. IHC 2+ 결과 시 **FISH 자동 진행** (대부분 병원 표준)
3. FISH 양성 → **HER2 양성** → [[HER2표적치료|허셉틴 등 표적치료]] 적응증
4. FISH 음성 → **HER2 음성** → [[HER2-low치료|HER2-low]] 또는 HER2 음성 치료

### IHC 3+에서는?
- IHC 3+는 양성으로 확정 → FISH 보통 생략
- 단, 임상 양상과 맞지 않으면 FISH 추가 검토

### 재발·전이 시
- 원발 대비 HER2 상태 **20~30% 전환** 가능
- 전이 병소에서 IHC + FISH 재검사 권고

## 한국 임상 가이드라인 / 보험 적용 여부

### 급여 적용

- IHC 2+ 환자에서 FISH는 **표준 보조 검사** — 보험 적용 (한국 표준)
- IHC 0/1+/3+ 환자에서 임의 시행은 비급여 가능
- **산정특례** (5%) 등록 후 본인부담 크게 감소

### 검사 비용·일정 (참고)

| 항목 | 한국 실무 |
|------|------------|
| **FISH 시행 적응증** | IHC 2+ → 자동 진행 |
| **검사 소요 시간** | 검체 처리·판독 포함 약 **5~10 영업일** |
| **외부 의뢰 시** | 10~14일 (대형 병원 → 외부 위탁 시) |
| **비용 (급여, 산정특례 5%)** | 약 5~10만 원 본인부담 (병원·청구 항목별 차이) |
| **비용 (비급여)** | 약 30~50만 원 |
| **수술 후 보충 필요시 추가 시행** | 동일 적응증 + 보험 적용 |

### 한국 환자가 자주 겪는 동선

1. 조직검사 시 IHC 우선 시행 → 결과지 수령
2. IHC 2+ 확인되면 **같은 병원·같은 검체로 FISH 자동 진행**
3. **이미 다른 병원에서 IHC 시행** → 슬라이드·블록 대여로 본 병원 FISH 가능 (의뢰서 필요)
4. FISH 결과 통보까지 1~2주 — 환자가 외래에서 결과지 직접 확인

## IHC 2+ 케이스 — 환자 실전 동선 (HER2-low 시대)

DESTINY-Breast04 이후 **IHC 2+ FISH 음성 = HER2-low** 환자도 엔허투 옵션이 열려, IHC 2+ 케이스의 임상적 중요도가 크게 증가했다.

### IHC 2+ 환자가 확인할 4가지

| 항목 | 확인 방법 |
|------|------------|
| **1. IHC 점수가 정확히 2+인가?** | 결과지에서 IHC 점수(0/1+/2+/3+) 직접 확인 — 1+와 2+ 경계 케이스는 재판독 가치 |
| **2. FISH 결과는?** | 양성(증폭) → HER2+ 표적치료 / 음성(비증폭) → HER2-low → 엔허투 후보 |
| **3. FISH가 Group 2~4 모호군인가?** | 모호군은 추가 세포 계수·재슬라이드·세컨드 오피니언 검토 |
| **4. 재발·전이 시 재생검 했는가?** | 원발 vs 전이 병소에서 HER2 상태 20~30% 전환 가능 |

### IHC + FISH 결과 조합별 치료 동선

| IHC | FISH | 의미 | 치료 옵션 |
|-----|------|------|------------|
| 0 | 시행 안 함 | HER2 음성 (절대) | TNBC 또는 HR+ 치료, HER2-ultralow 임상시험 |
| 1+ | 시행 안 함 | HER2-low | 전이성: 엔허투(T-DXd) 적응증 / 조기: 표준 치료 |
| 2+ | 양성 (Group 1) | HER2 양성 | [[HER2표적치료\|허셉틴·퍼제타·캐싸일라·엔허투]] |
| 2+ | 음성 (Group 5) | HER2-low | 전이성: 엔허투 적응증 |
| 2+ | Group 2~4 모호 | **재판독·재검사 필요** | 세컨드 오피니언 검토 |
| 3+ | 보통 생략 | HER2 양성 | HER2 표적치료 표준 |

### 환자가 외래에서 물을 질문

1. 제 IHC 점수가 **정확히 0/1+/2+/3+ 중 무엇**인가요?
2. IHC 2+면 **FISH 자동 진행**되나요? 결과 통보 시점은?
3. FISH 결과가 **Group 2~4 모호군**이면 어떻게 처리하나요?
4. (전이·재발 시) **전이 병소 재생검**으로 HER2 다시 확인할 수 있나요?
5. **HER2-low가 확정**되면 엔허투 적응증·보험 적용에 해당하나요?
6. 다른 병원 슬라이드를 본 병원에서 **재판독·재검사** 가능한가요?
7. 검사비 본인부담은 얼마이고, 산정특례 적용되나요?

> 💡 IHC 2+ 환자는 **결과지 사진을 휴대폰에 보관**하고 진료실에서 직접 보면서 확인하는 것이 권장된다. 통보된 숫자뿐 아니라 **판독 의사·날짜·검체 부위**도 함께 기록.

## 한계점

- 종양 이질성으로 부위별 결과 다를 수 있음
- 형광 신호 감쇄 — 슬라이드 보관·판독 시점 주의
- **Group 2~4 모호군** 판정은 병리과 전문성이 결정
- 판독 의사 간 일치도 **70~80%** — 경계 케이스는 재판독 가치 ↑

## 미해결 질문 / 연구 방향
> 💡 NGS 기반 ERBB2 증폭 검사가 FISH를 대체할 가능성
>    → **답변 (2026-05)**: **FoundationOne CDx·MSK-IMPACT** 등 NGS가 ERBB2 copy number 정량 가능. 일부 연구에서 FISH와 일치도 90%+ 보고. 그러나 **FDA 표준은 FISH** 여전 — NGS는 보조 또는 다른 변이 동시 검출 시 가치. 표준 대체는 5~10년 추가 필요.
>
> 💡 AI 보조 FISH 판독 — Group 2~4 모호군 정확도
>    → **답변**: **Paige FISH·Roche uPath** 등 AI 자동 신호 계수 도구 도입 — 판독자 간 일치도 ↑ (0.85 → 0.92). Group 2~4 모호군에서 추가 세포 계수·표준화 도움. 한국 일부 대형 병원 도입 진행.

## 주의사항
> ⚠️ FISH 결과가 임상 양상(종양 크기·림프절·재발 속도)과 맞지 않으면 재판독·재검사·세컨드 오피니언을 검토한다.
> ⚠️ FISH 양성/음성이 절대 기준은 아니며, Group 2~4 모호군은 IHC와 종합해 판단한다.
