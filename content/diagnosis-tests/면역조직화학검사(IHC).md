# 면역조직화학검사 (IHC) — ER·PR·HER2·Ki67 결과 해석

## 개요
면역조직화학검사(Immunohistochemistry, IHC)는 [[조직검사결과해석|조직검사]]로 얻은 종양 조직에 항체를 입혀 특정 단백질의 발현 정도를 색으로 시각화하는 검사다. 유방암에서는 **ER, PR, HER2, Ki67** 네 가지가 핵심이며, 이 결과가 [[유방암분자서브타입|서브타입]] 결정과 [[호르몬치료|호르몬치료]]·[[HER2표적치료|HER2 표적치료]]·[[항암화학요법|항암 추가 여부]] 결정의 1차 근거가 된다. 같은 종양도 부위·실험실·판독자에 따라 결과가 달라질 수 있어, **재발·전이 시 재검사**가 중요한 영역이다.

## 검사 방법

### IHC 원리
1. 종양 조직 절편을 슬라이드에 부착
2. 표적 단백질(ER·PR·HER2·Ki67)에 결합하는 **1차 항체** 적용
3. 색소 결합 **2차 항체**로 시각화
4. 병리과 전문의가 현미경으로 **염색 강도·세포 비율** 판독

### 검체 종류
- **수술 검체**: 가장 정확. 종양 전체에서 다양한 부위 평가 가능
- **총조직검사(CNB)**: 진단 시 표준. 일부 종양 이질성 놓칠 수 있음 ([[조직검사결과해석]])
- **전이 병소 조직검사**: 재발·전이 시 원발 대비 변화 확인 (서브타입 전환 약 20~30%)

## 핵심 내용 — 항목별 해석

### ER (Estrogen Receptor) / PR (Progesterone Receptor)

| 결과 | 의미 |
|------|------|
| **ER(+) ≥ 1%** | 호르몬 양성 — [[호르몬치료]] 적응증 |
| ER(+) 약양성 (1~10%) | 치료 반응 제한적, 더 공격적 가능성 |
| ER(+) 강양성 (≥70%) | 호르몬 치료 반응 우수, 예후 양호 |
| **ER(-) < 1%** | 호르몬 음성 |
| PR(+) | 호르몬 치료 효과 보조 지표, 25년 추적 효과는 PR 양성에서만 (스톡홀름 연구) |

**보고 형식**: 발현 비율(%) + 염색 강도

> 💡 ER 또는 PR 중 하나라도 양성이면 **호르몬 수용체 양성**으로 분류된다.

#### Allred Score (TS + IS, 0~8)

ER·PR 결과를 정량화하는 가장 흔한 점수 (한국 병리과 표준):

**Total Score = Proportion Score + Intensity Score**

| Proportion Score (TS) | 양성 세포 비율 |
|------------------------|----------------|
| 0 | 0% |
| 1 | <1% |
| 2 | 1~10% |
| 3 | 11~33% |
| 4 | 34~66% |
| 5 | ≥67% |

| Intensity Score (IS) | 염색 강도 |
|----------------------|-----------|
| 0 | 없음 |
| 1 | 약함 (weak) |
| 2 | 중간 (intermediate) |
| 3 | 강함 (strong) |

**판정**:
- **합 0~2점**: 음성
- **합 3~8점**: 양성 (3점이 cutoff)
- ASCO/CAP 2020: ER 1~10% 약양성은 "**ER Low Positive**"로 별도 보고 권고 — 호르몬치료 효과 제한적, 환자에게 정확히 안내 필요

#### H-Score (0~300, 일부 병원)

대안적 정량 시스템:
- H-score = (1 × 약양성 %) + (2 × 중간양성 %) + (3 × 강양성 %)
- 0~300 범위
- 일부 임상시험·연구에서 사용

> 💡 **결과지에 점수가 없고 % 만 적혀 있다면** 환자가 진료 시 "Allred score는 몇 점인가요?" 또는 "강도(IS)는 약/중/강 중 어느 정도였나요?"를 물어볼 수 있다.

### HER2 (Human Epidermal Growth Factor Receptor 2)

**IHC 점수 체계 (0 / 1+ / 2+ / 3+)**:

| 점수 | 의미 | 후속 검사 |
|------|------|-----------|
| **0** | HER2 음성 | 없음 — 단, 최근 HER2-ultralow 개념 등장 |
| **1+** | HER2 음성 | 없음 — HER2-low로 분류, [[HER2-low치료\|엔허투]] 적응증 |
| **2+** | 애매한 중간값 | **[[FISH검사]] 필수** — 유전자 증폭 여부 확인 |
| **3+** | HER2 양성 | [[HER2표적치료\|허셉틴·퍼투주맙·엔허투]] 적응증 |

> ⚠️ **IHC 2+ 단독으로는 양성/음성 판정 불가**. 반드시 [[FISH검사]] 또는 다른 ISH로 확인.

#### HER2-low 등장 (2022~ DESTINY-Breast04 이후)

- 과거 "HER2 음성"이었던 **IHC 1+ 또는 2+/FISH-** 환자가 [[HER2-low치료|HER2-low]]로 재분류
- 전체 유방암의 **약 60%** 해당 추정
- 엔허투(T-DXd) 적응증 확대 — 전이성에서 화학요법 대비 PFS 개선

#### HER2-ultralow (2024~)
- IHC 0이지만 극미량 발현 (어떤 염색이라도 보이는 경우)
- 일부 임상에서 반응률 30~40% 보고
- 표준 치료 미확립 단계

### Ki67 (증식 지수)

| 결과 | 해석 (전통 컷오프) |
|------|---------------------|
| **<14%** (전통적) | 루미날 A — 호르몬치료 중심 |
| **20% 이상** | 루미날 B — 항암 추가 고려 |
| **30% 이상** | 분열·성장 활성 높음 |

#### Ki67 컷오프 변화 (IKWG·St Gallen)

| 출처 | 컷오프 권고 |
|------|--------------|
| **St Gallen 2013** | <14% 저위험, ≥20% 고위험 |
| **St Gallen 2021** | <5%·5~30%·>30% 3분류 — 회색지대 명시 |
| **IKWG (Nielsen JNCI 2021)** | **≤5% 명확히 낮음, ≥30% 명확히 높음, 그 사이는 회색지대 → 보조 검사 필요** |
| **monarchE (버제니오 조기 보조)** | Ki67 ≥20% + 림프절 양성 등 고위험 정의에 사용 |

**한계**:
- 같은 종양 안에서도 부위별 염색 결과 다름
- **판독자 간 일치도 일관성 낮음** — IKWG 권고 핵심 이유
- 실험자 숙련도에 따른 오차
- 검체 보관·고정 시간에 따라 변동
- **Ki67 단독으로 항암 여부 결정 금지** — [[온코타입DX_RS점수|RS 점수]] 등 종합 평가 필요

#### Ki67 판독 표준화 권고 (IKWG)

- 전체 종양에서 **500~1000개 종양 세포 계수**
- **hot spot** 또는 invasive edge에서 평가
- 핵 염색만 양성으로 계수
- 자동 디지털 판독(AI 보조) 도입 권장

> 💡 Ki67 50~60%여도 RS 13점이면 항암 패스 가능한 사례 보고됨 (카페 전문지식 #460229). — Ki67은 종합 판단 지표 중 하나일 뿐.

### E-cadherin (보조)
- E-cadherin(-) → **침윤성 소엽암(ILC)** 의심
- 침윤성 관암(IDC)과 형태·치료 반응 차이

## 판독 정밀도와 한계

### 판독자 간 일치도
- 병리의사 간 일치도 약 **70~80%**
- 20~30%는 다른 병리의사가 다르게 판독
- 특히 **HER2-low 경계 (0 vs 1+, 2+ vs 3+)** 판독 차이가 치료 기회를 결정

#### 항목별 판독 일치도 (Kappa)

| 항목 | 일치도 | 가장 큰 변동 구간 |
|------|--------|-------------------|
| **ER** | 0.85~0.90 | 약양성 (1~10%) 경계 |
| **PR** | 0.75~0.85 | 약양성 경계 |
| **HER2 (IHC)** | 0.50~0.70 | **0 vs 1+ / 2+ vs 3+ 경계 (HER2-low 시대 가장 중요)** |
| **HER2 (FISH)** | 0.85~0.95 | Group 2~4 모호군 |
| **Ki67** | 0.40~0.70 | **회색지대 (5~30%) 가장 낮음** |

> ⚠️ HER2-low 시대에 **0 vs 1+ 판독 일치도가 결정적** — 0이면 엔허투 적응증 ❌ (현재), 1+이면 ✅. 다른 병리의사가 1+로 판독하면 치료 기회가 달라진다.

### 검체 한계
- 종양 이질성 — 같은 종양 안에서도 부위별 다름
- CNB(총조직검사)는 종양 일부만 채취
- 검체 고정 시간 (6시간 미만 또는 72시간 초과 시 항원성 변화)
- 슬라이드 보관 기간 (1년 이상 시 ER·PR 위양성 감소)
- 검사실 간 항체 클론·자동화 시스템 차이

### 재발·전이 시 재검사
- 원발 대비 서브타입 **20~30% 전환** 가능
- 전이 병소 조직검사로 **현재 HER2·ER·PR 상태** 확인 권장
- [[2026임상연구업데이트|JNCI 2026]]: T-DXd 환자 524명에서 순차 생검 IHC 불일치 약 20%, 불일치군 치료 결과 더 나쁨

> 💡 재발·전이 시 **세컨드 오피니언**으로 슬라이드 재판독을 받는 것이 카페에서 자주 권장된다.

## 재판독·재검사 동선 (환자 실전)

### 재판독·재검사가 의미 있는 상황

| 상황 | 권장 동선 |
|------|------------|
| **결과가 임상 양상과 맞지 않음** (예: 빠른 진행인데 루미날 A) | 재판독 우선 |
| **HER2 0 또는 1+ 경계** + HER2-low ADC 적응증 고려 | 슬라이드 재판독 (대형 병원 병리과) |
| **HER2 2+ FISH 모호 (Group 2~4)** | FISH 추가 세포 계수 + 재슬라이드 |
| **재발·전이 진단** | 전이 병소 재생검 + IHC 4종 재검사 |
| **타 병원 진단 후 본 병원 치료 시작** | 슬라이드·블록 대여 → 본 병원 판독 |
| **치료 결정 전 확신이 필요할 때** | 세컨드 오피니언 (대형 암 센터) |

### 재판독·재검사 절차 (한국)

1. **슬라이드·블록 대여** — 원래 검사 받은 병원 병리과에 요청
2. **의뢰서 작성** — 본 병원 외과·종양내과 발급
3. **2~4주 소요** (병원 간 운송·재판독 시간)
4. **비용**: 일부 비급여 (10~30만 원 수준)
5. **결과**: 새 IHC 점수 + 의견서

### 재검사가 치료를 바꾼 카페 사례 패턴

- HER2 1+ → 재판독에서 2+/FISH+ 확인 → HER2 표적치료 적응증 변경
- ER- (원발) → 전이 병소 재검사 ER+ 확인 → 호르몬치료 추가
- HER2 0 → 재판독 1+ → 엔허투 (T-DXd) 후보 ([[HER2-low치료]])

→ [[전이경고신호]]·[[FISH검사]] 재판독 동선 참조

## 환자가 결과지에서 직접 확인할 항목

진료 후 결과지를 받으면 다음을 직접 확인·메모:

| 항목 | 결과지 위치 | 확인 포인트 |
|------|------------|--------------|
| **ER %·강도** | "Estrogen Receptor" | 비율(%) + 강도 (weak/intermediate/strong), Allred score 있는지 |
| **PR %·강도** | "Progesterone Receptor" | 동일 |
| **HER2 IHC 점수** | "HER2" | 0/1+/2+/3+ 명시 |
| **HER2 FISH 비율** | "HER2 ISH" | HER2/CEP17 비율 + 평균 HER2 신호 수 |
| **Ki-67** | "Ki-67" 또는 "MIB-1" | % 표기 |
| **판독 의사** | 결과지 하단 | 이름·날짜 |
| **검체 부위** | 상단 | 생검 vs 수술 검체 |

> 💡 **결과지 사진을 휴대폰에 보관**하고 진료실에서 직접 보면서 확인 — 같은 종양이라도 일자·검체별 결과가 다를 수 있어 환자가 기록을 가지고 있어야 한다.

## 디지털 병리 AI — HER2-low/ultralow 판정 정확도

DESTINY-Breast04(HER2-low 2차)·DESTINY-Breast06(HER2-low/ultralow 1차) 이후 **HER2 IHC 0 vs 1+ 경계**가 치료 결정 분기점이 되었다.

### 왜 AI 보조 판독이 중요해졌나

| 상황 | 기존 문제 | AI 보조 효과 |
|------|-----------|-------------|
| HER2 IHC 0/1+ 경계 | 병리의사 간 판독 일치도 **Kappa 0.65** — 낮음 | Kappa **0.85** 이상 (Paige HER2 Complete) |
| HER2 IHC 2+/FISH | 일치도 0.75~0.80 | 0.88~0.92 (Paige·Roche uPath) |
| Ki-67 정량 | 수동 계수 편차 큼 | 자동 정량 ↑ |
| PD-L1 CPS | CPS ≥1 경계 일치도 낮음 | Lunit SCOPE PD-L1 보조 향상 |

### 한국 대형 병원 도입 현황 (2026 Q2)

| 도구 | 적용 병원 | 주요 기능 |
|------|-----------|-----------|
| **Lunit SCOPE HER2** | 서울대·삼성·아산 시범 운영 | HER2 IHC 0/1+/2+/3+ 자동 분류 |
| **Lunit SCOPE PD-L1** | 삼성서울·서울대·아산 확대 | TNBC 면역치료 CPS 정량 |
| **Paige HER2 Complete** | 일부 도입 | HER2-low 경계 보조 |
| **Visiopharm HER2** | 연구 단계 | HER2-low 정량 분석 |

### 환자 입장 — 진료실에서 물을 수 있는 질문

1. "제 HER2 IHC 결과가 0 또는 1+인데, **AI 보조 재판독**을 받을 수 있나요?" (엔허투 적응증 여부 결정)
2. "병리 검사에 **디지털 병리 AI**가 적용되었나요?" (HER2-low/PD-L1 정확도)
3. "**DESTINY-Breast06 기준** HER2-low/ultralow 적응 여부를 제 결과로 판단할 수 있나요?"
4. "**PD-L1 CPS** 측정에 AI 보조가 가능한가요?" (TNBC 면역치료 결정)

> 💡 **DESTINY-Breast06 (ASCO 2026) 맥락**: HER2-low(IHC 1+/2+·FISH-)·HER2-ultralow(0이지만 미량 발현) 전이성 1차 T-DXd가 OS 우위 확인 추정 → HER2 0/1+ 경계 판독 정확도가 **1차 치료 결정**에 직결. AI 보조 병리는 이 분기점을 정확하게 만드는 핵심 도구.

## 임상적 의의

- IHC는 비싸지 않고 빠르며 거의 모든 병원에서 가능 — 진단 1차 도구로 표준화됨
- ER·PR·HER2 4-항목 조합으로 **루미날 A/B, HER2+, TNBC, HER2-low** 5개 서브타입 결정
- HER2-low 개념 등장으로 ADC([[HER2-low치료|엔허투]]) 적응증이 60%까지 확대 — IHC 1+/2+ 환자에게도 새 옵션
- 재발·전이 시 재검사·재판독이 치료 선택을 바꿀 수 있어 환자가 적극 요청 가능
- **디지털 병리 AI**: HER2 IHC 0/1+ 경계 판독 일치도를 0.65→0.85로 향상 — DESTINY-Breast06 1차 적응증 정확도 직결

## 한국 임상 가이드라인 / 보험 적용 여부

- 모든 유방암 환자에서 ER·PR·HER2 IHC는 **기본 검사**, 산정특례 적용
- Ki67 IHC도 일반 시행, 보험 적용
- 재검사·재판독은 의료진 판단에 따라 가능
- 외부 슬라이드 판독 의뢰는 일부 비급여 가능

## 주의사항
> ⚠️ IHC 결과는 같은 종양이라도 부위·실험실·판독자에 따라 달라질 수 있다. 재발·전이 시 또는 결과가 임상 양상과 맞지 않으면 재판독·재검사를 의료진과 상의한다.
