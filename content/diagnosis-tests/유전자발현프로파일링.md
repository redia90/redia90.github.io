# 유전자발현 프로파일링 — 5종 검사 통합

## 개요
유전자발현 프로파일링(Gene Expression Profiling)은 종양 조직에서 **특정 유전자의 발현 수준**을 측정해 재발 위험·치료 반응을 예측하는 검사다. 유방암에서 5종 검사(**Oncotype DX·MammaPrint·Prosigna·EndoPredict·Breast Cancer Index**)가 임상에 사용되며, 주로 **ER+/HER2- 조기 유방암에서 항암 추가 여부**를 결정한다.

> ⚠️ **"유전자 검사" 혼동 주의 — 변이 vs 발현**
>
> | 검사 종류 | 본질 | 측정 | 예 |
> |-----------|------|------|------|
> | **이 페이지 ([[유전자발현프로파일링]])** | **발현 (Expression)** | 유전자가 얼마나 활성화되어 있는가? | Oncotype·MammaPrint·Prosigna·EndoPredict·BCI |
> | [[유전자검사]] | **변이 (Mutation)** | DNA 염기 서열에 영구 변화가 있는가? | BRCA·PALB2·PIK3CA·ESR1·HER2 증폭 |
>
> 본 페이지는 **종양 한 시점의 유전자 활동성**을 측정해 항암 추가 결정을 돕는 검사들이다. 평생 위험·가족 영향·표적 약제 적응증이 필요하면 [[유전자검사]]를 본다.

## 핵심 내용

### 5종 검사 한눈에 비교

| 검사 | 유전자 수 | 점수 형식 | 주요 검증 임상 | 한국 도입 |
|------|-----------|-----------|----------------|------------|
| **Oncotype DX** | 21 | RS 점수 0~100 | TAILORx, RxPONDER | 일부 보험 적용 |
| **MammaPrint** | 70 | High/Low 이분법 | MINDACT | 일부 적용 |
| **Prosigna (PAM50)** | 50 | ROR 점수 + 내인성 서브타입 | NCIC MA.5/MA.12 | 일부 병원 |
| **EndoPredict** | 8+4 (12) | EPclin 점수 | ABCSG-6/8 | 매우 제한적 |
| **Breast Cancer Index (BCI)** | 7 | HOXB13/IL17BR + MGI | aTTom, MA.17 | 거의 없음 |

### 1. Oncotype DX (21유전자)

→ 상세는 [[온코타입DX_RS점수]]

- 회사: Exact Sciences (미국)
- **재발 점수(RS) 0~100**
- 적응증: ER+/HER2-, 림프절 음성 또는 1-3개 양성
- **TAILORx 컷오프**: 50세 이상 RS ≤25 → 항암 패스, ≥26 → 항암 / 50세 미만은 16~20 회색지대
- **RxPONDER**: 림프절 양성 1-3개에서 폐경 후 항암 이득 없음, 폐경 전 있음
- 한국 보험: 조건 충족 시 일부 적용, 약 300~400만원

### 2. MammaPrint (70유전자) + BluePrint

- 회사: Agendia (네덜란드)
- **고위험/저위험 이분법** — 가장 단순
- **MINDACT (2016 NEJM)** 검증:
  - 임상 고위험 + 유전자 저위험 환자에서 항암 패스 시 **5년 무재발 생존율 ~94.7%**
  - → 임상적으로 고위험으로 보였지만 MammaPrint 저위험이면 안전하게 항암 회피 가능
- 적응증: ER+/HER2-, 림프절 음성 또는 일부 양성
- **BluePrint** (보조 도구): 분자 서브타입(루미날·HER2·Basal-like) 분류 — MammaPrint와 함께 보고
- 한국: 림프절 양성 1-3개 일부 보험 적용 (약 500만원)

### 3. Prosigna (PAM50, 50유전자)

- 회사: Veracyte (구 NanoString)
- **ROR (Risk of Recurrence) 점수 0~100**
- **내인성 서브타입 자동 분류**: 루미날 A / 루미날 B / HER2-enriched / Basal-like
- → 분자 수준 서브타입의 임상적 의미는 [[유방암분자서브타입|분자 서브타입 페이지의 PAM50 섹션]]
- 적응증: ER+/HER2-, 폐경 후
- 특징: **수술 검체에서 직접 시행 가능** — 일부 국가에서는 해외 의뢰 불필요
- 한국: 일부 병원 도입

### 4. EndoPredict (8+4 = 12유전자)

- 회사: Myriad Genetics
- **EPclin 점수**: 분자 점수 + 종양 크기 + 림프절 상태 결합
- **10년 원격재발 위험** 예측 — 후기 재발 예측에 강점
- 적응증: ER+/HER2-, 폐경 전후 모두
- ABCSG-6/8 검증 임상
- 한국 도입: 매우 제한적

### 5. Breast Cancer Index (BCI)

- 회사: Biotheranostics
- **HOXB13/IL17BR 비율** + **MGI (Molecular Grade Index)** 결합
- **5년 호르몬 치료 후 추가 5년 연장(extended endocrine therapy)** 이득 예측 — 다른 검사와 다른 목적
- 적응증: ER+/HER2- 환자, 5년 치료 완주 후 10년 연장 결정 시점
- aTTom·MA.17 임상 기반
- 한국 도입: 거의 없음 — 대안: 임상 위험도 + 환자 선호

## 임상 적용 의사결정 흐름

### 신보조 vs 보조 — 검사 시점

| 시점 | 검사 활용 |
|------|-----------|
| **수술 전 ([[신보조화학요법|신보조]])** | HER2+·TNBC는 임상 변수로 신보조 결정 — 유전자 검사 보통 안 함 |
| **수술 후 (보조)** | ER+/HER2- 중간 위험군에서 5종 검사로 항암 추가 결정 |
| **선항암 후 잔존병변** | 잔존병변 자체 평가가 우선 — 신보조 반응이 강력한 예후 지표 |

> 💡 ER+/HER2-에서 **수술 → 유전자 검사 → 보조 결정**이 표준 흐름. HER2+·TNBC는 임상 변수만으로 신보조 결정.

### 조기 ER+/HER2- 림프절 음성
1. 임상 위험도 평가 (종양 크기·Grade·Ki67·나이)
2. 중간 위험군 → Oncotype DX 또는 MammaPrint 검토
3. RS·MammaPrint 결과로 [[항암화학요법|항암 추가 여부]] 결정

### 조기 ER+/HER2- 림프절 양성 1-3개
1. Oncotype DX (RxPONDER) 또는 MammaPrint (MINDACT) 가능
2. **폐경 후**: RS ≤25 → 항암 이득 없음
3. **폐경 전**: 같은 점수여도 항암 이득 있음 (RxPONDER)

### 5년 호르몬 치료 완주 후
1. BCI 검토 — 추가 5년 연장 이득 예측 (한국 매우 제한적)
2. 대안: 임상 위험도(고위험 → 10년 연장) + 환자 선호 + [[호르몬치료|AI 부작용]] 평가

## 주요 검증 임상시험

### TAILORx (NEJM 2018) — Oncotype DX
- 9,719명, ER+/HER2-/림프절 음성
- 결론: **RS ≤25 + 50세 이상 → 항암 패스 안전**
- 회색지대: RS 16~20 + 50세 미만 — 항암 또는 OFS+호르몬 선택

### RxPONDER (NEJM 2021) — Oncotype DX
- 5,083명, ER+/HER2-/림프절 양성 1-3개, RS ≤25
- 결론:
  - **폐경 후 → 항암 이득 없음**
  - **폐경 전 → 항암 이득 있음** (iDFS·OS 향상)

### MINDACT (NEJM 2016) — MammaPrint
- 6,693명
- 결론: 임상 고위험 + MammaPrint 저위험 → **항암 패스 시 5년 무재발 ~94.7%**

## 차이점 — 어떤 검사가 가장 좋은가?

명확한 우열은 없으며 임상 가이드라인 권고가 다름:

| 영역 | 권고 검사 |
|------|-----------|
| 림프절 음성 ER+/HER2- 항암 결정 | **Oncotype DX** (가장 강한 권고, NCCN/ASCO) |
| 림프절 양성 1-3개 | Oncotype DX (RxPONDER), MammaPrint (MINDACT) |
| 폐경 후 + 내인성 서브타입 필요 | **Prosigna** |
| 후기 재발 (5~10년) 위험 | EndoPredict |
| 호르몬 치료 5년 후 연장 결정 | **BCI** |

## BCI·Prosigna·EndoPredict — 2026 후기 재발 결정 도구 (2026-06 갱신)

[[research/온코타입DX_RS점수|TAILORx 12년 추적]] (Sparano NEJM 2024) — RS는 5년 이내 재발 예측력 우수하나 **5~10년 후기 재발 예측력 약함**. 후기 재발 결정에는 **BCI·EndoPredict·Prosigna ROR**이 우수.

### BCI (Breast Cancer Index) — 호르몬 5→10년 연장 결정

| 항목 | 내용 |
|------|------|
| **검사 시점** | 호르몬치료 **5년 완료 후** (연장 여부 결정) |
| **유전자 수** | 11개 + H/I ratio (HOXB13/IL17BR) |
| **출력** | ① 후기 재발 위험 (Risk of Late Distant Recurrence), ② **연장 호르몬치료 이득 예측** (BCI-H/I) |
| **임상 근거** | aTTom·MA.17·TransATAC 사후 분석 — **H/I 높음 환자에서 연장 이득 명확** |
| **NCCN 권고** | Category 2A (호르몬 연장 결정) |
| **한국 보험** | 비급여 (약 100~150만원) — 일부 대형 병원 도입 |
| **2026 갱신** | EndoMET·SWOG S1207 후속 데이터 누적 — 표준 도입 가속 |

### Prosigna (PAM50 ROR) — 내인성 분자 분류 + 위험도

| 항목 | 내용 |
|------|------|
| **검사 시점** | 수술 직후 (Oncotype DX 대안) |
| **유전자 수** | 50개 (PAM50) |
| **출력** | ① 내인성 서브타입 (Luminal A/B·HER2-enriched·Basal-like), ② ROR 점수 (0~100), ③ 후기 재발 위험 |
| **임상 근거** | ATAC·ABCSG-8 검증 — **5년·10년 모두 예측력 우수** |
| **NCCN 권고** | Category 1 (림프절 음성·1-3개 양성) |
| **한국 도입** | 일부 대형 병원 (삼성·서울대·아산) 비급여 운영 — **약 100~150만 원** |
| **2026 갱신** | KBCS 권고안 진행 — 한국 보험 적용 평가 진행 중, 2027 예상 |

### EndoPredict (EPclin) — 후기 재발 + 항암 결정

| 항목 | 내용 |
|------|------|
| **검사 시점** | 수술 직후 |
| **유전자 수** | 8개 + 임상 변수 (종양 크기·림프절) = EPclin |
| **출력** | ① EP score (분자), ② EPclin score (임상 통합), ③ 후기 재발 위험 |
| **임상 근거** | ABCSG-6·8 검증 — **5~10년 예측력 우수** |
| **NCCN 권고** | Category 2A |
| **한국 도입** | 매우 제한적 — 일부 대형 병원 |
| **2026 갱신** | EPclin이 후기 재발 결정에 우수 — RS 16~20 회색지대 보완 가능성 |

### 후기 재발 결정 — 5년 시점 검사 선택 흐름

```
[호르몬치료 5년 완료 시점 도달]
    ↓
[5년 추적 검사 음성 + 잔존 호르몬 양성]
    ↓
[연장 여부 결정 — 환자 가치관 + 검사 보조]
    ↓
├── BCI H/I 양성 → 연장 권고 (5~10년)
├── BCI H/I 음성 → 5년 완료
├── EPclin 고위험 → 연장 검토
└── 환자 부작용·삶의 질 평가 통합
    ↓
[연장 결정 시 — 약제: AI (폐경 후), 타목시펜 → AI 전환, OFS+AI (폐경 전)]
[비연장 결정 시 — 추적 정기 일정 ↑, BCI 갱신 가능성]
```

### 한국 환자 진료실 활용 (2026-06)

ASCO 2026·SABCS 2025 후속 호르몬 연장 결정 진료실 질문:

1. 제 호르몬치료 5년 시점에 **BCI 검사** 받을 수 있나요? 비용은?
2. BCI 결과 H/I 양성이면 **연장 5년 vs 10년** 권고는?
3. **EPclin** 또는 **Prosigna ROR**도 후기 재발 결정에 활용 가능한가요?
4. RS 16~20 회색지대 환자라면 BCI·EPclin 추가 검토?
5. 한국 보험 적용 진행 상태는? (현재 모두 비급여)

## 한계점

- **종양 이질성** — 작은 검체 부위만 측정
- 결과 해석은 단독 결정 아닌 **임상 변수 종합** 필요 (Grade·종양 크기·림프절·나이)
- 검사 비용 부담 — 한국 비급여 시 300~500만원
- HER2 양성·TNBC에는 권고되지 않음 (ER+/HER2-에 한정)
- 신뢰도: Oncotype DX·MammaPrint가 가장 강한 권고, 나머지는 보조

## 한국 임상 가이드라인 / 보험 적용 여부

- **Oncotype DX**: 일부 조건(림프절 음성·중간 위험)에서 보험 적용 — 본인부담 일부
- **MammaPrint**: 림프절 양성 1-3개에서 일부 적용
- **Prosigna**: 일부 대형 병원 도입, 보험 적용 제한적
- **EndoPredict·BCI**: 한국 적용 거의 없음 — 임상시험·연구 외 비급여
- 검사 결과 받기까지: 약 2주 (Oncotype DX는 미국으로 검체 송부)

## 임상적 의의

- 5종 검사는 **"항암 추가 여부" 의사결정의 객관 도구** — 임상 변수만으로 결정하기 어려운 중간 위험군에 핵심
- Oncotype DX·MammaPrint는 **불필요한 항암 회피** 근거 — ER+/HER2- 환자의 약 50% 이상이 호르몬 치료만으로 충분
- BCI는 다른 검사들과 목적이 다름 — **5년 호르몬 치료 완주 환자의 연장 결정**
- Prosigna의 내인성 서브타입 분류는 [[유방암분자서브타입]]을 분자 수준에서 재확인

## 미해결 질문 / 연구 방향
> 💡 5종 검사 직접 비교 임상 — 어느 검사가 가장 정확한가
>    → **답변 (2026-05)**: **OPTIMA trial (UK 진행 중)** — Oncotype·MammaPrint·Prosigna 직접 비교, 결과 대기. 메타분석 (Bartlett JNCI 2016): 5종 검사 분류가 환자 약 30%에서 다름 — 일관성 ↓. 환자별 임상 변수·접근성·비용으로 선택.
>
> 💡 BCI의 한국 도입·5년 후 연장 결정
>    → **답변**: BCI 한국 도입 매우 제한적 — 일부 병원 자비. **aTTom·MA.17 데이터 기반** 5년 호르몬 치료 후 10년 연장 결정 도구. 한국 표준은 임상 위험 (T·N·Grade) 평가 — BCI 도입 보험 적용 진행 중.
>
> 💡 ctDNA 기반 차세대 유전자발현 검사
>    → **답변**: ctDNA에서 유전자 발현 직접 측정은 기술적 한계 (RNA 양 적음). **메틸화 패턴 (Methylation) + ctDNA** 차세대 모니터링 (Galleri·Grail) 도입 진행. 표준 진입 5년+ 예상.

## 주의사항
> ⚠️ 이 검사들은 **ER+/HER2- 환자에만 의미**가 있다. HER2 양성·TNBC에는 권고되지 않는다.
> ⚠️ 검사 결과는 **임상 변수 종합 판단**의 도구 — 단독으로 치료 결정 금지.
> ⚠️ 한국에서 비급여 시 수백만원 부담 — 보험 적용 조건은 변동되므로 진료실에서 최신 기준 확인.
