# 유전자검사 — BRCA·NGS·유전상담

## 개요
유방암 유전자 검사는 (1) **생식세포 변이(germline)** 검사 — BRCA1/2 등 유전성 위험 평가, (2) **종양 변이(somatic)** 검사 — 약제 선택용 NGS, (3) **ctDNA(혈액)** 검사 — ESR1 변이 등 동반진단 세 영역으로 나뉜다. 각 검사는 시점·목적·보험 적용·결과 해석이 달라 환자가 진료실에서 어떤 검사를 받는지 명확히 알아야 한다. 결과 활용은 [[BRCA유전자]]·[[온코타입DX_RS점수]]·[[2026임상연구업데이트]] 참조.

> ⚠️ **"유전자 검사"의 두 가지 본질 — 혼동 주의**
>
> | 검사 종류 | 본질 | 측정 | 예 |
> |-----------|------|------|------|
> | **이 페이지 ([[유전자검사]])** | **변이 (Mutation)** | DNA 염기 서열에 영구 변화가 있는가? | BRCA1/2·PALB2·PIK3CA·ESR1·HER2 증폭 |
> | [[유전자발현프로파일링]] | **발현 (Expression)** | 유전자가 얼마나 활성화되어 있는가? | Oncotype DX·MammaPrint·Prosigna·EndoPredict·BCI |
>
> **변이 검사**는 본인·가족의 평생 위험과 표적 약제 적응증을 결정.
> **발현 검사**는 종양 한 시점의 활동성을 보고 항암 추가 여부를 결정.
> 같은 "유전자 검사"라는 단어를 쓰지만 **목적·결과·해석·후속 결정이 완전히 다르다**.

## 검사 종류

### 1. 생식세포 변이 (Germline) — 가족력·유전 위험

| 검사 | 대상 | 용도 |
|------|------|------|
| **BRCA1/2 단독** | 가족력·발병 나이·트리플네거티브 등 | [[BRCA유전자]] 변이 확인, 예방적 절제·[[PARP억제제]] 적응증 |
| **다유전자 패널 (멀티진)** | BRCA + PALB2·CHEK2·ATM·TP53·CDH1 등 17~80개 | 고위험 유전자 종합 평가 |
| **전체 엑솜·유전체** | 임상시험·연구 | 일반 임상 보편 적용 아님 |

#### 검사 시점
- 가족 중 유방암·난소암 환자 다수
- 발병 나이 **<45세**
- 양측 유방암 또는 다른 부위 추가 암
- **트리플네거티브** + 60세 미만
- 남성 유방암
- 가족 중 BRCA 변이 확인자

#### 검사 결과 해석
- **양성(병원성 변이)**: 본인 위험·가족 위험 평가, 예방적 절제·[[PARP억제제]] 고려
- **음성**: 검사한 유전자에 변이 없음 — 다른 유전성 위험은 배제 못 함
- **VUS (Variant of Uncertain Significance)**: 의미 불명 변이 — 추적 권장, 임상 결정에 직접 사용 금지

### 2. 종양 변이 (Somatic NGS) — 약제 선택

종양 조직에서 직접 추출, 약제 적응증 결정에 활용:

| 변이 | 적응증 약제 |
|------|--------------|
| **HER2 증폭** | [[HER2표적치료\|허셉틴·퍼투주맙·엔허투]] (보통 [[FISH검사]]로 확인) |
| **BRCA 종양 변이** | [[PARP억제제]] (germline BRCA가 표준이지만 일부 적응증 확대) |
| **PIK3CA 변이** | 알페리시브 (Piqray) + 풀베스트란트 — ER+/HER2- 전이성 |
| **AKT1·PTEN 변이** | 카피바세르팁 (Truqap) — ER+/HER2- 전이성 |
| **NTRK 융합** | 라로트렉티닙·엔트렉티닙 (드묾) |
| **MSI-H/dMMR** | [[TNBC치료\|키트루다]] (드묾) |
| **TMB-H** | 키트루다 |
| **HRD-positive** | [[PARP억제제]] (난소암 적응증 확장 가능성) |
| **ERBB2 (HER2) 활성 변이** | 일부 임상시험 (HER2 비증폭) |

→ 종양 NGS는 보통 **전이성·재발 시점** 또는 임상시험 등록 시 시행

#### 변이별 적응증 약제 상세 + 임상 근거

| 변이 | 약제 | 임상 | 핵심 데이터 |
|------|------|------|------------|
| **gBRCA1/2** | 올라파립 (린파자) | OlympiAD·OlympiA | 전이성: PFS 7.0 vs 4.2개월 / 조기 보조: iDFS HR 0.58 |
| **gBRCA1/2** | 탈라조파립 (탈젠나) | EMBRACA | PFS 8.6 vs 5.6개월 |
| **PIK3CA** | 알페리시브 + 풀베스트란트 | SOLAR-1 | PFS 11.0 vs 5.7개월 |
| **AKT1·PTEN·PIK3CA** | 카피바세르팁 + 풀베스트란트 | CAPItello-291 | PFS 7.3 vs 3.1개월 (변이군) |
| **ESR1** | vepdegestrant (PROTAC) | VERITAC-2 | PFS 5.0 vs 2.1개월 |
| **ESR1** | 엘라세스트란트 (Oral SERD) | EMERALD | PFS 3.8 vs 1.9개월 |
| **HER2 amplification** | 엔허투 (T-DXd) | DESTINY-Breast03 | 진행 위험 72%↓ |

> 💡 NGS 패널을 한 번 시행하면 위 변이들을 동시에 검출 — 전이성 환자에서 가장 효율적.

### 3. ctDNA (혈액 액체생검) — 비침습 동반진단

종양 DNA 일부가 혈액에 떠다니는 것을 검출:

| 검사 | 용도 |
|------|------|
| **Guardant360 CDx** | [[호르몬치료\|vepdegestrant]] 적응증 — **ESR1 변이** 확인 (FDA 2026 동반진단) |
| **PIK3CA ctDNA** | 알페리시브 적응증 (기존 종양 NGS 대안) |
| **잔존 미세 잔류병변 (MRD)** | 수술 후 재발 위험 추적 — 임상 단계 |
| **반응 평가 보조** | ctDNA 감소가 [[2026임상연구업데이트\|치료 반응 예측 후보]] |
| **Signatera** | 환자 맞춤형 MRD — 수술 직후 종양 조직으로 개인 마커 설계 |
| **FoundationOne Liquid CDx** | 다중 변이 패널 (BRCA·PIK3CA·ESR1·HER2 등) |

> 💡 [[2026임상연구업데이트|2026 FDA 승인 Guardant360 CDx]]는 ESR1 변이 환자에서 vepdegestrant 적응증을 결정. 비침습이라 전이 병소 조직검사 부담을 줄임.

#### ctDNA 핵심 임상 데이터

| 데이터 | 출처 |
|--------|------|
| 수술 1년 뒤 ctDNA 양성 → 전이 위험 **20.8배** | PubMed 38460249 (2024 SR/MA) |
| CT·MRI 발견 대비 ctDNA 리드 타임 **평균 8.7~10.7개월** | PMC10317487 (2023 MA) |
| 영상 한계: 콩알 크기 (수 mm) 필요 vs ctDNA: 마이크로미터 단위 | — |
| 종양 부담 적으면 위음성 가능성 ↑ | — |

→ [[정밀의학도구]] MRD 섹션 상세 / [[호르몬치료]] ESR1 통합 동선

### 4. HRD (Homologous Recombination Deficiency) — 유방암 도입 진행 중

상동재조합복구 결손 — BRCA 외에도 HRR 경로 (PALB2·RAD51·BARD1 등) 손상 평가:

**HRD score 도구**:
- **myChoice CDx (Myriad)**: FDA 승인 — 난소암 적응증 확립, 유방암은 일부 임상
- **Foundation Heme Liquid HRD**: 일부 적응증
- **국내 HRD 검사**: 일부 대형 병원 임상 도입

**임상 활용**:
- **OlympiA 외 PARP 적응증 확장 가능성** — BRCA 음성 + HRD-positive 환자
- TNBC·고위험 ER+에서 PARP·백금계 반응 예측
- 한국 보험 미적용 (난소암 우선 적용)

→ [[BRCA유전자]] HRR 경로 / [[PARP억제제]]

### 변이 vs 발현 — 검사 결정 통합 매트릭스

환자 시점·목적별로 어떤 검사를 받아야 하는지:

| 시점 | 검사 유형 | 결정 항목 |
|------|-----------|------------|
| **진단 직후 (모든 환자)** | IHC 4종 ([[면역조직화학검사(IHC)]]) | 서브타입 — ER·PR·HER2·Ki67 |
| **HER2 IHC 2+** | [[FISH검사]] | HER2 양성/음성 (HER2-low 분기) |
| **고위험 가족력·발병 <45세·TNBC·양측** | **gBRCA + 다유전자 패널** | 본인·가족 위험, PARP 적응증 |
| **수술 후 ER+/HER2- 조기 (T1-2N0-1)** | [[유전자발현프로파일링\|Oncotype DX·MammaPrint]] | 항암 추가 여부 (발현 검사) |
| **5년 호르몬 치료 후 연장 결정** | [[유전자발현프로파일링\|BCI]] | 10년 연장 이득 (발현 검사) |
| **재발·전이 진단** | 전이 병소 IHC 재검사 + **종양 NGS** | 서브타입 전환·약제 적응증 |
| **AI + CDK4/6 진행 (ER+ 전이성)** | **ESR1 ctDNA (Guardant360)** | vepdegestrant·엘라세스트란트 |
| **수술 후 재발 위험 모니터** | **MRD ctDNA (Signatera 등)** | 분자 단위 재발 조기 감지 — 임상시험 단계 |
| **임상시험 등록** | 종양 NGS + ctDNA | 적격 변이 확인 |

> 💡 같은 환자가 **시간이 지남에 따라 여러 검사**를 받을 수 있다. 각 시점의 검사 목적이 다름 — 변이 (영구·평생) vs 발현 (한 시점·항암 결정) vs ctDNA (실시간 추적) 차이 인지.

## 유전상담 (Genetic Counseling)

검사 전·후 전문가 상담은 BRCA 검사처럼 **결과가 본인·가족 모두에게 영향**을 주는 경우 권장:

| 시점 | 내용 |
|------|------|
| **검사 전** | 검사 의미·결과 시나리오·가족 영향·심리적 영향 설명 |
| **검사 후 양성** | 본인 추가 검진(MRI·예방 절제), 가족 검사 권유, 보험·취업 영향 |
| **검사 후 VUS** | 추적 계획, 의학적 결정 보류 |

**한국 유전상담 접근성**:
- 대형 대학병원 **유전상담 클리닉** 운영 (서울대·아산·삼성 등)
- 일부는 별도 진료비, 일부는 외래 진료 안에 포함
- **유전자 검사 자체는 보험 일부 적용**, 상담은 비급여 가능

## 한국 임상 가이드라인 / 보험 적용 여부

### BRCA 검사
- 한국유방암학회 가이드라인 기준 충족 시 산정특례로 부담 줄어듦
- 보험 적용 조건: 발병 나이·가족력·서브타입 등 (기준 변동)
- 검사비: 보험 적용 시 본인부담 줄어듦, 비급여 시 수십~수백만원

### 종양 NGS
- 일부 적응증에 한해 산정특례·산정외 적용
- 임상시험 등록 시 무상 가능

### ctDNA
- 일부 적응증 (Guardant360 CDx 등) 한국 도입 진행 중
- 2026-05 기준 일부 병원만 가능

### 한국 보험 적용 동향 매트릭스 (2026-05 기준)

| 검사 | 보험 적용 | 본인부담 (산정특례 5%) |
|------|-----------|------------------------|
| **BRCA1/2 단독** | ✅ 기준 충족 시 | 약 10~30만 원 |
| **BRCA 가족 검사 (확인 변이)** | ✅ 변이 확인 후 가족 | 약 5~15만 원 |
| **다유전자 패널 (17~80개)** | ⚠️ 일부 (NCCN 적응증) | 비급여 시 70~200만 원 |
| **종양 NGS** | ⚠️ 적응증별 | 비급여 50~200만 원 |
| **HER2 FISH** | ✅ IHC 2+ 적응증 | 약 5~10만 원 |
| **PIK3CA NGS** | ⚠️ 알페리시브 동반진단 | 일부 적용 |
| **HRD score** | ❌ 미적용 (난소암 우선) | 자비 100~300만 원 |
| **Guardant360 ctDNA** | ❌ 도입 진행 | 자비 약 200~400만 원 |
| **Signatera MRD** | ❌ 임상시험 | 자비 또는 시험 무상 |
| **Oncotype DX** | ⚠️ 일부 적용 | 비급여 시 300만 원+ |
| **MammaPrint** | ⚠️ 일부 적용 | 비급여 시 약 500만 원 |

> 💡 **검사 결정 시 환자가 확인할 항목**:
> 1. 이 검사가 내 치료에 직접 영향을 주는가?
> 2. 결과 통보까지 얼마나 걸리나? (다음 치료 일정과 맞나)
> 3. 보험 적용·자비 비용은?
> 4. 본 병원에서 시행 가능한가, 외부 의뢰인가?
> 5. 같은 검체로 한 번에 여러 변이 동시 검출 가능한가? (NGS 패널)

### 검사 결과 통보까지 소요 시간

| 검사 | 일반 소요 |
|------|------------|
| BRCA 단독 | 2~4주 |
| 다유전자 패널 | 4~6주 |
| FISH (HER2) | 5~10일 |
| 종양 NGS | 2~4주 |
| ctDNA (Guardant 등) | 1~2주 |
| Signatera MRD (개인화) | 초기 셋업 4~6주, 이후 분기별 |
| Oncotype DX | 약 2주 |

## 임상적 의의

- 유방암 유전자 검사는 **개인 위험 평가 → 약제 선택 → 가족 위험**까지 세 축으로 확장
- BRCA 검사 결과는 [[BRCA유전자|예방적 절제]] 결정에 활용 — [[유방암보험청구쟁점|대법원 2021다234368]] 판례로 보험 청구도 가능
- 종양 NGS는 [[2026임상연구업데이트|2026 신약]] (vepdegestrant·알페리시브·카피바세르팁 등) 적응증과 직결
- ctDNA는 비침습 — 전이 병소 조직검사가 어려울 때 대안

## 미해결 질문 / 연구 방향
> 💡 PALB2·CHEK2 등 BRCA 외 한국인 빈도·치료 영향
>    → **답변 (2026-05)**: PALB2 약 1~2%·CHEK2 약 1%·ATM 약 1% (한국 BRCA 음성 코호트). **PALB2**는 BRCA2와 동등 위험 — OlympiA 후속·일부 PARP 적응증 확대 진행. CHEK2 1772delT는 위험 RR 2~3.
>
> 💡 ctDNA 기반 MRD 임상 적용 시점
>    → **답변**: **Signatera·Natera·FoundationOne Tracker** 임상 진입 — 수술 1년 뒤 양성 → 전이 위험 20.8배 (PubMed 38460249), CT/MRI 대비 8~10개월 리드타임 (PMC10317487). 표준 진입은 **2027~2028** 예상. 한국 도입 임상시험 단계.
>
> 💡 멀티진 패널 VUS 해석 표준화
>    → **답변**: **ClinVar·ENIGMA·ACMG/AMP 분류 표준** — 5등급 (B/LB/VUS/LP/P). 매년 5~10% 재분류. **고기능 분석 (saturation editing)** 으로 BRCA1 모든 변이 분류 완료 (Findlay Nature 2018). 임상 결정은 VUS 단독 ❌.

## 주의사항
> ⚠️ 검사 결과는 본인뿐 아니라 **가족에게도 영향**을 미친다. 양성 결과 시 가족 검사 권유는 가족 동의를 전제로 한다.
> ⚠️ VUS 결과는 의학적 결정에 단독 근거로 사용하지 않는다.
> ⚠️ 유전자 검사 결과는 일부 보험·취업에 영향을 줄 수 있어 검사 전 [[유전자검사|유전상담]]을 권장한다.
