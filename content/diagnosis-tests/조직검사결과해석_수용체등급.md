# 조직검사 결과 해석 — 수용체·등급 판독

> 이 페이지는 [[diagnosis-tests/조직검사결과해석|조직검사 결과해석 허브]]에서 분리된 세부 문서입니다.

결과지에 등장하는 ER·PR·HER2·Ki-67·Histologic Grade를 해석하는 방법을 다룬다. ASCO 2026 이후 HER2 IHC 0/1+ 경계 판독 정확도와 ER 약양성 임상 의미가 중요해졌다.

---

## 결과지 핵심 용어 해설

### Histologic Grade (= Nottingham Grade = Elston Grade)

세 이름은 모두 같은 의미. 3가지 측면을 점수화한 합산 그레이드:
1. 관상(tubule) 형성 정도
2. 핵 모양의 다양성
3. 분열 중인 세포 수

| Grade | 점수 합 | 특징 |
|-------|---------|------|
| **Grade 1** | 3~5점 | 정상세포와 비슷, 천천히 성장, 예후 양호 |
| **Grade 2** | 6~7점 | 중간 |
| **Grade 3** | 8~9점 | 정상세포와 매우 다름, 빠른 성장·전파 경향, 예후 나쁜 편 |

**임상 결정 원칙**:
- Grade + Ki-67 + 종양 크기 + 림프절 → 항암 추가 여부
- **단독 결정 금지** — RS·BCI·EPclin과 통합

---

### Ki-67 지수

- 암세포 증식·분열 속도 지표
- **30% 이상**이면 분열 활성 높음으로 해석되는 경우가 많음
- 같은 종양 안에서도 부위별 염색 결과가 다르며, 실험자 숙련도에 따른 오차 존재
- **Ki-67만으로 항암 여부를 단독 판단하지 말 것** — [[research/온코타입DX_RS점수|RS 점수]] 등 종합 평가 필요

#### Ki-67 통합 평가 도구 매트릭스

| 도구 | 활용 |
|------|------|
| **Ki-67 단독** | 부정확 — 부위별 염색 차이, 실험자 숙련도 |
| **Ki-67 + Grade + 종양 크기 + 림프절** | 임상 위험도 |
| **+ Oncotype DX RS** | 항암 추가 결정 |
| **+ MammaPrint·Prosigna·EndoPredict** | 5종 검사 통합 |
| **+ BCI (5년 시점)** | 호르몬 연장 결정 |

→ [[diagnosis-tests/유전자발현프로파일링|5종 검사 통합 흐름]]

### TNM 병기 구성요소

| 기호 | 의미 |
|------|------|
| **T** | 종양 크기 (T0, Tis/DCIS, T1, T2, T3, T4) |
| **N** | 림프절 전이 (N0 = 없음, N3까지) |
| **M** | 원격 장기 전이 (M0 = 없음, M1 = 있음) |
| **pN1mi** | 림프절 미세전이 — 외과 절제 후 병리에서 확인 |

→ 병기 결정의 전체 흐름은 [[diagnosis-workflow/유방암진단체계|유방암 진단 체계]] 참조

---

### 주요 IHC/FISH 결과 의미

| 항목 | 의미 |
|------|------|
| **ER(+)** | 에스트로겐 수용체 양성 → [[treatment-systemic/호르몬치료|호르몬치료]] 반응 가능 |
| **PR(+)** | 프로게스테론 수용체 양성 |
| **HER2(+)** | [[treatment-systemic/HER2표적치료|허셉틴·퍼투주맙]] 표적치료 가능 |
| **E-cadherin(-)** | 침윤성 소엽암 의심 |

→ 서브타입 결정의 전체 흐름은 [[biology/유방암분자서브타입|유방암 분자 서브타입]] 참조

## ASCO 2026 후 결과지 해석 갱신

### HER2 IHC 0/1+ 정밀 판독 — DESTINY-Breast06 1차 도입 압력

ASCO 2026 후 HER2-low/ultralow 1차 ADC ([[treatment-systemic/HER2-low치료|엔허투]]) 도입과 함께 **HER2 0 vs 1+ 경계 판독 정확도**가 환자 치료 결정의 핵심:

| IHC 점수 | 정의 | ADC 적응증 |
|----------|------|-------------|
| **HER2 0** | 완전 음성·염색 없음 | 없음 |
| **HER2 ultralow** | 0이지만 일부 염색 (≤10% 약한 막 염색) | DESTINY-Breast06 1차 (FDA 적응증, 한국 비급여) |
| **HER2 1+** | 약한 막 염색 (10%+) | 엔허투 (전이성 2차+ 표준·1차 도입 진행) |
| **HER2 2+** | 중간 강도 | FISH 필수 — FISH+ = HER2+, FISH- = HER2-low |
| **HER2 3+** | 강한 막 염색 | HER2+ 표준 (허셉틴·퍼투주맙·T-DXd·T-DM1) |

**디지털 병리 AI 도입** (2026-06):
- **Paige Breast·Lunit SCOPE HER2** — HER2 0/1+ 경계 판독 일치율 90%+
- 병리의 판독 + AI 보조 표준화 진행
- 한국 일부 대형 병원 (삼성·서울대·아산) 시범 운영
- → [[diagnosis-imaging/유방암AI영상|디지털 병리 AI 상세]]

> 💡 **카페 환자 진료실 질문**: "**제 HER2 IHC 0/1+ 경계 결과 — 디지털 병리 AI 재판독 가능한가요?**" — 엔허투 적응증 판정에 직결.

---

### ER/PR 발현 강도 — 약한 양성·% 평가 갱신 (2026-06)

| 발현 | 의미 | 치료 권고 |
|------|------|-----------|
| **ER 강양성** (>90%) | 호르몬 의존성 高 | 호르몬치료 단독·CDK4/6 병합 |
| **ER 중간 양성** (10~90%) | 표준 호르몬 치료 | 호르몬치료 + 항암 검토 |
| **ER 약양성** (1~9%) | 호르몬 의존성 낮음 | TNBC와 유사 행동 — 항암 적극 |
| **ER 음성** (<1%) | 호르몬치료 불가 | 항암 + 면역 (TNBC 시) |

**임상 의미**:
- ER 1~9% (약양성) 환자는 호르몬 치료 효과 제한적 — TNBC 진료 모델 일부 적용
- ER 약양성 + HER2+ = 비교적 공격적
- → [[biology/유방암분자서브타입|서브타입 결정]] 통합

---

### 환자가 결과지에서 우선 확인할 7항목

1. **진단명** (양성·DCIS·침윤암·아형)
2. **HER2 IHC + FISH** (0/1+/2+/3+ — HER2-low/ultralow 가능성)
3. **ER·PR %·강도** (강·중·약 양성)
4. **Ki-67 %**
5. **Histologic Grade** (1/2/3)
6. **종양 크기·림프절** (T·N)
7. **수술 변연·LVI·EIC** (재수술 여부)

> 💡 결과지에서 HER2 IHC 0/1+ 경계 또는 ER 약양성이면 **재판독·디지털 병리 AI 검토** 요청 가치 ↑.

---

### 결과지에 등장하는 진단명 분류

**'암이 아닌' 진단명**:
usual ductal hyperplasia, adenosis, sclerosing adenosis, radial scar, papilloma, apocrine metaplasia, cysts, fibrocystic changes 등 — 양성 분류이지만 일부는 증식성으로 위험도 평가가 필요 (→ [[조직검사결과해석_병변분류|병변 분류 세부]] 참조)

**'제거 필요한 상피내암'**:
atypical ductal hyperplasia (ADH), atypical lobular hyperplasia (ALH), **DCIS**, intraductal carcinoma, **LCIS** 등
