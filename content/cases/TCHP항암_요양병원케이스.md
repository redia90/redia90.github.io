# TCHP 6회 항암 — 요양병원 병행 회복 케이스

## 환자 프로파일 (익명)
- 네이버 카페 '유방암이야기' 회원
- TCHP 6회 항암을 받은 [[HER2표적치료|HER2 양성]] 추정 환자
- 1~2차는 자택에서 단독 회복, 3차부터 요양병원 입원 병행

## 진단 경과
원문에는 진단·병기 세부 정보가 명시되어 있지 않으나, [[항암화학요법|TCHP 요법]](도세탁셀 + 카보플라틴 + [[HER2표적치료|허셉틴 + 퍼투주맙]]) 6회를 받았다는 사실에서 [[유방암분자서브타입|HER2 양성]] 유방암 환자임을 추정할 수 있다.

## 치료 선택과 근거
- 표준 TCHP 6회 항암
- **회차별 회복 전략 변경**:
  - 1~2차: 집에서 단독 회복
  - 3차 이후: 항암 직후 약 **10일씩 요양병원 입원**, 다음 항암 전까지 자택 복귀
- 실비보험 활용

## 치료 반응 — 증상별 자가 관리 기록

작성자는 부작용을 "참기보다 증상별로 빠르게 기록·요청"한 점을 강조한다. 다음은 6회 동안 누적된 22개 증상과 관리 포인트:

| 증상 | 경험담 기반 관리 포인트 |
|------|---------------------------|
| 구토·메스꺼움 | 식사가 어려울 때 **식욕촉진제 처방**으로 도움 |
| 구내염·입마름 | 얼음 물기, 식염수 가글, 프로폴리스, 오라메디, 비판톨 |
| 고열 | 해열제로 버티지 말고 병원 기준에 따라 응급실 문의 (작성자는 고열을 참았다가 교수에게 주의받음) |
| 식욕부진·극심한 피로 | 잘 먹고 잘 자기 핵심. 필요 시 영양주사·수면장애 약 활용 |
| 설사·변비·가스 | 항암 내내 변 상태 변화 반복 → 기록하고 병원 공유 |
| 탈모·두피염 | **1차 후 16일째 급격한 탈모**. 두피 염증은 처방 연고·스프레이 |
| 착색·혈관 변화 | 항암 주사 부위, 팔 혈관, 얼굴 기미 검게 착색 — 자외선 차단 필수 |
| 콧물·코피 | 점막이 얇아져 잦아짐 |
| 부종 | 발목 자국이 오래 남을 정도, 체중 증가 — **도수치료** 도움 |
| 눈 분비물·다래끼 | 안과 진료·눈꺼풀 세정제 |
| 전신 건조 | 손끝·피부·손발톱 건조, 지문 흐려짐 → 수분크림 자주 |
| 상처 염증 | 작은 상처도 커질 수 있어 피부과 진료 필요 가능 |
| 주사 부위 통증·물집 | 화상처럼 수포·착색 → 냉찜질 |
| 손발톱 손상 | 조반월 소실, 검은 멍, 들뜸과 통증 → 손톱 영양제 |
| 손발저림 | 말초신경 손상으로 통증·감각저하 → 도수치료·지압볼 |
| 불면증 | 기존 수면장애가 악화되어 **정신건강의학과 약**으로 관리 |
| 배꼽 염증 | 배꼽 주변 발적·분비물 |
| 공간·지각능력 저하 | 운전 중 멍함·방향감각 저하 → **장거리 운전 회피** |
| 관절·근육통 | 계단 오르기 힘들 정도 → 본병원 처방약 도움 |
| 잔기침·쉰 목소리 | 피로 시 발생 |
| 어지럼증 | 일어서다 주저앉을 정도 → **낙상 주의** |
| 호중구 수치 | 주 2회 면역주사제로 회복 |

→ 표준 부작용 분류는 [[항암화학요법]] 참조

## 요양병원 활용 — 의사결정 체크리스트

작성자가 요양병원을 선택할 때 확인한 포인트:

- **실비보험**이 있다면 항암 후 심한 부작용을 혼자 견디기보다 요양병원 이용 검토
- 의료적 도움뿐 아니라 환우들과 산책·서로 위로한 경험이 **심리적 지지** 측면에서 큰 도움
- 선택 시 확인 항목:
  - 항암 부작용 관리 수준
  - 수액·영양 지원
  - 도수치료 제공 여부
  - 수치 관리 (혈액·간기능 모니터)
  - **본병원과의 연계 가능성**
  - 주치의 상담 빈도

> ⚠️ 요양병원 치료는 [[항암화학요법|표준치료]]를 **대체하는 것이 아니라** 항암을 버티기 위한 **보조적 회복 수단**으로 본다.

## 교훈

1. 항암 부작용은 "참는 것"이 아니라 증상별로 **빠르게 기록·요청**하는 것이 중요
2. 혼자 집에서 버티기 힘든 시기에는 **요양병원·가족·환우 커뮤니티** 같은 지지 자원을 활용
3. 고열, 염증, 어지럼, 낙상 위험, 주사 부위 이상은 작게 넘기지 말고 **본병원 기준**에 따라 확인
4. 식욕촉진제, 수면제, 영양주사, 도수치료, 정신건강의학과 약 등 **다학제 협진**을 적극 활용
5. 도수치료는 부종·말초신경병증에 카페에서 반복 권장됨 (효과 개인차 있음)

## 임상적 의의
- 한국 환자에서 흔한 **요양병원 병행 항암**의 실제 운영 사례 — 표준치료 가이드에는 잘 나오지 않는 영역
- 증상 기록을 통한 자가 관리 + 의료팀 적극 활용 모델은 [[항암화학요법|항암화학요법]] 환자 교육에 활용 가능
- TCHP 22개 증상 카탈로그는 환자가 다음 회차 준비에 활용 가능한 체크리스트
