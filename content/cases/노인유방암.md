# 노인 유방암 (70세 이상)

## 개요

70세 이상 유방암은 한국 임상에서 비중이 빠르게 증가하지만 임상시험 데이터는 65세 미만에 집중되어 **표준 치료 적용 vs 강도 조정(de-escalation) 사이의 균형**이 핵심이 된다. 결정 기준은 단순 연령(chronological age)이 아니라 **종합 노인 평가(CGA)** 로 본 생리적 나이·기능 상태·동반 질환·예상 여명이다.

ER+/HER2-가 우세해 [[호르몬치료]] 중심 전략이 잘 맞으며, **PRIME II (NEJM 2023)** 같은 새 임상 결과로 일부 환자에서 방사선 생략이 가능해지는 등 의사결정 옵션이 늘고 있다. "노인이라서 치료 안 한다"는 통념과 "표준 일률 적용"은 모두 위험하며, CGA·환자 가치관 기반 개별화가 정답이다.

한국은 70세 이상 유방암 환자 비율이 약 15~20%(증가 추세)이며, 80세 이상도 약 5%를 차지한다. 노인 환자는 진단 지연·임상시험 데이터 부족·다약제·돌봄 자원 격차라는 고유한 도전을 안고 있어 **노인의학 + 종양내과 + 사회복지 다학제 팀**이 필요하다.

## 빠른 참조 테이블

| 항목 | 핵심 내용 |
|------|-----------|
| **서브타입** | ER+/HER2- 약 75~85% — 호르몬치료 중심 |
| **CGA 분류** | Fit → 표준, Vulnerable → 조정, Frail → 완화 중심 |
| **선별 도구** | G8 ≤14점 → 정밀 CGA 필요 |
| **방사선 생략** | PRIME II: 65세+ T1-T2 N0 ER+ 보존수술 + 호르몬치료 시 생략 검토 |
| **항암 경구 옵션** | Capecitabine·비노렐빈 우선 (취약·쇠약 환자) |
| **HER2+ 노인** | 트라스투주맙 + 카페시타빈 (RESPECT 임상) |
| **CDK4/6 노인** | 80세+ 감량 시작 흔함 (400mg→300mg) |
| **필수 모니터** | 낙상·골밀도·인지·영양·다약제 |

## 임상적 의의

- 노인 유방암은 한국 임상에서 비중이 빠르게 증가하지만 **임상시험 데이터 부족** 상태
- CGA·G8 기반 치료 결정이 표준 — 단순 연령 컷오프 회피
- PRIME II는 "노인 방사선 일률 시행"에서 "선택적 생략" 패러다임 변화
- 호르몬 치료가 가장 큰 비중을 차지하나 부작용 관리·순응도가 핵심
- "노인이라서 치료 안 한다"는 잘못된 통념 — fit한 환자는 표준 치료 안전
