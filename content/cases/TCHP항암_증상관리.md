# TCHP 항암 — 치료 선택·증상관리·호중구 타이밍·요양병원 체크리스트

> 이 페이지는 [[cases/TCHP항암_요양병원케이스|TCHP 케이스 허브]]에서 분리된 세부 문서입니다.

## 치료 선택과 근거

- 표준 TCHP 6회 항암 (도세탁셀 + 카보플라틴 + 허셉틴 + 퍼투주맙)
- **회차별 회복 전략 변경**:
  - 1~2차: 집에서 단독 회복
  - 3차 이후: 항암 직후 약 **10일씩 요양병원 입원**, 다음 항암 전까지 자택 복귀
- 실비보험 활용

## 치료 반응 — 증상별 자가 관리 기록

작성자는 부작용을 "참기보다 증상별로 빠르게 기록·요청"한 점을 강조한다. 다음은 6회 동안 누적된 22개 증상과 관리 포인트:

| 증상 | 경험담 기반 관리 포인트 |
|------|---------------------------|
| 구토·메스꺼움 | 식사가 어려울 때 **식욕촉진제 처방**으로 도움 |
| 구내염·입마름 | 얼음 물기, 식염수 가글, 프로폴리스, 오라메디, 비판톨 |
| 고열 | 해열제로 버티지 말고 병원 기준에 따라 응급실 문의 (작성자는 고열을 참았다가 교수에게 주의받음) |
| 식욕부진·극심한 피로 | 잘 먹고 잘 자기 핵심. 필요 시 영양주사·수면장애 약 활용 |
| 설사·변비·가스 | 항암 내내 변 상태 변화 반복 → 기록하고 병원 공유 |
| 탈모·두피염 | **1차 후 16일째 급격한 탈모**. 두피 염증은 처방 연고·스프레이 |
| 착색·혈관 변화 | 항암 주사 부위, 팔 혈관, 얼굴 기미 검게 착색 — 자외선 차단 필수 |
| 콧물·코피 | 점막이 얇아져 잦아짐 |
| 부종 | 발목 자국이 오래 남을 정도, 체중 증가 — **도수치료** 도움 |
| 눈 분비물·다래끼 | 안과 진료·눈꺼풀 세정제 |
| 전신 건조 | 손끝·피부·손발톱 건조, 지문 흐려짐 → 수분크림 자주 |
| 상처 염증 | 작은 상처도 커질 수 있어 피부과 진료 필요 가능 |
| 주사 부위 통증·물집 | 화상처럼 수포·착색 → 냉찜질 |
| 손발톱 손상 | 조반월 소실, 검은 멍, 들뜸과 통증 → 손톱 영양제 |
| 손발저림 | 말초신경 손상으로 통증·감각저하 → 도수치료·지압볼 |
| 불면증 | 기존 수면장애가 악화되어 **정신건강의학과 약**으로 관리 |
| 배꼽 염증 | 배꼽 주변 발적·분비물 |
| 공간·지각능력 저하 | 운전 중 멍함·방향감각 저하 → **장거리 운전 회피** |
| 관절·근육통 | 계단 오르기 힘들 정도 → 본병원 처방약 도움 |
| 잔기침·쉰 목소리 | 피로 시 발생 |
| 어지럼증 | 일어서다 주저앉을 정도 → **낙상 주의** |
| 호중구 수치 | 주 2회 면역주사제로 회복 |

→ 표준 부작용 분류는 [[항암화학요법]] 참조

## TCHP 호중구 최저점 타이밍 — 요양병원 입소 가이드

### 호중구 최저점 (Nadir) — TCHP 주기별 타이밍

TCHP는 3주(21일) 1사이클 기준:

| 시점 | 호중구 상태 | 주의 사항 |
|------|-------------|-----------|
| **Day 1** | 항암 투여일 — 정상 범위 확인 후 투여 | 뉴라스타 (G-CSF) 당일 또는 +1일 투여 |
| **Day 3~7** | 점진적 감소 시작 | 발열·오한 시작 시 즉시 대응 준비 |
| **Day 8~14 (★Nadir)** | **호중구 최저점 — 가장 위험한 시기** | **38℃ 발열 → 즉시 응급실**, 혼자 외출 회피 |
| **Day 10~12** | 최저점 (뉴라스타 없을 경우 더 낮고 더 길 수 있음) | 사람 많은 곳 절대 회피 |
| **Day 14~18** | 회복 시작 — ANC 점진적 상승 | 외래 혈액검사로 회복 확인 |
| **Day 18~21** | 대부분 정상 복귀 → 다음 사이클 준비 | 다음 항암 전 혈액검사 기준 확인 |

> ⚠️ 뉴라스타 (페그필그라스팀) 투여 시: Nadir 깊이 감소·기간 단축 효과. 그러나 Day 8~14은 여전히 감염 위험 고위험 구간 — 발열 = 즉시 응급실.

### 요양병원 입소 가능 시점 — 실전 가이드

카페 케이스 종합:

| 입소 시점 | 장·단점 | 적합 상황 |
|-----------|---------|-----------|
| **항암 당일 또는 +1일** | 부작용 즉시 관리 가능 / 요양병원 의료 수준 확인 필요 | 체력 저하, 1인 가구, 1차 후 매우 힘든 사람 |
| **Day 2~5 (오심·설사 피크)** | 부작용 피크 시 수액·약물 지원 가장 효과적 | 오심·구토·설사 심한 사람, 탈수 위험 높은 사람 |
| **Day 7~10 (Nadir 전후)** | 호중구 최저점 감염 위험 구간 커버 가능 | 고열 이력·면역 저하 우려·가족 돌봄 어려운 경우 |
| **Day 10~14 종료 후** | 최저점 지나고 입소 → 상대적으로 안전 | 부작용 스스로 관리 가능하나 회복 지원 필요 |

**카페 사례에서 반복된 요양병원 체류 패턴**:
- **3차 이후 10일 입원** (본 케이스 핵심 패턴) — 가장 흔한 모델
- **3차부터 7일 수액치료** (사례 2, #21 — 체중 36kg 감량 케이스)
- **막항 당일 즉시 요양병원** (사례 4, #43 — 막항 + 심장초음파 + 뉴라스타 당일)

**요양병원 입소 전 본병원에 반드시 확인할 항목**:
1. **본 병원 연계 가능 여부** — 호중구 기준치 이하 시 응급 연락 체계
2. **뉴라스타 투여 여부** — 이미 투여했다면 Nadir가 더 짧을 수 있음
3. **38℃ 발열 시 대응 프로토콜** — 요양병원에서 응급실로 이송 기준 사전 확인
4. **실비보험 처리 방식** — 입원/통원 구분·요양병원 전문의 진료 확인서 발급 가능 여부

## 요양병원 활용 — 의사결정 체크리스트

작성자가 요양병원을 선택할 때 확인한 포인트:

- **실비보험**이 있다면 항암 후 심한 부작용을 혼자 견디기보다 요양병원 이용 검토
- 의료적 도움뿐 아니라 환우들과 산책·서로 위로한 경험이 **심리적 지지** 측면에서 큰 도움
- 선택 시 확인 항목:
  - 항암 부작용 관리 수준
  - 수액·영양 지원
  - 도수치료 제공 여부
  - 수치 관리 (혈액·간기능 모니터)
  - **본병원과의 연계 가능성**
  - 주치의 상담 빈도

> ⚠️ 요양병원 치료는 [[항암화학요법|표준치료]]를 **대체하는 것이 아니라** 항암을 버티기 위한 **보조적 회복 수단**으로 본다.
