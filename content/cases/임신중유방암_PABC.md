# 임신 관련 유방암 (PABC) — 임신 중·산후 진단

## 개요
**임신 관련 유방암(Pregnancy-Associated Breast Cancer, PABC)** 은 임신 중 또는 분만 후 **1년 이내** 진단된 유방암을 통칭한다. 두 그룹으로 나뉜다: **PrABC (임신 중 진단)** 와 **PpBC (산후 1년 이내 진단)**. 전체 유방암의 약 0.2~3.8%를 차지하며, 젊은 진단·진단 지연·복잡한 치료 결정이 특징이다. 임신 중에도 일부 치료는 안전하게 가능하며, "임신 종료가 무조건 필요하다"는 오해는 잘못된 것이다. 카페 #262622 (둘째 임신 중 진단 시리즈)·#265798(간전이 4기) 등 한국 사례도 있다.

## 환자 프로파일 (특성)

### 빈도
- 전체 유방암 중 **0.2~3.8%** (분류 기준에 따라)
- 가임 연령 유방암 환자의 약 7%
- 한국: 정확한 빈도 데이터 부족, 30~40대 진단 증가와 함께 관심 영역

### 특수성 — 진단 지연
- 임신·수유로 유방 조직이 부풀고 압통 발생 → 멍울 발견 어려움
- 신체검진에서 멍울이 "수유 변화"로 오인
- 환자 본인도 검진 미루는 경향
- **진단 지연 평균 5~15개월** (비PABC 대비 길어짐)
- 결과적으로 진단 시 더 진행된 병기 (림프절 양성·종양 크기 큼)가 많음

### 분자 특성
- 약 60~70% **HR 양성**
- **HER2 양성** 약 25~30% (일반 환자보다 높음)
- **TNBC** 약 15~30%
- BRCA 변이 비율 약간 더 높음 (젊은 진단 효과)

## 진단 — 임신 중 가능한 검사

| 검사 | 임신 중 안전성 |
|------|----------------|
| **신체검진·유두 분비물** | ✅ 안전 |
| **유방 초음파** | ✅ 안전 — 1차 검사 |
| **유방촬영술 (맘모그래피)** | ✅ 복부 차폐 시 안전 — 태아 노출 미미 |
| **유방 MRI (조영제 없이)** | ⚠️ 가돌리늄 조영제는 회피 — 비조영 MRI는 일부 사용 |
| **조직검사 (CNB)** | ✅ 안전 — 표준 검사 |
| **흉부 X-ray (복부 차폐)** | ✅ 안전 |
| **흉부 CT** | ⚠️ 필요 시 복부 차폐 |
| **PET-CT** | ❌ 회피 — 방사선 노출 |
| **뼈 스캔** | ❌ 회피 — 방사성 동위원소 |

> 💡 임신 중 PABC 의심 시 **유방 초음파 + CNB**가 1차. 영상 검사를 거부하지 않는다.

## 진단 경과 (한국 사례 — 카페 #262622)

1. **임신 중 멍울 발견** (남편 또는 본인)
2. 개인 병원 → 대학병원 의뢰
3. 임신 단계 확인 → 검사 안전성 평가
4. 초음파·조직검사
5. 다학제 평가 (산부인과·종양내과·외과·방사선종양학과)
6. 임신 단계·서브타입·환자 의향 종합 결정

## 치료 선택과 근거 — 임신 단계별

### 1삼분기 (1~12주)
- **수술 가능**: 전신마취 안전 (수술 자체는 임신 중 가능)
- **항암 회피**: 기형 위험 — 첫 12주는 가장 위험
- 일반적으로 1삼분기 진단 시 → 임신 13~14주까지 대기 후 항암
- 임신 종료 결정은 환자·가족·종양내과 협의

### 2삼분기 (13~28주)
- **수술 가능**
- **항암 가능** — 안트라사이클린(AC)·탁산(파클리탁셀) 안전성 데이터 다수
- 카보플라틴·시클로포스파마이드 등 사용
- **방사선 회피** — 분만 후 시행
- [[HER2표적치료|허셉틴]] 회피 (양수 감소·태아 신장 손상)
- 내분비치료([[호르몬치료|타목시펜]]) 회피 — 태아 기형 위험
- [[PARP억제제]] 회피 (안전성 데이터 없음)

### 3삼분기 (29주~분만)
- **수술 가능**
- **항암 가능** — 분만 3주 전까지
- **방사선 회피** — 분만 후
- 출산 후 곧바로 표준 치료 (방사선·허셉틴·호르몬·PARP) 시작

### 분만 시점
- 종양 진행 위험과 태아 성숙도 균형
- 가능하면 **만삭 (37주 이상) 출산** 권장
- 응급 시 34~36주에 유도 가능
- **모유수유**: 항암 약제 잔존으로 일부 약제는 모유로 분비 — 종양내과 확인

## 치료 반응

- 임신 중 항암 반응은 비PABC 환자와 **유사**
- 단, 진단 지연으로 진행된 병기가 많아 **전체 예후는 더 나쁨**
- 같은 병기·서브타입 기준에서는 차이 없음 (대규모 메타분석)

## 태아 결과 (Amant NEJM 2015)

- 임신 중 항암 받은 어머니의 자녀 추적 (3~12세)
- **인지·심장 기능 정상**
- 조산 빈도는 약간 높음 — 의도적 조기 분만 영향

### 안전한 약제 (2~3삼분기)
- 안트라사이클린: 독소루비신·에피루비신
- 탁산: 파클리탁셀
- 사이클로포스파마이드
- 5FU
- 카보플라틴

### 회피 약제
- 메토트렉세이트 (항폴산 — 1삼분기 절대 회피, 후기도 신중)
- 타목시펜
- 허셉틴·퍼투주맙·엔허투
- PARP 억제제
- CDK4/6 억제제
- 면역항암제 (안전성 데이터 부족)
- 방사선 치료

## 산후 진단 (PpBC)

분만 후 1년 이내 진단된 유방암:
- 임신 중 진단 회피된 종양이 산후 진행해 진단되는 경우
- 산후 호르몬 환경에서 더 공격적 행동 우려 (일부 연구)
- 모유수유 중단 결정 — 항암 약제 잔존
- 일반 환자와 치료는 동일하지만 영아 돌봄 부담이 크다

## 환자 특수 그룹 공통 주제

[[남성유방암]]·[[노인유방암|노인 유방암 (70세 이상)]]과 함께 **희귀·특수 환자 그룹**으로서 공유하는 도전:

| 공통 주제 | 남성 | PABC (이 페이지) | 노인 |
|------------|------|--------------------|------|
| 진단 지연 | 인식 부족 | **임신 변화 오인 (평균 5~15개월)** | 검진 빈도 낮음 |
| 임상시험 데이터 부족 | ✓ | ✓ (특히 안전성 데이터) | ✓ |
| 표준 가이드라인 한정 적용 | ✓ | ✓ (단계별 약제 회피) | ✓ (PRIME II 등 노인 특이 연구) |
| 다학제 팀 | 종양내과 + 비뇨기과 | **종양내과 + 산부인과 + 신생아과 + 외과 + 방사선** | 종양내과 + 노인의학 + 사회복지 |
| 환자 의사결정 가치관 | 수치심 극복 | **임신 종료 vs 치료 — 환자 의향 우선** | 삶의 질 vs 적극 치료 |
| 가족 영향 | BRCA2 자녀·형제 | **자녀 양육 + 임신·출산** | 돌봄 부담·요양 등급 |
| 환우 커뮤니티 | 매우 소수 | 소수 (소셜 미디어·환우회) | 디지털 접근성 격차 |

> 💡 세 그룹 모두 [[환자지원프로그램]]·[[보호자심리지지]] 자원이 일반 환자보다 더 중요. 다학제 협진의 가치도 더 큼.

## 교훈

1. **"임신 중 유방암 = 임신 종료" 잘못된 통념** — 2~3삼분기에는 항암 가능
2. 진단 지연이 가장 큰 위험 요인 — 임신 중 멍울은 즉시 평가
3. **다학제 팀** 필수 (산부인과·종양내과·외과·방사선·신생아과)
4. 자녀 추적 결과 인지·심장 정상 — 의학적 두려움보다 진단 지연이 더 큰 위험
5. [[가임력보존|가임력 보존]] 결정은 임신 중에는 불가능 — 산후 후속 임신 계획에 영향
6. 카페 #265798: 2기에서 1년 반 만에 간전이 4기로 진행 — 첫째 임신 중 진단·둘째 임신 중 진행 사례

## 임상적 의의

- PABC는 **희귀하지 않음** — 30~40대 진단 증가와 함께 임상적 중요성 커짐
- 임신 중 진단 시 산모·태아 모두 안전한 치료 옵션이 다수 있음
- 진단 지연 회피가 예후의 가장 큰 결정 요인
- 표준 가이드라인(ESMO 2020·한국유방암학회)에 포함된 영역
- 환자 의사결정에 산부인과 + 종양내과 + 신생아과 다학제 필수

## 미해결 질문 / 연구 방향
> 💡 BRCA 변이 PABC 환자에서 PARP 억제제 적용 — 산후 시작 시점·수유 영향
> 💡 산후 면역항암제 안전성 데이터 (수유 중 환자)
> 💡 한국 PABC 코호트 — 정확한 빈도·치료 결과 데이터 구축

## 주의사항
> ⚠️ "임신 중에는 영상 검사를 모두 미뤄야 한다"는 잘못된 인식이 진단 지연의 핵심 원인이다. 멍울 발견 시 초음파·조직검사는 안전하다.
> ⚠️ 1삼분기 항암은 기형 위험 — 진단 시점이 1삼분기면 13~14주까지 대기 가능 여부 종양내과·산부인과 협의.
> ⚠️ 임신 종료 결정은 의학적 권고가 아니라 **환자 의향**이 우선이다. 의학적으로는 2~3삼분기 항암 가능.
