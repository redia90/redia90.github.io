# 약사 협진 — 실전 가이드

## 개요

유방암 환자가 약사 협진을 실제로 활용하기 위한 실전 정보를 담는다. 협진 시점·환자 준비물·새 보충제 추가 동선(카페 팁)·한국 자원·자주 묻는 사례 6건·환자 약 목록 양식·일반약·영양제 Q&A를 포함한다.

---

## 약사 협진 절차

### 시점

- **진단 직후 — 1회**: 기존 모든 약물·보충제 평가
- **새 약제 시작 전 — 매번**: 추가 약물과 기존 약물 상호작용 평가
- **6개월~1년 — 정기**: 누적 약물 재평가
- **부작용 발생 시**: 즉시 약사 협진

### 환자가 준비할 것

1. **현재 복용 약물 전체 목록**:
   - 처방약 + OTC + 한약 + 보충제 + 영양제
   - 용량·복용 시간·시작일
2. **알레르기·부작용 이력**
3. **만성질환 동반** (당뇨·고혈압·갑상선 등)
4. **임신 계획**·[[가임력보존]] 검토 여부

---

## 카페 실전 팁 — 새 영양제·보충제 시작 동선 (TOP50 #17, #28)

새 영양제·한약·보충제를 시작하기 전:

1. **성분표 사진** 촬영 (앞·뒤·옆 라벨 전체)
2. 진료 시 또는 메시지로 **담당의·약사에게 사진 전송**
3. 답변 확인 전까지 **복용 시작 보류**
4. 시작 후 **첫 1주 간수치·증상 변화** 모니터링
5. 의심 증상 시 즉시 중단 + 보고

> 💡 환자들이 가장 자주 빠뜨리는 약: **눈 영양제·홍삼·즙류·한약** — "건강식품이라 약이 아니다"라고 생각해 보고를 누락하는 경향. **모든 입에 들어가는 것은 약**으로 간주.

## 한국 자원

- **대형 암 센터 종양약학과**: 약사 직접 상담 가능 (서울대·아산·삼성·연세 등)
- **약국 약사 상담**: 일반 처방 검토
- **공공기관**:
  - 식약처 의약품안전정보 (drugsafe.mfds.go.kr)
  - 의약품 상호작용 데이터베이스 (DrugInfo)
- **모바일 앱**: Lexicomp·Medscape (영어), 일부 한국 앱

---

## 자주 묻는 약물 검토 사례

### 사례 1: 타목시펜 + 우울증

- **환자**: ER+ 폐경 전, 타목시펜 5년 + 산후 우울
- **평가**: 파록세틴 회피 → 시탈로프람으로 처방 변경
- **결과**: 타목시펜 활성 유지 + 우울증 치료

### 사례 2: CDK4/6 + 자몽

- **환자**: 전이성 ER+ 1차, 키스칼리 처방
- **평가**: 자몽주스 매일 섭취 발견 → 회피 권고
- **결과**: 약제 농도 정상화·QTc 안정

### 사례 3: 4기 환자의 다약제

- **환자**: 70세, 4기 ER+, 페마라+버제니오+골다공증 약+고혈압·당뇨 약+우울증 약
- **평가**: 12가지 약물 — 8가지 상호작용 확인
- **결과**: 일부 약제 변경·시간 조정·정기 모니터

→ [[노인유방암|노인 환자]]에서 특히 중요

### 사례 4: 50대 동반 만성질환 (한국 흔한 패턴)

- **환자**: 52세, ER+ 2기, **고혈압 + 당뇨 + 갑상선기능저하 동반**
- **기존 약**: 암로디핀, 메트포민, 레보티록신 (씬지로이드)
- **새 처방**: 타목시펜 + 졸라덱스 + 칼슘·비타민 D
- **평가**:
  - 암로디핀·메트포민·레보티록신은 타목시펜과 직접 상호작용 ❌ (안전)
  - **레보티록신 공복 복용 + 칼슘은 30분 간격** 필요
  - 타목시펜 → CYP2D6 정상 활성 확인 (특이 약물 없음)
- **결과**: 약 5종 모두 유지, 복용 시간 재구성

### 사례 5: PPI + 카페시타빈 (젤로다)

- **환자**: 60대 ER+ 전이성 + 위염으로 오메프라졸 장기 복용
- **새 처방**: 카페시타빈 (젤로다) — 위 산성 환경에서 흡수
- **평가**: PPI가 카페시타빈 효과를 약 20~30% 감소시킬 수 있음
- **결과**: PPI → H2 차단제 (파모티딘) 변경, 또는 카페시타빈 복용 후 2시간 후 PPI

### 사례 6: 감기·복통 OTC

- **환자**: 40대 ER+ 1기, 항암 중 (TC 3회차) 감기 증상
- **환자 자가 복용**: 종합감기약 + 이부프로펜
- **평가**: 호중구 최저점 시기 → 발열 평가 우선 (응급실 기준), 이부프로펜은 출혈·신장 위험
- **결과**: 종합감기약 중단, 아세트아미노펜 + 38℃ 이상 시 응급실 평가

## 환자가 가져갈 약 목록 양식 (병원 공유용)

진료실·약사 협진 시 휴대폰 메모 또는 종이에 다음 형식으로 정리:

```
[처방약]
1. 약 이름·용량·복용 시간 (예: 타목시펜 20mg, 매일 저녁 9시)
2. ...

[OTC·일반의약품]
1. 약 이름·용량·복용 빈도 (예: 타이레놀 500mg, 두통 시 PRN)
2. ...

[영양제·건강식품]
1. 제품명 + 성분명 (예: 종합비타민·비타민D 1000IU·오메가-3)
2. ...

[한약·보조식품]
1. 제품명 + 성분 (가능한 만큼)
2. ...

[복용 빈도]: 매일 / 주 N회 / 필요 시 (PRN)
[시작일]: YYYY-MM-DD
[특이사항]: 알레르기·과거 부작용
```

## 일반약·영양제 — 카페 환자가 자주 묻는 약 Q&A

항암 중 환자가 자가 판단으로 복용하는 흔한 OTC·영양제 — **모두 의료진·약사 확인 권장**:

| 약·영양제 | 항암 중 권고 |
|------------|---------------|
| **지르텍 (세티리진)·일반 항히스타민** | 일반적으로 안전, 그러나 졸음·구강건조 — 의료진 확인 (#149) |
| **종합감기약** | 호중구 최저점 시기 발열 가림 — 회피, 아세트아미노펜 단독 권장 |
| **이부프로펜·아스피린** | 출혈·신장 위험 — 회피, 아세트아미노펜 우선 |
| **마그밀** (변비) | 처방 안전, 카페 #60·#61에서 흔히 권장 |
| **위장약·넥시움** | 속쓰림에 처방 안전 (#78) |
| **푸룬주스·식이섬유 보충제** | 변비 예방에 안전 |
| **고용량 비타민 C·셀레늄** | 회피 — Ambrosone JNCI 2020 사망률·재발 ↑ |
| **올리브오일·들기름** (수술 전) | 수술 1주 전 중단 (#9·#26·#39) |
| **홍삼·석류·자몽** | 호르몬치료·CDK4/6과 상호작용 — 회피 |
| **한약·약초 달인물** | 간수치 부담 (#116) — 회피·의료진 확인 |
| **고용량 단일 항산화제** | 항암 효과 ↓ 가능성 — 식품 단위로 섭취 권장 |

> ⚠️ **카페 #149 노하우**: 처방약·일반약·영양제 모두 **성분명을 병원에 보여주고 확인**하는 습관이 안전. 약사 협진 시 약 목록 사진 지참.

## 임상적 의의

- 약사 협진 도입 후 응급실 방문 감소·약제 변경 빈도 적정화 (ASCO·한국병원약사회 보고)
- 한국 일부 단일 기관 데이터 — 응급실 방문 20~30% 감소 보고
- OTC 약은 환자가 자가 판단으로 복용하는 경우 多 — 진료 시 매번 "처방전 없이 사 먹는 약 있나요?" 질문 권장
- 카페 환자 빈도 높은 OTC (#149 지르텍 등)도 의료진 확인 습관 — 일반약·영양제·식품 모두 성분명 공유
