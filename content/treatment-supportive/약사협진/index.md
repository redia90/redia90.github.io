# 약사 협진 — 약물 상호작용·다약제 검토

## 개요

유방암 환자는 항암·표적·호르몬·CDK4/6·진통제·정신과 약·만성질환 약 등 **5~10가지 약물**을 동시 복용하는 경우가 많다. 약물 상호작용(특히 **CYP3A4·CYP2D6·QT 연장**)을 놓치면 치료 효과 감소 또는 부작용 증가로 이어진다. 본 페이지는 핵심 상호작용 빠른 참조와 하위 문서 목차를 제공한다.

## 빠른 참조 — 핵심 상호작용 요약

| 약제 | 회피·주의 약물 | 대안 / 조치 |
|------|----------------|-------------|
| **타목시펜** | 파록세틴·플루옥세틴·부프로피온 (CYP2D6 억제) | 시탈로프람·에스시탈로프람·벤라팍신 |
| **CDK4/6 억제제** (입랜스·키스칼리·버제니오) | 자몽·케토코나졸·클라리스로마이신·베라파밀·리팜핀 | CYP3A4 비기질 항생제·항진균제 대안 |
| **리보시클립 (키스칼리)** | 아미오다론·아지스로마이신·시탈로프람 고용량·플루코나졸·온단세트론 고용량 (QTc 누적) | 심전도 모니터링 + 대안 항생제·항구토제 |
| **vepdegestrant** | 에리스로마이신·아미오다론·자몽·리팜핀·세인트존스워트 (QTc+CYP3A4) | EKG 모니터링, 임신 검사·피임 필수 |
| **capivasertib** | 케토코나졸·자몽·세인트존스워트·이뇨제 병용 | 혈당·칼륨 정기 모니터링 |
| **inavolisib** | 자몽·세인트존스워트·강한 CYP3A4 억제제 | 시작 전 HbA1c, 혈당 정기 모니터 |
| **알페리시브** | 고혈당·발진 (자체 부작용) | 메트포르민·항히스타민 사전 준비 |
| **PARP 억제제** | TMP-SMX·기타 골수억제 약물 | 혈구 수치 모니터링 |
| **마약성 진통제** | 진정제·항우울제·디히드로코데인 함유 감기약 | 완화의료팀 약사 협진 |
| **세인트존스워트** | 거의 모든 표적치료 (CYP3A4 강유도) | 즉시 중단 후 약사 협진 |
| **NSAID** (항암 중) | 혈소판 감소 시기 출혈·신독성 누적 | 아세트아미노펜 우선 |
| **PPI** (오메프라졸) | 카페시타빈·일부 TKI 흡수 감소 | H2 차단제 대안 또는 시간 간격 |
| **심바스타틴·로바스타틴** | CDK4/6 억제제 (CYP3A4 경쟁) | 로수바스타틴·프라바스타틴 |
| **베라파밀·딜티아젬** (고혈압약) | CDK4/6·표적치료 농도 상승 | 암로디핀·로사르탄 대안 |
| **와파린** | CYP 변동 약제 시작 시 INR 변화 | INR 정기 모니터링 |

## 임상적 의의

- 약물 상호작용은 **무증상으로 약제 효과를 떨어뜨리는** 가장 흔한 오류
- 자몽 회피·타목시펜 SSRI 선택 같은 단순 정보가 환자 결과에 직결
- 노인·4기 환자는 다약제 위험이 가장 큼 — 약사 협진 필수
- 한약·보충제 자가 도입은 [[보조요법주의|보조요법 판단]] + 약사 협진 필요
- **한국 50대 진단 환자**는 동반 만성질환 비율 높음 — 항암 시작 전 전체 약 점검 필요
- OTC 약은 환자가 자가 판단으로 복용하는 경우 多 — 진료 시 매번 "처방전 없이 사 먹는 약 있나요?" 질문 권장

## 미해결 질문 / 연구 방향

> 💡 한국 환자 다약제 비율·약물 상호작용 빈도
>    → **답변 (2026-05)**: 한국 유방암 환자 약 30~50%가 5+ 약제 복용 — 특히 노인·4기. 임상영양사·약사 협진율은 대형 병원 약 30~50%. 약물 상호작용 빈도 정밀 데이터 부족 — Lexicomp·Micromedex 일부 사용.
>
> 💡 약사 협진 환자 결과
>    → **답변**: ASCO·한국병원약사회 — 약사 협진 도입 후 응급실 방문 ↓·약제 변경 빈도 적정화. 한국 일부 단일 기관 데이터 — 응급실 방문 20~30% 감소 보고.
>
> 💡 AI 기반 약물 상호작용 검토 도구
>    → **답변**: **Lexicomp·Micromedex·Epocrates** 일부 AI 통합. 한국 약사회 디지털 도구 개발 진행. 표준 임상 도입은 진행 중.
