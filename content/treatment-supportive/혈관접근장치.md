# 항암 혈관 접근 장치 — PICC와 케모포트

## 개요
장기간 [[항암화학요법|항암제]] 또는 [[HER2표적치료|표적치료제]]를 정맥에 안전하게 투여하기 위해 사용하는 중심정맥카테터다. 대표적으로 **PICC (말초삽입 중심정맥카테터)** 와 **케모포트 (피하 매립형 정맥 접근 포트)** 두 가지가 있으며, 항암 기간·생활 패턴·관리 부담을 기준으로 선택한다.

## 적응증

- 정맥 자극이 강한 항암제(독소루비신 등) 반복 투여
- 1년 이상 장기 표적치료 ([[HER2표적치료|허셉틴]] 등)
- 잦은 채혈·수액·항생제·수혈 병행이 필요한 경우

## 핵심 내용

### PICC vs 케모포트 비교

| 항목 | 케모포트 (Chemoport) | PICC |
|------|----------------------|------|
| **위치** | 흉벽 피하 (쇄골 아래) 매립 | 상완 정맥 → SVC, 외부 노출 |
| **삽입 시간** | 30~60분 (국소마취 + 진정) | 30~45분 (국소마취) |
| **장소** | 영상의학과·수술실 | 침상 옆도 가능 |
| **사용 시작** | 24~48시간 후 | 즉시 |
| **외부 노출** | ❌ 없음 (수영·목욕 자유로움) | ✅ 외부 카테터 (관리 필요) |
| **관리 주기** | **4주마다** 헤파린 락 | **주 1회** 소독·헤파린 |
| **샤워** | 피부 회복 후 자유 | 방수 커버 + 주의 |
| **사용 기간** | **1년 이상 장기** (표적치료) | 수주~6개월 (단기 항암) |
| **혈전 위험** | 1~5% (낮음) | 5~15% (높음) |
| **감염 위험** | 낮음 (피부 보호) | 높음 (외부 노출) |
| **비용 (산정특례 후)** | 20~50만 원 | 10~30만 원 |
| **제거** | 외래 시술 (15~30분) | 침상 옆 즉시 제거 |
| **외형 흔적** | 흉벽 작은 흉터 + 디스크 윤곽 | 거의 없음 (제거 후) |
| **주의 신호** | 발적·주입 저항·발열 | 발적·팔 부종·열감·혈전 |

### 환자 상황별 선택 가이드

어느 장치가 더 적합한지는 **항암 일정·생활 패턴·환자 선호**의 조합:

| 상황 | 권장 | 이유 |
|------|------|------|
| **TCHP 6사이클 + 1년 허셉틴 유지** | 케모포트 | 1년+ 장기 — 관리 부담 낮음 |
| **AC 4회 + 탁솔 4회 (TC·AC-T, 약 6개월)** | 케모포트 또는 PICC | 환자 선호에 따라 |
| **선행 항암 후 수술 + 보조 항암** | 케모포트 | 누적 1년 이상 사용 |
| **삼중음성 1년 치료 (KEYNOTE-522 + 키트루다)** | 케모포트 | 면역항암 1년 |
| **CDK4/6 진행 후 단기 화학요법** | PICC 또는 PIVC | 짧으면 PIVC도 가능 |
| **수영·해수욕 좋아하는 환자** | 케모포트 | 외부 노출 없음 |
| **운동 활발 (테니스·골프·등산)** | 케모포트 | 팔 움직임 자유 |
| **삽입 부위 흉터 거부** | PICC | 외형 흔적 더 적음 |
| **혈전 과거력** | 케모포트 | PICC가 혈전 위험 ↑ |
| **유방 수술 부위 동측** | **반대측** 선택 | 림프부종 위험 회피 |

> 💡 카페에서 가장 자주 나오는 후회: "**1년 치료라면 처음부터 케모포트가 나았다**" — PICC를 단기로 시작했다가 치료 연장되어 6개월 후 케모포트로 전환한 사례 多.

### 응급 신호 — 즉시 병원 문의

다음 증상은 카테터 관련 감염·혈전·기능 이상을 시사한다:

- 삽입 부위 발적, 부종, 분비물
- 카테터 통증
- **헤파린 주입 저항** (밀어 넣어지지 않음)
- 관 파손, 외부 노출 길이 변화
- 38도 이상 열, 오한
- 팔(PICC) 부종, 무거움, 색 변화 → 혈전 의심

→ [[항암화학요법]] 호중구 감소 시기와 겹치면 응급실 평가가 필요할 수 있다.

### 시술 절차

#### 케모포트 삽입
1. **장소**: 인터벤션 영상의학과 또는 외과 수술실
2. **마취**: 국소마취 + 진정제 (대부분 외래 또는 1박 입원)
3. **삽입**:
   - 쇄골 아래 피부 절개 (2~3cm)
   - 쇄골하정맥 또는 내경정맥 통해 카테터 진입
   - 카테터 끝을 SVC-우심방 접합부에 위치
   - 포트(작은 디스크)를 흉벽 피하에 매립
   - 봉합·드레싱
4. **시간**: 30~60분
5. **확인**: 흉부 X-ray로 위치·기흉 확인
6. **회복**: 당일~익일 퇴원, 7~10일 후 봉합사 제거
7. **사용 시작**: 보통 24~48시간 후

#### PICC 삽입
1. **장소**: 인터벤션 또는 침상 옆 (간호사·전담 팀)
2. **마취**: 국소마취만
3. **삽입**:
   - 상완 정맥(주로 basilic vein)을 초음파로 확인
   - 카테터 삽입·전진 → SVC 위치까지
   - 외부 길이 측정·고정
4. **시간**: 30~45분
5. **확인**: X-ray 또는 ECG 가이드로 끝 위치 확인
6. **사용 시작**: 즉시 가능

### 한국 비용 (참고, 2026)

- **케모포트 삽입**: 산정특례 적용 시 본인부담 약 20~50만원 (병원·재료별 차이)
- **PICC 삽입**: 산정특례 적용 시 약 10~30만원
- 비급여 의료재료 포함 시 추가 가능
- **유지 관리**: 외래 진료비 + 드레싱·헤파린 (월 단위 누적)
- **합병증 처치** (혈전·감염): 산정특례 5%

### 일상 관리 팁

- 삽입 후 며칠은 무리한 팔 사용·무거운 짐 들기 회피
- 샤워 시 PICC는 방수 커버 사용
- 가족·간병인에게 외부 노출 길이를 미리 알려두고 변화 시 즉시 보고
- 환자 본인이 발열·발적·통증 일지를 기록

#### 케모포트 일상 관리 체크리스트

**삽입 직후 (1~2주)**:
- 삽입 부위 봉합사 제거 전까지 물·땀 노출 회피
- 무거운 짐 들기 회피
- 일시적 통증·멍은 정상 — 진통제로 관리

**정착 후 (1개월~)**:
- **샤워·목욕·수영 자유** (단, 사용 직후 24시간은 일반 샤워)
- 팔 움직임·운동 자유 (단, 직접 충돌 회피)
- 액세서리 (목걸이) 마찰 회피
- 안전벨트가 직접 닿으면 쿠션 사용
- **4주마다 정기 헤파린 락** — 외래 또는 가정형 방문 간호

**자가 점검 (매일 확인)**:
- 디스크 부위 발적·열감·종창
- 새로 생긴 통증
- 디스크가 이동한 느낌
- 피부 변색

#### PICC 일상 관리 체크리스트

**매일 점검**:
- 외부 카테터 길이 (처음 기록한 cm와 비교)
- 삽입 부위 발적·분비물·열감
- 팔 부종·색 변화·뻐근함

**주간 관리 (대부분 방문 간호 또는 외래)**:
- 드레싱 교환 (1주에 1회 또는 더럽혀지면 즉시)
- 헤파린 락 (5~10mL 식염수 + 헤파린 100~300 IU/mL)
- 캡 교환 (1주에 1~2회)

**금기 활동**:
- ❌ **혈압 측정** PICC 측 팔 (반대팔 사용)
- ❌ **채혈** PICC 측 팔 정맥
- ❌ **수영·해수욕·뜨거운 욕조** (외부 노출 위험)
- ❌ 무거운 짐 들기, 격렬한 팔 운동
- ❌ 자가 절단·제거 시도

### 사용 중단·제거 동선

#### 케모포트 제거 시점
| 상황 | 제거 권고 |
|------|------------|
| 항암·표적치료 1년 완료 (HER2+ 표준) | **마지막 사용 1~2개월 후** 제거 또는 추가 치료 시 유지 |
| 만성 감염 (CRBSI 반복) | 즉시 제거 + 항생제 |
| 카테터 파손·기능 상실 | 제거 후 새 카테터 |
| 환자 요구 (외형·심리) | 의료진과 상의 |
| **재발 위험 고위험** | 추가 치료 가능성 — 유지 또는 환자 의사 우선 |

#### 제거 절차 (케모포트)
1. 외래 시술 (영상의학과 또는 외과)
2. 국소마취
3. 흉벽 절개 → 카테터·포트 제거
4. 봉합 (수술 시간 15~30분)
5. 흉부 X-ray (드물게 합병증 확인)
6. 당일 귀가
7. 봉합사 제거 7~10일 후
8. 잔여 흉터는 시간 지나며 옅어짐

#### 제거 후 관리
- 1~2주 무리한 팔 운동 회피
- 흉터 보습·자외선 차단
- 외형 변화 신경 쓰이면 [[유방재건수술|재건 수술과 같은 날 제거]] 가능

> 💡 카페 경험담: 카테터 제거 후 "마지막 치료가 끝났다"는 심리적 의미가 크다는 후기 多. 가족·보호자가 함께 동행하는 경우도 흔함.

### 진료실에서 환자가 물어볼 질문

PICC·케모포트 결정 전:

1. 제 항암·표적치료 **총 기간**은 어느 정도로 예상되나요?
2. 1년 이상이면 케모포트가 더 나은가요?
3. 제 직업·운동 패턴을 고려할 때 어느 게 편한가요?
4. 수술측 vs 반대측 어디에 삽입하나요?
5. 헤파린 락 주기는? 가정형 간호 가능한가요?
6. 감염·혈전 응급 신호 — 본 병원 연락처는?
7. 제거 시점은 누가 결정하나요?
8. 제거 흉터·통증·외형 변화는 어느 정도인가요?

### 카테터 관련 혈전 (CRT, Catheter-Related Thrombosis)

PICC·케모포트 합병증 중 가장 우려되는 것:

**빈도**:
- PICC: **5~15%** (증상 있는 혈전), 무증상 포함 시 30~70%
- 케모포트: 약 **1~5%** (PICC보다 낮음)

**위험 인자**:
- 유방암 자체가 혈전 위험 증가
- [[항암화학요법|항암제]] 일부 (특히 시스플라틴·5-FU·CDDP)
- 좌측 PICC가 우측보다 위험 ↑ (해부학적 이유)
- 카테터 끝 위치가 SVC 상부 (이상적 위치는 SVC-우심방 접합부)
- 이전 혈전 병력·비만·면역기동성 저하

**증상**:
- 팔의 부종·무거움·뻐근함 (PICC 측)
- 색 변화 (창백·청색)
- 안면·목 부종 (광범위 SVC 혈전)
- 호흡곤란·흉통 (폐색전 위험 — 응급)

**진단**:
- 상지 정맥 도플러 초음파 — 1차 검사
- CT 정맥조영술 — 광범위 혈전 의심 시
- D-dimer는 암 환자에서 위양성 많아 단독 사용 어려움

**치료**:
- 항응고제 (LMWH·DOAC) 3개월 이상
- 카테터 제거는 보통 불필요 — 항응고제 + 카테터 유지 가능 (CLOT 임상 등)
- 단, 감염 동반·기능 상실·심각한 증상 시 제거

**예방**:
- 항응고제 일률 예방은 권고되지 않음 (CAVENT·SAVE-ONCO 임상)
- 고위험 환자에서 개별 평가
- 카테터 끝 적정 위치 확인 (삽입 시 영상 확인)

### 합병증 종합

| 합병증 | 빈도 | 대처 |
|--------|------|------|
| **CRT (카테터 관련 혈전)** | PICC 5~15%, 포트 1~5% | 도플러 → 항응고제 |
| **카테터 관련 감염 (CRBSI)** | 100 카테터-일당 0.5~2건 | 혈액 배양 → 항생제, 심하면 제거 |
| **기계적 합병증** (관 막힘·파손·이탈) | 5~10% | 영상 평가, 일부는 교체 |
| **기흉** (포트 삽입 시) | <1% | 흉부 X-ray, 대부분 보존 치료 |
| **혈관 외 누출 (extravasation)** | 드묾 | 즉시 사용 중단, 약제별 대처 |
| **카테터 부위 통증** | 일시적 다수 | 보존 치료, 지속 시 평가 |

### 카페 환자 경험 — 케모포트 운영 실전 (TOP50 2페이지 #43 등)

**케모포트 + TCHP 6차 막항 — 운영 패턴 (#43)**:
- 막항 당일 일정: 혈액검사 → 진료 → **심장초음파** (TCHP 누적 심독성 확인) → 항암 → **부종 이뇨제·엔커버 처방** → **뉴라스타** (호중구 부스터) → 요양병원 입원
- **막항 이후에도 표적치료(허셉틴·퍼투주맙) + 수술이 남는 경우 케모포트 유지**가 표준
- 표적치료 1년 완료 시점에 제거 결정

**환자가 자주 묻는 결정 (카페 패턴)**:
| 질문 | 카페 회원 다수 결론 |
|------|---------------------|
| 막항 후 바로 제거? | 표적치료 남으면 **유지** — 1년 후 제거 |
| 수술과 같은 날 제거? | 가능 — 일정 효율, 마취 1회로 끝 |
| 4기 환자는 제거? | 보통 **유지** — 다음 약제 가능성 |
| 제거 후 흉터는? | 시간 지나며 옅어짐 — 1~2년 후 거의 안 보임 |

**케모포트 일상 운영 노하우**:
- **안전벨트가 디스크에 직접 닿으면 쿠션 사용** — 자극 누적이 통증 원인
- **목걸이·브래지어 끈** 위치 조정 — 디스크 위 마찰 회피
- 4주 헤파린 락 — 일정 알람 설정 (놓치면 막힘 위험)
- 사용 직후 24시간은 일반 샤워 (수영·욕탕은 그 이후)

> 💡 **카페 회원 #43 노하우**: "TCHP는 막항 후에도 1년 표적치료 + 수술 + 방사선이 남을 수 있으니 케모포트 제거 시점을 너무 빨리 결정하지 말기. 의료진과 다음 일정 전체를 그려보고 결정."

### 한국 보험 적용

- **케모포트 삽입**: 산정특례 적용 시 본인부담 일부
- **PICC 삽입**: 외래 또는 입원 시술 — 보험 적용
- **유지 관리** (헤파린 플러시·드레싱): 외래 진료 보험 적용
- **혈전 발생 시**: 항응고제·도플러·CT 모두 보험 적용
- **제거**: 보험 적용
- 산정특례 환자는 본인부담 5%

## 임상적 의의

- 정맥 자극이 강한 약제의 반복 투여 시 말초 정맥 손상을 줄여 치료 지속성을 보장
- 장기 표적치료 환자에게 케모포트는 일상 자유도와 관리 부담의 균형점을 제공
- 카페 경험담에서 가장 자주 공유되는 응급 사유 중 하나가 **카테터 관련 발열·발적**이라 환자 교육이 매우 중요
