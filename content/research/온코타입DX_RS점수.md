# 온코타입DX와 RS 점수 — 항암 여부 결정 검사

> 💡 **상위 페이지**: 온코타입DX는 [[유전자발현프로파일링|5종 유전자 발현 검사]] 중 하나다. 다른 검사(MammaPrint·Prosigna·EndoPredict·BCI)와의 비교·임상 의사결정 흐름은 [[유전자발현프로파일링]] 상위 페이지에서 확인.

## 개요
**온코타입DX(Oncotype DX)** 는 종양 조직에서 21개 유전자의 활성도를 분석해 **재발점수(Recurrence Score, RS)** 를 0~100점으로 산출하는 검사다. 주로 **ER 양성 / HER2 음성 / 림프절 음성** 또는 일부 림프절 양성 초기 유방암에서 [[항암화학요법|항암 추가 여부]]를 결정하는 데 활용된다. Ki67 같은 단일 지표보다 신뢰도가 높아, Ki67이 50~60%여도 RS 13점이면 항암을 피할 수 있는 사례가 실제로 보고된다.

## 연구 배경

전체 유방암의 70~80%가 ER 양성 / HER2 음성이지만, 이 환자군의 상당수는 호르몬 치료만으로 재발이 잘 통제된다. 과거에는 종양 크기·림프절·Grade·Ki67만으로 항암 여부를 결정해 **불필요한 항암을 받는 환자 비율**이 컸다. 온코타입DX는 종양의 유전자 발현 프로파일로 개인별 재발 위험을 정량화해 항암의 이득이 큰 환자만 선별하는 도구로 개발되었다.

## 방법론

### 21개 유전자 구성

| 그룹 | 유전자 | 역할 |
|------|--------|------|
| 기준점(reference) | ACTB, GAPDH, RPLPO, GUS, TFRC | 정규화 기준 |
| 분열 관련 | **Ki67, STK15, Survivin, CCNB1 (cyclinB), MYBL2** | 종양 증식 |
| 침윤 관련 | MMP11, CTSL2 | 침습성 |
| HER2 관련 | HER2, GRB7 | HER2 시그널 |
| 에스트로겐 관련 | ER, PGR, BCL2, SCUBE2 | 호르몬 반응성 |
| 초기 유방암 | GSTM1, CD68, BAG1 | 면역·기타 |

### RS 점수 산출
21개 유전자의 발현 수준을 가중합 → 0~100점 사이의 단일 점수로 변환.

> 💡 **Ki67만으로 항암 여부를 결정하지 말 것**. 같은 종양 안에서도 부위별 Ki67이 다르게 염색되며 실험자 숙련도에 따른 오차가 있다. RS 점수는 21개 유전자를 종합하므로 단일 지표보다 신뢰도가 높다.

## 주요 결과 — TAILORx 기반 항암 권고 기준

대규모 TAILORx 임상시험(2018 NEJM)을 근거로, RS 점수 + 나이를 종합한 항암 추가 권고:

| RS 점수 | 나이 | 항암 권고 |
|---------|------|-----------|
| ≤ 25점 | **50세 이상** | 항암 이득 1% 이내 → **항암 패스** |
| ≥ 26점 | **50세 이상** | 항암 권고 |
| 0~15점 | **50세 미만** | 항암 패스 |
| 16~20점 | **50세 미만** | 항암 또는 셀 호르몬 치료(인위 폐경 유도) 중 선택 |
| ≥ 21점 | **50세 미만** | 항암 적극 권고 |

> ⚠️ 50세 기준은 폐경 전후 차이와 관련. 폐경 전 여성에서는 동일 RS 점수라도 항암의 상대적 이득이 더 클 수 있다.

### 실제 사례 패턴 (카페 경험담)
- Ki67 50~60%였지만 RS 점수 13점으로 항암 패스한 사례 보고됨 → Ki67과 RS는 다른 정보를 본다는 증거

### RxPONDER 임상 (NEJM 2021) — 림프절 양성 1-3개 폐경 전후 차이

**대상**: ER+/HER2-/림프절 양성 1-3개, RS ≤25, 5,083명

**핵심 결과**:

| 그룹 | 5년 무침습 질병 생존율 (iDFS) | 항암 이득 |
|------|-------------------------------|-----------|
| **폐경 후** + 호르몬 단독 | 91.6% | 항암 추가해도 0.97% 차이 (HR 0.97) |
| **폐경 후** + 호르몬 + 항암 | 92.6% | → **이득 없음** |
| **폐경 전** + 호르몬 단독 | 89.0% | — |
| **폐경 전** + 호르몬 + 항암 | 93.9% | **+4.9% 이득** (HR 0.60) |

> 💡 같은 RS ≤25 + 림프절 양성 1-3개라도 **폐경 상태**가 항암 추가 여부를 가른다.

**임상적 함의**:
- **폐경 후** 림프절 양성 1-3개 + RS ≤25 → 호르몬 단독으로 안전
- **폐경 전** 림프절 양성 1-3개 + RS ≤25 → **항암 이득 있음** — 또는 OFS + AI 강화 옵션
- 항암 추가 효과가 폐경 전에서 큰 이유는 추정되며, **OFS (난소 기능 억제)** 효과의 일부일 가능성 (난소 기능 보존된 환자에서 항암이 일시적 폐경 유도 효과)

**OFS 대안 검토**:
- 폐경 전 RS ≤25 + 림프절 양성 환자는 **항암 vs OFS + AI** 선택지
- 부작용·삶의 질 차이 고려
- [[가임력보존]] 계획 환자는 [[호르몬치료|POSITIVE 연구]] 기반 호르몬 치료 일시 중단도 후속 옵션

### TAILORx + RxPONDER 통합 컷오프 (2026 기준)

| 림프절 | 폐경 | RS | 권고 |
|--------|------|-----|------|
| 음성 | 50세 이상 | ≤25 | 항암 패스 |
| 음성 | 50세 이상 | ≥26 | 항암 권고 |
| 음성 | 50세 미만 | 0~15 | 항암 패스 |
| 음성 | 50세 미만 | 16~20 | 항암 or OFS+호르몬 선택 |
| 음성 | 50세 미만 | ≥21 | 항암 권고 |
| **양성 1-3개** | **폐경 후** | ≤25 | **항암 패스** (호르몬 단독) |
| **양성 1-3개** | **폐경 전** | ≤25 | **항암 권고** 또는 OFS+AI |
| 양성 1-3개 | — | ≥26 | 항암 권고 |

## 임상적 함의

- **불필요한 항암 회피**: ER+/HER2- 환자의 약 **50% 이상**이 RS ≤25점에 해당하며 항암 없이 [[호르몬치료]]만으로 충분
- **항암 결정 권한 이동**: 종양 크기·Grade 위주의 정성 판단에서 유전자 발현 기반 정량 판단으로
- **온코타입DX 검사 시점**: 수술 후, 치료 시작 전에 시행해야 항암 결정에 활용 가능
- **림프절 양성 1~3개**: 70개 유전자 검사인 **맘마프린트**가 보조 옵션으로 언급됨 → [[유방암진단체계]] 참조

## 한계점

- HER2 양성 또는 ER 음성 환자에는 권고되지 않음
- 매우 큰 종양(>5cm), 다발성, 염증성 유방암에는 검증 부족
- 검사 비용 (한국 약 300~400만원, 보험 일부 적용)
- 임상의의 종합 판단이 여전히 필요 — RS는 도구이지 결정자가 아님

## RSClin — 임상 변수 + RS 통합 도구

### 개요
RSClin은 **RS 점수만으로 부족한 영역** (특히 종양 크기·림프절 상태와의 결합)을 보완하는 통합 예측 도구다. Sparano et al. (JCO 2021)이 검증.

### 입력 변수
- RS 점수 (0~100)
- 종양 크기 (cm)
- 종양 Grade (1~3)
- 환자 나이
- (림프절 음성 환자에 사용)

### 출력
- **10년 원격 재발 위험률 (%)**
- 항암 추가 시 절대 이득 (%)
- 시각화된 그래프

### 임상적 함의
- **RS 단독 16~20점 회색지대**에서 더 정밀한 의사결정 도구
- 임상 위험도와 분자 위험도 통합 — TAILORx 기반 권고 정제
- 환자와 결과 공유 시 시각 자료로 활용 (informed decision)

### 사용 가능 도구
- RSClin Calculator (Exact Sciences 제공, 의료진용)
- 일부 임상 결과는 학술 데이터로 검증, 한국 임상에서는 부수적 활용

### 한국 적용
- 별도 보험 항목 아님 — 의료진 도구
- Oncotype DX 검사 결과지에 일부 통합되어 제공되는 경우
- 환자 결정에 활용은 의료진 판단에 따라

> 💡 RSClin은 **RS 점수의 후속 정제 도구**이며 단독 검사가 아니다. 21유전자 검사 결과가 있어야 사용 가능.

## 한국 임상 가이드라인 / 적용 현황
- 보험 일부 적용 (림프절 음성 ER+/HER2- 초기 유방암 기준)
- 검사 기관: 미국 Genomic Health (현 Exact Sciences)로 검체 송부
- 결과 소요: 약 2주
- 진료 전 질문 목록에 검사 가능 여부·시기를 넣어두는 것이 카페 회원 노하우로 자주 언급됨

## TAILORx 12년 추적·BCI 비교 (2026-06 갱신)

### TAILORx 12년 추적 (Sparano NEJM 2024)

- **RS는 5년 이내 재발 예측력 우수**
- **5~10년 후기 재발 예측력 약함** — RS 낮음(≤10)에서도 후기 재발 발생 가능
- ER+ 후기 재발 (>5년)은 **휴면 세포 재활성화** 기전 — RS만으로 예측 한계
- → [[휴면암세포_재발메커니즘]] 통합 평가 필요

### BCI vs RS — 후기 재발 예측 비교

| 항목 | Oncotype DX (RS) | BCI (Breast Cancer Index) |
|------|--------------------|----------------------------|
| **검사 시점** | 수술 직후 (보조 항암 결정) | 5년 호르몬치료 후 (연장 결정) |
| **예측 영역** | **0~5년 재발 + 항암 이득** | **5~10년 후기 재발 + 호르몬 연장 이득** |
| **임상 활용** | 항암 추가 여부 | 호르몬치료 5년 → 10년 연장 여부 |
| **유전자 수** | 21개 | 11개 + H/I ratio |
| **한국 보험** | 일부 적용 (림프절 음성) | 비급여 (약 100~150만 원) |
| **NCCN 권고** | Category 1 (항암 결정) | Category 2A (연장 결정) |
| **상호 보완** | 보완적 — 같은 환자에서 두 시점 다른 결정 도구 | 보완적 |

> 💡 **카페 회원 활용 패턴**: 수술 직후 RS로 항암 결정 → 5년 호르몬치료 후 BCI로 연장 결정. 두 검사는 다른 시점·질문에 답한다.

### RxPONDER 2026 후속 — 폐경 전 N1 환자

ASCO 2026·SABCS 2025 후속 데이터:
- 폐경 전 RS ≤25 N1 환자에서 **항암 + 호르몬 vs OFS + AI** 비교 분석 진행 (SOFT/TEXT 사후 분석)
- 두 옵션이 **iDFS 동등할 가능성** 시사 — NSABP B-60 진행 중 (2027 결과 예상)
