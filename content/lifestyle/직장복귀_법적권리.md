# 직장 복귀·법적 권리 — 한국 근로기준·차별 금지

## 개요
유방암 진단·치료 중 환자의 직장 권리는 한국 **근로기준법·산업재해보상보험법·장애인차별금지법** 등으로 보호된다. 그러나 현실에서 차별·해고·복직 거부 사례가 보고되며, 환자가 본인 권리를 알고 활용해야 한다. [[보험행정|행정 전반]]은 별도 페이지에 정리되어 있고, 본 페이지는 **근로·법적 권리 중심**.

## 핵심 내용

### 1. 병가·연차·휴직 — 한국 근로기준

**병가 (질병 휴가)**:
- 근로기준법상 의무 규정 없음 — **회사 취업규칙에 따름**
- 대형 기업·공공기관 다수 운영 (보통 30~90일 유급·이후 무급)
- 중소기업은 제한적

**연차 유급휴가**:
- 1년 80% 이상 출근 시 15일 (1년 미만 매월 1일)
- 치료·검진에 자유롭게 활용 가능
- 미사용 연차 수당 청구 가능

**휴직**:
- **질병 휴직**: 회사 취업규칙에 따름 — 보통 1~3년 가능
- **무급 휴직**도 가능
- 4대 보험 일부 유지 (회사·근로자 협의)

**근로기준법 제74조 (생리휴가)**:
- 여성 근로자에게 월 1일 무급 생리휴가
- 항암 중 휴식 활용 가능

### 2. 차별 금지 — 법적 보호

**장애인차별금지법 (2007)**:
- 암 환자도 일정 기준 충족 시 **장애인으로 분류**
- 채용·승진·해고에서 차별 금지
- 합리적 편의 제공 의무

**남녀고용평등법**:
- 임신·출산·질병 사유 해고 금지
- [[임신중유방암_PABC|PABC 환자]] 추가 보호

**근로기준법 제23조**:
- 정당한 이유 없는 해고 금지
- 질병 치료 중 해고는 부당해고 가능성

### 3. 산업재해 인정 가능성

- **방사선 노출 직업** (의료기사·간호사 등) 일부 유방암 산재 인정 사례
- **야간 교대 근무 + 유방암 위험**: IARC Group 2A — 일부 산재 신청 가능
- 근로복지공단 신청 — **인과 입증 필요**

#### 한국 유방암 산재 인정 사례 (참고)

| 직군·노출 | 인정 사례 |
|----------|-----------|
| **간호사·의료기사 (야간 근무 + 방사선)** | 일부 인정 — 누적 노출 입증 |
| **항공 승무원 (장기 야간·우주방사선)** | 일부 임시 인정 |
| **야간 교대 근무자 (10년+)** | IARC 2A 기준 — 인정 시도 증가 |
| **화학·살충제·페인트 노출자** | 일부 — 입증 어려움 |
| **방사선 시설 종사자** | 비교적 인정 |

**산재 신청 시 준비 자료**:
- 직업력 (근무 기간·시간·노출 종류)
- 의학적 인과 (산업의학과 자문)
- 동료 사례 (같은 직장 다른 환자)
- 야간 근무자: 야간 시간 누적 (10년 이상 권장)

**신청 동선**:
1. **근로복지공단** (1588-0075) 산재 신청
2. **직업환경의학과** 전문의 자문 (서울대·서울아산·세브란스 등)
3. **노무사·변호사** 검토 (산재 전문)
4. 거부 시 **재심사 청구** → 행정소송

> 💡 산재 인정 시 **치료비 100% + 휴업급여 + 장해급여** — 환자 본인부담 ❌ 큰 차이

### 4. 복직 — 점진적 복귀 모델

**ASCO 권고**: 점진적 복귀 (Phased Return)
- 1~2주: 4시간/일
- 3~4주: 6시간/일
- 5주~: 8시간/일

**한국 적용**:
- 회사와 사전 협의 필수
- **재택근무·시간제·반차** 조합 가능
- 항암 회차별 컨디션 패턴 ([[항암화학요법]]) 기록 → 출근 가능일 예측

### 5. 직장 공유 범위

- 회사에 알릴 범위 — 환자 본인 결정
- 직속 상사·인사팀 정도가 일반적
- 동료에게는 본인 선택
- **차별 위험** 있으면 인사팀에만 알리고 합리적 편의 요청

| 임신·출산·질병 차별 금지 | 남녀고용평등법 | 차별 시 고용노동부 진정 |

### 8-1. 50대 진단 환자 — 직장 복귀 핵심 시나리오

한국 유방암 진단 평균 52세 — 50대 진단 환자 직장 복귀의 흔한 패턴:

| 시나리오 | 패턴 | 대응 |
|----------|------|------|
| **정규직 + 대형 기업** | 병가 + 연차 + 휴직 충분 | 인사팀에만 알리고 합리적 편의 |
| **정규직 + 중소기업** | 병가·휴직 제한적 | 노동위·국가인권위 활용 가능성 |
| **계약직** | 재계약 거부 위험 | 차별 가능성 — 증거 확보 |
| **자영업·프리랜서** | 일감 직접 조절 가능 | 일감·계약 조정 |
| **공무원·교사** | 휴직 제도 강함 | 법정 휴직 활용 |
| **간호사·의료직** | 항암 중 감염 위험 | 부서 이동·재택·휴직 |
| **육체노동** | 림프부종 위험 (수술 측 팔) | 부서 이동·작업 강도 조정 |

### 8-2. 가족돌봄휴직·간병 휴직

**가족돌봄휴직** (남녀고용평등법):
- 가족이 환자라면 본인이 돌봄 휴직 가능
- 연 90일·횟수 무제한 (회사 협의)
- 무급 — 회사가 일부 지급 시 인정

**가족돌봄휴가**:
- 연 10일 단위 (분할 가능)
- 단기 응급 상황 (수술·검사·항암 동행 등)

**남편·자녀·부모 활용 가능**:
- 유방암 환자 본인뿐 아니라 가족이 활용
- 회사에 사전 신청 + 의사 진단서

### 8-4. 실제 복직 시 환자 체크리스트

**복직 전 (1~2주)**:
- [ ] 의사 소견서 (복직 가능·근무 시간·주의사항)
- [ ] 회사 인사팀과 사전 회의 (재택·시간제·휴직 만료일)
- [ ] 동료에게 알릴 범위 결정
- [ ] 의무기록·진단서 사본 보관
- [ ] 항암·방사선 일정 = 회사 일정 동기화

**복직 직후 (1~2개월)**:
- [ ] 점진적 시간·강도 적응 (4h→6h→8h)
- [ ] 회식·야근 강제 면제 요청
- [ ] 화장실·휴식 시간 보장
- [ ] 컨디션 변화 일기 기록
- [ ] 동료 차별·괴롭힘 시 즉시 인사팀 보고

**장기 (3~6개월~)**:
- [ ] 합리적 편의 지속 협의
- [ ] 산정특례·실비 청구 정리
- [ ] 정신건강 (우울·번아웃) 자가 평가
- [ ] 환우 자조 그룹 참여

### 9. 부당해고 구제 절차 — 단계별

| 단계 | 채널 | 기한 | 비고 |
|------|------|------|------|

| 2단계 | **지방노동위원회** 부당해고 구제 신청 | **해고일 후 3개월 이내** | 강제 효력 있음 |
| 3단계 | 중앙노동위원회 재심 | 지노위 판정 후 10일 이내 | — |
| 4단계 | 행정소송 (서울행정법원) | 재심 후 15일 이내 | — |

| 보완 | 국가인권위원회 진정 (1331) | 차별 발생 후 1년 이내 | 권고 효력 |

- 노무사 선임 가능 — **승소 시 회사 부담**
- 입증 책임: 회사 측 (정당 사유 입증)

### 10. 합리적 편의 제공 — 구체 사례

장애인차별금지법상 회사가 제공해야 할 **합리적 편의** 예시:
- 항암 회차일 휴가·재택근무 허용
- 화장실 가까운 자리·기립 시간 단축
- 회의 일정 컨디션 좋은 시간대 배치
- 회식 강제 면제 (호중구 감소 시기)
- 사무용 의자·책상 높이 조정
- 통근 셔틀 이용 우선 배정
- 가발·모자 착용 허용

> 💡 합리적 편의 요청은 **서면** (이메일 등) 으로 — 거부 시 차별 근거.

### 11. 자영업·프리랜서

- 근로기준법 적용 제외 → 별도 권리 체계
- **국민건강보험 임의계속가입** — 직장 그만둔 뒤 3년간 직장보험료 유지 가능
- **국민연금 납부 예외** — 치료 기간 유예 신청
- **건강보험료 경감** — 산정특례·중증환자 신청
- 폐업 시 **자영업자 고용보험** 가입 이력 있으면 실업급여 가능
- 일감 거절·계약 해지 시 → 차별로 보기 어렵지만 **국가인권위 진정** 가능

### 12. 4대 보험 유지 — 휴직 중

| 보험 | 휴직 중 처리 |
|------|---------------|
| **건강보험** | 유지 — 회사·근로자 분담 협의 |
| **국민연금** | 납부 예외 신청 가능 (소득 없음 사유) |
| **고용보험** | 유지 — 향후 실업급여 자격 보전 |
| **산재보험** | 보험료 면제 — 사고 발생 시 보호 유지 |

- 휴직 중 4대 보험료 본인 부담분 회사 대납 후 복직 시 정산 케이스 多
- 회사와 **사전 서면 합의** 권장

### 13. 실업급여·재취업 지원

**실업급여 자격**:
- 고용보험 가입 180일 이상
- 비자발적 이직 (해고·계약만료·권고사직)
- 적극적 재취업 노력

**암 환자 특례**:
