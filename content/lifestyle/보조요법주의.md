# 유방암 보조요법·민간요법 주의사항

## 개요
유방암 환자 커뮤니티에는 표준치료 외 다양한 보조요법·민간요법 경험담이 공유된다. 이 페이지는 자주 언급되는 항목과 **위험 신호**를 정리한다. 핵심 원칙은 (1) 표준치료를 지연·중단시키는 선택을 피한다, (2) 약물 상호작용·간독성·출혈 위험을 점검한다, (3) "누군가에게 효과 있었다"가 "내 치료에 안전하다"를 의미하지는 않는다는 것이다.

## 핵심 내용

### 분리해서 봐야 할 보조요법 항목

다음 항목들은 원문에 경험담으로 포함되어 있으나, 의학적 근거·상호작용·간수치·치료 지연 위험이 있어 **담당의 확인 전 실행하지 않는다**.

| 분류 | 항목 |
|------|------|
| 구충제 | 메벤다졸, 알벤다졸 등 |
| 고용량 영양제 | 고용량 비타민, 고용량 멜라토닌, 토코트리에놀, 커큐민, **후코이단·AHCC, DIM, MSM 보충제**, **비타민 C 메가도즈** |
| 항산화제 (항암 중) | 셀레늄·고용량 비타민C·비타민 주사 — **재발률 41%·사망률 40% 증가 연구 (#487613)** |
| 정맥주사·물리치료 | 미슬토, 자닥신, 고주파, 고압산소, 광면역치료 등 |
| 농축 건강식품 | 죽염, 각종 즙·액기스, 고농축 건강식품, **녹즙(케일·신선초·민들레 등)**, **약초 달인물(부처손·개똥쑥·겨우살이·상황·차가버섯)** |
| 한방·자연요법 | 항암 중 임의 한약, 침치료, **자연치유 단독 선택**, 울금·강황 환·분말 (식품 형태와 구분) |
| 발효식품 (호중구 감소 시기) | 콤부차, 고용량 유산균 생균, 일부 발효식품 |

### 판단 기준 (4가지)

1. **표준치료를 지연·중단**하게 만드는 선택은 피한다
2. 항암제·표적치료제·호르몬제와 **상호작용 가능성**이 있는지 확인
3. 피검사, **간수치**, 신장기능, 혈액응고, 출혈 위험을 함께 본다
4. "누군가에게 효과 있었다"와 **"내 치료에 안전하다"는 별개**로 본다

### 응급 신호 (보조요법 도중)

- 38도 이상 열이 3시간 이상 지속
- 황달, 짙은 소변색, 우상복부 통증 (간기능 의심)
- 멍·코피·잇몸 출혈 (혈액응고 영향)
- 호흡곤란, 흉통 (혈전·심장 부작용)
- 카테터·[[혈관접근장치|포트]] 부위 발적·통증

→ 즉시 병원 문의. [[항암화학요법]]의 응급 기준 참조.

### 호르몬 양성에서 주의

- 홍삼·석류 등 식물성 에스트로겐 함량 식품은 [[유방암분자서브타입|호르몬 양성]]에서 회피 권고가 많음
- [[식이영양관리]]에서 식품 단위 회피 목록 참조

### ⚠️ 임상 현장 실제 사례 — 홍삼 · 메가비타민 (김성원 2021)

대림성모병원 김성원 박사가 직접 목격·보고한 임상 사례:

#### 홍삼·산삼 → 간 부전 → 간 이식
- 항암 치료 중인 환자의 간은 **항암제 부담만으로도 한계 상태**
- 여기에 홍삼·산삼이 추가되면 → **간이 버티지 못하고 간 부전**
- 김성원: "**항암 치료 중 과량의 홍삼 혹은 산삼을 드시고 간 부전에 빠져서 간 이식을 하신 환자분도 제가 본 적이 있다**"
- 홍삼·산삼은 **간에서 대사**되어 항암제와 같은 대사 경로를 두고 경쟁

#### 메가비타민 → 타목시펜 효과 감소 → 재발률 증가
- **비타민 C 1000mg 다량 복용 (메가비타민)** 등 고용량 단일 비타민 보충
- [[호르몬치료|타목시펜]] 복용 환자에서 메가비타민이 **타목시펜 효과를 떨어뜨림**
- → **재발률 증가**
- 김성원: "**비타민을 과량 섭취했을 때 타목시펜 효과가 떨어집니다. 그 말은 재발율이 증가한다는 뜻이겠죠.**"
- 종합 비타민 (일반 용량)은 OK, 메가도즈만 회피

> 💡 영양제 판매자가 "안전하다"고 강조하더라도 항암 환자·호르몬 치료 환자에서는 위험 평가가 다르다. 보조요법은 일반인 안전성 ≠ 환자 안전성.

### 항목별 임상 근거 — 카페 자주 등장 보조요법

| 항목 | 임상 근거 수준 | 위험 |
|------|----------------|------|
| **구충제 (펜벤다졸·메벤다졸·알벤다졸)** | 인간 유방암 임상시험 **없음** — SNS 발 가설 | 간독성, 항암 효과 입증 안 됨 |
| **미슬토 (압노바·Iscador)** | Cochrane 2019: 삶의 질 개선 약한 증거, **항암 효과 입증 안 됨** | 면역·간기능 영향 가능, 자가주사 부작용 |
| **고용량 비타민 C 메가도즈 IV** | 항암 중 사용 시 **재발↑·사망↑** 보고 (Ladas JCO 2004) | 신장 결석, 항암제 효과 저해 가능 |
| **셀레늄·종합 항산화제 (항암 중)** | 항암 효과 **저해 가능** (Lawenda JNCI 2008) | 항암제 효과 감소 |
| **후코이단·AHCC** | 일부 동물·소규모 임상, 인간 효과 **불명** | 일반적으로 안전하나 약물 상호작용 미규명 |
| **DIM·I3C** | 호르몬 양성에서 **권장 안 됨** — 에스트로겐 대사 영향 우려 | 농축 보충제는 회피 권고 (식품 형태 십자화과 채소는 안전) |
| **MCP (Modified Citrus Pectin)** | 동물 모델 일부, 인간 데이터 빈약 | 일반적 안전 |
| **자닥신 (티모신α1)** | 일부 적응증 임상 — 유방암 적응증은 미확립 | 면역 활성화 — 면역항암제 병용 시 평가 |
| **녹즙·약초 달인물** | 항암 중 **간수치 부담 위험** | 간독성, 농약·중금속 오염 가능 |
| **고용량 멜라토닌·토코트리에놀** | 소규모 임상 — 약한 효과 보고 | 졸음·약물 상호작용 |
| **커큐민 (보충제)** | 흡수율 낮아 임상 효과 작음 | 항응고제·항암제 상호작용 가능 |
| **콩 농축 이소플라본 보충제** | 호르몬 양성에서 **회피** — 식물성 에스트로겐 농축 | 종양 자극 우려 |
| **고용량 비타민 D** | 적정 농도 보충은 안전, **고용량 단독은 권장 안 됨** | 고칼슘혈증·결석 |
| **고용량 어유(오메가-3) 보충제** | 일반적 안전, 항암 중 출혈 위험 일부 | 항응고제와 출혈 위험 ↑ |
| **고압산소·고주파 온열치료** | 일부 임상 진행 — 표준 권고 단계 아님 | 비용 부담, 표준치료 지연 우려 |
| **광면역치료** | 두경부암 일부 적응증, 유방암 미확립 | — |

### 한방·고가 면역요법 — 카페 TOP50 #44 사례

수술 후 한방병원 팸플릿에서 자주 등장하는 옵션과 카페 결론:

| 옵션 | 비용 | 카페 결론 |
|------|------|------------|
| **Rg3 약침** | 회당 수만~수십만 | 표준치료 대체 ❌ — 간수치·실비 한도 영향 |
| **미슬토** | 회당 수만 | Cochrane 2019: 항암 효과 입증 ❌ — 위 표 참조 |
| **항암단·면역단 (한약)** | 월 수십만~수백만 | 성분 표준화 부족 — 간수치·약물 상호작용 평가 필수 |
| **NK뷰키트** | 회당 수십만~수백만 | NK세포 활성도 측정 — 진단 보조, 치료 효과 입증 ❌ |
| **이뮨셀-LC** | 회당 수백만 | 일부 적응증(간세포암) 외 표준 ❌, 비용 vs 효과 평가 |
| **고주파 온열치료** | 회당 10~30만 | 표준치료 대체 ❌, 일부 방사선 교수가 금지 안내 |

**카페 댓글에서 자주 강조**:
- "**실비 한도 때문에 입원 중**에 보조치료를 받는 것이 비용 측면에서 효율적"
- "**과한 보조치료는 비추**" — 비용·간수치·표준치료 지연 위험
- 방사선 부위·시기에 따라 **금지 권고**되는 시술이 있으므로 반드시 주치의 확인

### 3BP·대사항암제 — 카페 TOP50 #43

- **3-BP (3-Bromopyruvate)**: 암세포 대사 (해당과정) 표적 후보 물질
- **현재 단계**: 동물실험 + 일부 기업 임상 추진 단계
- **인간 표준치료 ❌** — 임상 1~3상·승인 확인 필수
- 동물실험 결과 ≠ 인간 적용
- 카페 회원이 신약 소식에서 희망을 얻는 경향 — 단계 구분 필요

### 면역세포치료제 — 일반 면역 보조와 구분

> ⚠️ **"면역항암제"와 "면역세포치료"와 "면역력 부스터 영양제"는 모두 다르다**

| 분류 | 예 | 표준치료 위치 |
|------|------|----------------|
| **면역관문억제제 (검증)** | 키트루다·옵디보·티센트릭 | TNBC·일부 적응증 표준 |
| **CAR-T 세포치료 (적응증 제한)** | 일부 혈액암 적응증 | 유방암 표준 ❌ — 임상 단계 |
| **NK세포·면역세포 주사 (비검증)** | NK뷰키트·이뮨셀 등 | 유방암 표준 ❌ |
| **"면역력 부스터" 보충제** | 다양 | 효과 입증 데이터 빈약 |

### SIO/ASCO Integrative Oncology Guideline (2018·2022)

근거 등급별 보조요법 권고:

| 권고 등급 | 보조요법 (유방암) |
|-----------|--------------------|
| **권고 (Recommend)** | 명상·요가·이완 (불안·우울 감소) |
| **약한 권고** | 침술 (오심·관절통), 음악 치료 |
| **고려 가능** | 마사지 (림프부종 도수치료는 별개로 권고) |
| **권고 안 함** | 미슬토·고용량 항산화제·고용량 비타민 메가도즈 (항암 효과 근거 부족) |
| **회피 권고** | 항암 중 고용량 항산화 보충제, 검증 안 된 구충제 |

→ [[유방암환자정신건강|명상·요가·이완]]은 SIO에서 우울·불안 감소에 권고 — [[운동수면위생]] 참조

## 임상적 의의

- 보조요법은 항암을 잘 받기 위한 **컨디션 유지 목적**이며, 표준치료 대체 수단이 아니다
- 항암 중 환자의 간수치는 약물 부담만으로도 변동하므로, 추가 부담을 주는 보충제는 위험 평가가 필요
- 카페 회원들이 일관되게 강조: **자연치유 단독 선택은 치료 지연 위험으로 공유**됨
