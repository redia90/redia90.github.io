# 한국 유방암 환자 영양 가이드

## 개요
유방암 환자의 영양 관리는 ACS·WCRF/AICR 권고 외에 **한국 환자의 식습관·문화·식품 접근성**을 함께 고려해야 한다. 카페 회원 경험담·임상영양사 권고와 학회 권고를 통합해 한국 환자 실무에 맞는 가이드를 정리한다. 일반 영양 원칙은 [[식이영양관리]]·[[호르몬양성식이]]·[[항암중식이주의]]·[[설탕탄수화물관리]] 참조.

## 핵심 내용

### 한국 환자의 식이 특성

- **한식 = 채소·발효식품·생선** 비중 높음 (장점)
- 동시에 **염분·정제탄수화물·외식 빈도** 증가 (단점)
- 노인 환자에서 **단백질 부족** 흔함 ([[노인유방암]])
- 영양 보충제 자가 사용 빈도 높음 — [[보조요법주의]] 적용 필요

### 학회·기관별 권고 비교

| 출처 | 핵심 권고 |
|------|------------|
| **WCRF/AICR 2018** | 비만 회피·일상 활동·통곡물·콩류·채소·과일 / 가공육·붉은 고기·가당음료 줄이기 / 음주 회피 |
| **ACS 2020** | 중강도 운동 주 150~300분 + 근력 주 2회 / 식물성 위주 식단 |
| **한국유방암학회 (KBCS) 2023** | 균형 잡힌 한식 / 표준치료 우선 / 영양제 자가 도입 주의 |
| **한국임상영양학회 2023** | 단백질 1.0~1.5g/kg/일 / 체중·근육 보존 우선 / 항암 중 식이 미신 교정 |
| **대한영양사협회 2024** | 임상영양사 협진 권장 / 환자별 개별 영양 평가 |

### 한국 환자 단백질 목표 (임상영양학회 2023)

| 상황 | 목표 |
|------|------|
| **항암 중** | 1.0~1.5g/kg/일 (체중 60kg = 60~90g) |
| **회복기** | 1.0~1.2g/kg/일 |
| **노인 환자** ([[노인유방암]]) | 1.2~1.5g/kg/일 (영양 부족 위험) |
| **악성 영양불량** | 임상영양사 협진 |

→ 식품별 함량은 [[식이영양관리|식이영양관리]] 참조

### 한식 기반 권장 메뉴 (한국 영양사 권고)

**아침**:
- 잡곡밥 (소량) + 미역국 + 두부조림 + 나물 + 김치
- 계란말이 또는 생선 (단백질)
- 우유·두유 1잔

**점심·저녁**:
- 잡곡밥 + 채소국 + 단백질 (생선·닭·소고기) + 김치·나물
- 식사 순서: 채소 → 단백질 → 탄수화물

**간식**:
- 두유·요거트·견과 (소량) — [[호르몬양성식이|호르몬 양성 농축형 회피]]
- 과일 1~2조각

### 한국 식품의 영양 가치 — 카페 자주 묻는 항목

| 식품 | 평가 | 비고 |
|------|------|------|
| **김치** | 발효식품·채소 ✅ | 염분 주의, 매일 적당량 |
| **된장·청국장** | 발효 콩 ✅ | [[호르몬양성식이|식품 형태 안전]] |
| **미역·다시마** | 미네랄·요오드 ✅ | 갑상선 환자는 의료진 상의 |
| **삼겹살·곱창** | 포화지방·가공도 ⚠️ | 빈도 제한 |
| **떡·면 (정제탄수)** | 혈당 스파이크 ⚠️ | 양 조절 — [[설탕탄수화물관리]] |
| **국·찌개 염분** | 위암 위험 인자 ⚠️ | 국물 줄이기 |
| **장아찌·젓갈** | 발효 + 염분 | 적당량 |
| **홍삼·인삼** | [[호르몬양성식이|호르몬 양성 회피]] | 약물 상호작용 |
| **즙·액기스** | [[보조요법주의|간수치 부담]] | 회피 또는 의료진 확인 |

### 칼슘·비타민 D (한국 환자 특이)

- 한국 식단은 **칼슘 섭취 부족** 흔함 — AI 복용 환자 골다공증 위험
- **칼슘**: 우유·요거트·치즈·멸치·콩·두부·해조류
- **비타민 D**: 햇빛 + 식품(연어·고등어·계란) + 보충제 (혈액검사 후)
- AI 복용 시 정기 골밀도 검사 ([[방사선장기부작용|호르몬치료 + 방사선 골절 위험]])

### 임상영양사 협진 — 한국 자원

| 시점 | 평가 항목 |
|------|------------|
| 진단 직후 | 기존 식습관·체중·영양 상태 평가 |
| 항암 중 | 단백질·체중·구내염·오심 |
| 항암 후 | 회복기 영양 |
| 호르몬 치료 중 | 체중·골밀도·칼슘 |
| 4기·노인 | 악성 영양불량·근육량 |

- 대형 암 센터 임상영양과 운영
- [[보험행정|산정특례]] 적용 시 영양 상담 일부 보험 적용
- [[환자지원프로그램|환자지원프로그램]] 자원 활용

#### 임상영양사 협진 실전 동선

| 단계 | 절차 |
|------|------|
| **본 병원 의뢰** | 종양내과·외과에 "임상영양사 협진 의뢰" 요청 |
| **상담 예약** | 외래·입원 중 가능 |
| **준비물** | 최근 7일 식사 기록·체중 변화·증상 일기·복용 영양제 목록 |
| **상담 내용** | 본인 상태 평가·맞춤 식단·문제 해결 (체중·구내염·오심·식욕부진) |
| **비용** | 입원 중: 보험 적용 / 외래: 일부 비급여 (병원별 1~5만 원) |
| **재상담** | 1~3개월 간격 또는 증상·체중 변화 시 |

#### 임상영양사가 잘 다루는 영역
- 항암 중 입맛 상실 — 음식 텍스처·온도·향 조절 팁
- 구내염 — 부드럽고 미지근한 식사
- 오심·구토 — 작게 자주, 차가운 음식
- 변비·설사 — 식이섬유·수분 조절
- 체중 감소·근감소 — 단백질·열량 보강 (뉴케어·엔커버 등)
- 호르몬 치료 중 체중 증가 — 칼로리·운동
- 한식 기반 맞춤 메뉴

### 입원 중 영양 관리 — 의료기관 표준

수술·항암 입원 중 영양 관리는 의료기관 임상영양사가 주도:

| 입원 단계 | 영양 관리 |
|----------|-----------|
| **수술 전 (1~2일)** | 일반식 + 금식 준비 (자정~) |
| **수술 직후 (0~1일)** | 죽·미음 (소화 회복 평가) |
| **수술 후 (2~5일)** | 부드러운 일반식 → 일반식 전환 |
| **항암 입원 (D0~D1)** | 가벼운 식사, 항구토제 사전 |
| **항암 입원 (D2~)** | 입맛에 맞는 식사·소량 자주 |
| **퇴원 전** | 가정 식단 안내 — 임상영양사 교육 |

### 한국 환자 코호트 영양 데이터 (공백 영역)

> 💡 **연구 공백**: 한국 유방암 환자의 식이·체중·재발 위험 코호트 데이터는 제한적. 대부분 미국·중국 데이터에 의존. KBCS·국가암등록사업에서 추가 연구 필요.

| 영역 | 한국 데이터 상태 |
|------|--------------------|
| **한국 환자 평균 단백질 섭취량** | 부분 데이터 — 일부 단일 기관 |
| **한식 발효식품과 재발 위험** | 제한적 |
| **콩·이소플라본과 ER+ 재발** | 중국 데이터로 추론 |
| **항암 중 영양 불량 빈도** | 일부 보고 — 30~50% 추정 |
| **임상영양사 협진율** | 대형 병원 약 30~50% |
| **노인 환자 영양 부족** | 60% 이상 추정 ([[노인유방암]]) |

### 콩·식물성 에스트로겐 — 한국 입장 통합

가장 많은 환자 질문 영역. **국내·국제 권고가 미묘하게 다름** — 환자가 혼란 多.

#### 식품 vs 농축 보충제 — 가장 중요한 구분

| 분류 | 권고 |
|------|------|
| **콩 식품** (두부·콩나물·된장·두유·낫토·콩밥) | ✅ 안전 — 식품 단위는 보호적 가능성 (LACE·Shu) |
| **콩 농축 이소플라본 보충제·환** | ❌ 회피 — 농축형은 약물 대사 방해·자극 가능 |
| **석류 식품 (생과·주스)** | ⚠️ 적당량 (호르몬 양성에서는 신중) |
| **석류 농축 보충제·환·즙** | ❌ 회피 |
| **두유** | ✅ 1~2잔/일 (식품 단위) |

#### 임상 데이터 — LACE Study + Shu Shanghai

- **LACE Study (CEBP 2009)**: 미국 유방암 생존자 1,954명
  - 콩 이소플라본 섭취 ↑ → 재발 위험 ↓ 경향
  - 폐경 후 + 타목시펜 복용군에서 가장 강한 보호 (재발 60% 감소)
- **Shu Shanghai (JAMA 2009)**: 중국 환자 5,042명
  - 콩 식품 섭취 ↑ → 사망·재발 위험 ↓
  - **ER+ 환자에서도 보호 효과** 보고

#### 한국 의료진별 입장 차이

| 출처 | 입장 | 적용 |
|------|------|------|
| **김성원 (비온뒤 2021)** | "콩은 좋고, BRCA+에서도 보호" | 식품 형태 권장 |
| **LACE·Shu 국제 데이터** | 식품 섭취는 보호적 | 식품 형태 권장 |
| **강동성심병원 정진철 (2022)** | "**석류·콩 장기 다량 자제**" — 특히 호르몬 양성·항암 중 | 보수적 — 신중 자제 |
| **한국유방암학회 (KBCS)** | 명시적 권고 ❌ — 일반 식이 권고만 |
| **한국임상영양학회** | 식품 단위 균형 식이 — 농축 보충제 회피 |

> ⚠️ **두 입장 모두 일리 있음** — 환자별·상황별 결정 필요:
> - **식품 형태 + 일반 양 (두부 1~2조각·두유 1~2잔/일)** → 대부분 의료진 동의 안전
> - **농축 보충제·환·즙** → 모든 의료진 회피 권고
> - **호르몬 양성 + 항암 치료 중** → 본 병원 주치의·영양사와 사전 상의 권장
> - **BRCA+ 환자** → 콩 식품 섭취가 일부 보호적 (김성원·LACE)

### 환자가 자주 묻는 영양 미신 교정

| 미신 | 사실 |
|------|------|
| "고기 먹으면 안 된다" | 항암 중 단백질 필수 — 살코기 OK (안심·닭가슴살 권장) |
| "가공육 = 생고기" | **가공육이 더 나쁨** — 환경호르몬·첨가물 가능성 (김성원 2021) |
| "꽃등심·삼겹살이 좋은 고기" | **마블링 지방이 유방암 위험 증가** — 안심·닭가슴살로 |
| "설탕은 암 먹이" | 직접 인과 단정 어려움 — 가당음료·디저트 양 조절 |
| "유기농만 안전" | 일반 채소·과일도 안전, 잘 씻기 |
| "MSG·소금이 암 유발" | 직접 연관 약함 (단, 위암은 염분 위험) |
| "녹즙·즙이 항암" | 항암 중 간수치 부담·치료 방해 가능 ([[항암중식이주의]]) |
| "특정 영양제가 재발 막음" | 식품 형태 영양 우선·고용량 보충제 회피 ([[보조요법주의]]) |
| "유방암 환자 평생 회·고기 금지" | **잘못된 인식** — 항암 중에만 익혀서 (김성원 2021) |
| "콩이 호르몬 양성에 무조건 나쁘다" | 식품 형태는 안전, **BRCA+에서는 보호 효과 보고** (김성원 2021) |
| "채식·생식만이 정답" | 단백질·지방 필수 — 3대 영양소 골고루 ([[식이영양관리]]) |
| "과일은 무한히 먹어도 OK" | 과량 탄수화물·당 — 밥 대용 금지 |
| "메가 비타민이 항암 효과" | 타목시펜 효과 감소 → 재발률 증가 ([[보조요법주의]]) |
