# 남성 유방암 (Male Breast Cancer)

## 개요
남성 유방암은 전체 유방암의 **약 0.5~1%** 를 차지하는 드문 질환이지만, **BRCA2 변이와 강한 연관성**, **진단 지연**, **치료 데이터 부족**이라는 특수성으로 별도 접근이 필요하다. 거의 모든 남성 유방암이 ER 양성으로, 호르몬 치료가 핵심이며 [[BRCA유전자|BRCA2]] 검사 적응증이 명확하다. 카페에도 남성 환자 투병기(#759732, AC 3차)가 있어 한국 내 진단 사례가 꾸준히 보고된다.

## 핵심 내용

### 빈도와 역학

| 항목 | 수치 |
|------|------|
| 전체 유방암 중 비율 | **0.5~1%** |
| 평균 진단 연령 | **65~70세** (여성보다 5~10년 늦음) |
| 미국 연간 발병 | 약 2,800명 |
| 한국 연간 발병 | 약 100명 추정 |
| 5년 생존율 (조기) | 80~90% |
| 5년 생존율 (전이성) | 약 25% |

### 한국 남성 유방암 특이점 (KBCS 등록사업 추정)

| 항목 | 한국 (추정) | 서구 |
|------|-------------|------|
| 전체 유방암 중 비율 | **약 0.5%** | 약 1% |
| 평균 진단 연령 | **60대** | 65~70세 |
| 진단 시 1·2기 비율 | 약 60% (낮음) | 약 70% |
| BRCA2 변이율 | 약 10~15% (한국 데이터 제한) | 10~15% |
| 5년 생존율 | 약 78~85% | 80~90% |

- **한국 환자 특이점**: 진단 시점이 약간 빠르지만 1·2기 비율은 낮음 — **진단 지연**이 더 흔함
- 한국 자료 부족 — 대규모 코호트 데이터 추가 수집 필요

### 위험 요인

| 요인 | 위험 증가 |
|------|-----------|
| **BRCA2 변이** | 평생 위험 **약 7%** (정상의 70~100배) |
| **BRCA1 변이** | 평생 위험 약 1% |
| **클라인펠터 증후군 (47,XXY)** | 20~50배 증가 — 가장 강한 단일 위험 요인 |
| 가족력 (1·2촌 유방암) | 2~3배 |
| 고환 기능 이상·고환염 | 일부 보고 |
| 간경변·간기능 저하 | 에스트로겐 대사 변화 |
| 비만 | 약간 증가 |
| 방사선 노출 (흉부) | 일부 보고 |
| Cowden 증후군 (PTEN 변이) | 증가 |

### 진단 — 진단 지연이 핵심 문제

**전형적 증상**:
- 유두 주변 무통성 멍울 (가장 흔함)
- 유두 함몰·분비물·궤양
- 피부 발적·궤양·오렌지 껍질 모양
- 겨드랑이 림프절 종대

**진단 지연 이유**:
- "남성도 유방암이 있나" 인식 부족
- [[조직검사결과해석|여성형 유방(gynecomastia)]]과 혼동
- 환자의 부끄러움·심리적 회피
- 1차 의료기관에서 의심도 낮음

**진단 도구**:
- 신체검진·유두 분비물 확인
- 유방촬영술 (남성에도 시행 가능, BI-RADS 적용)
- 초음파
- 조직검사 (총조직검사) → [[조직검사결과해석]]
- [[유전자검사|BRCA1/2 검사 강력 권고]] (NCCN)

### 분자 특성 — 여성과 다른 점 (EORTC/BIG 2018)

| 특성 | 남성 유방암 | 여성 유방암 (참고) |
|------|-------------|---------------------|
| **ER 양성** | **>99%** | 70~80% |
| **PR 양성** | 80% | 60~70% |
| **HER2 양성** | 약 9% | 15~20% |
| **TNBC** | <2% (드묾) | 15~20% |
| **루미날 A 우세** | 더 흔함 | — |
| **BRCA2 변이** | 10~15% | 2~5% |
| **AR (Androgen Receptor)** | 90% 양성 | — |

> 💡 거의 모든 남성 유방암이 **ER+/HER2-** 호르몬 양성. [[호르몬치료]]가 중심.

## 치료

### 1. 수술
- **변형 근치 유방절제술 (Modified Radical Mastectomy)** 이 가장 흔함
- 유방 조직이 작아 보존 수술이 어려운 경우 많음 — 일부에서 보존 가능
- 감시 림프절 생검 적용

### 2. 방사선
- 전절제 후 림프절 4개 이상·종양 5cm 초과 등 [[방사선치료|PMRT 적응증]] — 여성과 동일

### 3. 호르몬 치료
- **타목시펜이 표준** (1차)
- 5~10년 복용
- 부작용: 안면홍조·체중 증가·성욕 감소·정맥혈전·골밀도 변화
- **AI (아로마타제 억제제) 단독은 효과 제한** — 남성은 고환에서 호르몬 생성 지속, AI 단독으로 차단 부족
- AI 사용 시 **GnRH 작용제 병합** 필요 (난소 억제와 유사)

### 4. 항암
- [[항암화학요법|여성과 동일한 약제]] 적용 — AC·TC·TCHP·CMF 등
- 결정 기준: [[온코타입DX_RS점수|Oncotype DX RS]]·[[유전자발현프로파일링|MammaPrint]] 등 활용 가능 (남성 데이터 제한적이지만 적용 가능)

### 5. 표적치료
- HER2 양성 시 [[HER2표적치료|허셉틴·퍼투주맙·엔허투]] — 여성과 동일

### 6. PARP 억제제
- BRCA 변이 + HER2- 전이성: [[PARP억제제|올라파립·탈라조파립]] — 여성과 동일
- BRCA2 변이 비율이 높아 PARP 억제제 후보가 많음

### 7. AR (Androgen Receptor) 표적치료 — 임상 단계

남성 유방암 **90% AR 양성**:
- **비칼루타미드 (Casodex)**: 전이성 AR+ 남성 유방암 임상 일부 — 부분 반응 보고
- **엔잘루타미드 (Xtandi)**: 임상시험 진행
- **GnRH 작용제 (졸라덱스·루프린) + AI 병합**: AI 단독 효과 제한 → 고환 호르몬 생성 차단 필요
- 한국 표준 치료에 도입 ❌ — 임상시험 또는 비급여

> 💡 AR 표적치료는 남성 유방암의 미래 치료 옵션 — 비칼루타미드 단독 또는 다른 호르몬과 병합 임상 진행 중.

## 환자 진단 후 추가 검사·평가

| 검사 | 시점 | 목적 |
|------|------|------|
| **BRCA1/2 검사** | 진단 직후 | 가족 위험·PARP 적응증 — NCCN 강력 권고 |
| **PALB2·CHEK2·ATM 패널** | BRCA 음성 시 | 추가 유전 위험 |
| **고환 초음파** | 진단 시 | 클라인펠터 평가·고환 기능 |
| **혈중 테스토스테론·에스트라디올** | 진단 시 | 호르몬 평가 |
| **간기능 검사** | 진단 시 | 간경변 동반 평가 |
| **전립선암 검진 (PSA)** | 50세 이상 | BRCA2 보유자에서 전립선암 위험 ↑ |
| **췌장암 위험 평가** | BRCA2 양성 | 가족 자원 평가·추적 |

### BRCA2 양성 남성 환자의 다층 위험

BRCA2 보유 남성은 유방암 외 추가 위험:

| 암 종류 | 평생 위험 (BRCA2+ 남성) | 일반 인구 |
|---------|------------------------|-----------|
| **유방암** | **약 7%** | 0.1% |
| **전립선암** | 약 20~30% (조기·공격적) | 약 12% |
| **췌장암** | 약 5~10% | 1~2% |
| **흑색종** | 약 5% | <1% |

→ [[BRCA유전자]] BRCA2 다층 위험 / [[유방암유전상담]] 가족 검사 동선

## 임상적 의의

- **모든 남성 유방암 환자는 [[유전자검사|BRCA1/2 검사]]** — NCCN 강력 권고
- BRCA2 양성 시 가족 검사 (남성·여성 친척 모두)
- 진단 지연이 예후의 가장 큰 영향 — 환자·의료진 교육이 핵심
- 호르몬 치료는 거의 항상 타목시펜 — AI 단독 효과 제한
- 임상시험 데이터 부족 — 대부분 여성 데이터에 의존

## 환자 특수 이슈

### 심리·사회적
- "여성 질환" 인식으로 인한 **수치심·고립감**
- 카페·환우 커뮤니티에서도 소수 — 정보 접근성 낮음
- 카페 #759732 사례: 지방에서 상경한 남성 환자의 AC 3차 항암 — 동료 환자가 거의 없는 환경
- [[보호자심리지지|가족 지지]] + 정신건강 전문 상담 권장 ([[유방암환자정신건강]])

### 환자 특수 그룹 공통 주제

[[임신중유방암_PABC|임신 관련 유방암(PABC)]]·[[노인유방암|노인 유방암(70세 이상)]]과 함께 **희귀 환자 특수 그룹**으로서 공유하는 도전:

| 공통 주제 | 남성 | PABC | 노인 |
|------------|------|------|------|
| 진단 지연 | 인식 부족 | 임신 변화 오인 | 검진 빈도 낮음 |
| 임상시험 데이터 부족 | ✓ | ✓ | ✓ |
| 표준 가이드라인 한정 적용 | ✓ | ✓ | ✓ |
| 다학제 팀 필요 | 종양내과 + 비뇨기과 | 종양내과 + 산부인과 + 신생아과 | 종양내과 + 노인의학 + 사회복지 |
| 환자 의사결정 가치관 | 수치심 극복 | 임신 종료 vs 치료 | 삶의 질 vs 적극 치료 |
| 가족 영향 | BRCA2 자녀·형제 | 자녀 양육 | 돌봄 부담·요양 |
| 환우 커뮤니티 | 매우 소수 | 소수 | 디지털 접근성 격차 |

> 💡 세 그룹 모두 [[환자지원프로그램]]·[[보호자심리지지]] 자원이 일반 환자보다 더 중요한 역할을 한다.

### 진단 후 1차 액션 (남성 환자 체크리스트)
1. [[유전자검사|BRCA1/2 검사]] 신청 — 무조건 권고
2. 가족(남성·여성 형제·자녀) 검사 권유 가능성 평가
3. [[온코타입DX_RS점수|Oncotype DX]] 가능 여부 (보험·시행 가능 여부 진료실 확인)
4. [[가임력보존|가임력]] 영향 평가 (탁산·AC는 정자 생성 영향 가능)
5. [[호르몬치료|타목시펜]] 5년 vs 10년 결정 (고위험 시 10년)

## 한국 남성 유방암 환자 자원

남성 환자가 거의 정보·자원에서 소외되는 영역. 가능한 자원:

| 자원 | 활용 |
|------|------|
| **국가암정보센터 1577-8899** | 일반 상담 — 남성도 동일하게 이용 가능 |
| **한국유방암환우총연합회 (KBCN)** | 일부 행사 참여 — 남성 회원 소수 |
| **네이버 카페 '유방암이야기'** | 카페 내 남성 환자 게시판 — 소수 |
| **병원 사회복지팀** | 1:1 상담 — 환자 그룹과 별개 가능 |
| **유튜브 남성 환자 채널** | 일부 환자 본인 운영 |
| **국제 자원 (Male Breast Cancer Coalition)** | malebreastcancercoalition.org |
| **종교·민간 비영리** | 일부 — 호스피스·정서 지원 |

> 💡 한국 남성 유방암 환자는 **국제 자원 활용** 가치 ↑. 영어 커뮤니티 (Male Breast Cancer Coalition, Susan G. Komen)·환우 블로그·논문에서 정보 격차 해소 가능.

### 사례 패턴 — 카페에서 보고된 한국 남성 환자

#### 케이스 A: 60대, 무통성 멍울 → 1차 의원 → 6개월 후 유방외과 (#759732)
- 진단 지연 약 6개월
- 진단 시 2기 ER+/HER2- → AC 4회 + 탁솔 4회 + 타목시펜
- BRCA2 양성 확인 → 자녀(남녀) 검사 진행

#### 케이스 B: 50대, 가족력 강함 (어머니 유방암·이모 난소암)
- 가족력 유전상담 → BRCA2 확인 → 유방암 검진 강화
- 검진 중 조기 발견 → 보존 가능
- 형제·자녀 가족 검사 진행

#### 케이스 C: 70대, 간경변 환자 (간경변 → 에스트로겐 ↑ → 유방암)
- 간기능 관리와 동시에 호르몬 치료
- 타목시펜 + 간 보호 약제 병행
- AI 단독 사용 시 GnRH 병합 필요

### 환자가 알면 도움되는 메시지

> 💡 "**남성 유방암은 드물지만 분명히 존재한다**" — 의료진·환자·가족 모두의 인식이 진단·치료에서 가장 큰 차이를 만든다.

- 부끄러워하지 말 것 — 의학적 질환
- BRCA 검사가 본인 + 가족 모두를 위한 결정
- 환우 커뮤니티에 적극 등록 (수 적지만 존재)
- 가족 (남녀) BRCA 검사 권유
- 타목시펜 부작용 (홍조·성욕 감소·체중)을 미리 인지하고 의료진과 상의

## 미해결 질문 / 연구 방향
> 💡 남성 유방암 전용 임상시험 — 여성 데이터 의존도 줄이기 위한 국제 협력 필요
> 💡 AR (Androgen Receptor) 표적치료 — 비칼루타미드 등 임상 단계
> 💡 BRCA2 변이 남성에서 PARP 억제제 효과 직접 검증 데이터
> 💡 한국 남성 유방암의 정확한 빈도·BRCA2 변이율 — 코호트 부재
> 💡 **한국 남성 유방암 환자 BRCA2 비율** 서구 약 10% vs 일반 유방암 5% — 한국 코호트 데이터 필요
> 💡 한국 남성 환자 자조 그룹·디지털 커뮤니티 활성화 방안

## 주의사항
> ⚠️ "남성도 유방암이 있다" — 1차 의료기관과 환자 모두의 인식 부족이 진단 지연의 핵심 원인. 무통성 유두 주변 멍울은 즉시 유방외과 평가.
> ⚠️ 여성 유방암 데이터에 기반한 치료가 대부분 — 일부 결정(특히 AI 단독)은 남성에서 효과 다를 수 있음. 종양내과 상담 필수.
> ⚠️ BRCA2 양성 시 가족(남성·여성 모두)의 유방암·전립선암·췌장암 위험 평가가 필요하다.
