# 유방암 진단 체계

## 개요

유방암 진단은 **영상검사(발견) → 조직검사(확진) → 수용체·유전자 검사(분류) → 병기 결정**의 단계로 이루어진다. 각 단계는 치료 전략 수립에 직접 연결되며, 정확한 초기 진단이 예후와 직결된다.

진단 체계는 단순한 검사 나열이 아니라, 시점별로 적절한 검사를 선택하는 의사결정 흐름이다. 같은 검사라도 초기 진단·수술 후 보조치료 결정·재발/전이 시점 등 상황에 따라 목적과 해석이 달라진다.

> 💡 **처음 진단받으신 분들께**: 정보가 한꺼번에 쏟아지는 시기 — 우선 읽기 순서·수술 전 체크리스트·진료실 질문 정리는 [[처음온사람안내|처음 온 사람 안내 — 진단 직후 길잡이]]에서 확인하세요.

## 빠른 참조 — 검사 종류와 목적

| 검사 범주 | 본질 | 대표 검사 | 주요 목적 |
|-----------|------|-----------|-----------|
| **영상검사** | 병소 위치·크기 파악 | 맘모그래피·초음파·MRI | 발견·범위 평가·반응 평가 |
| **조직검사** | 암 유무 확진 | 코어 바늘 생검 (CNB) | 양성·악성 감별 |
| **IHC (단백질 발현)** | 수용체·증식지수 | ER·PR·HER2·Ki-67 | 서브타입 결정 |
| **FISH (유전자 복제 수)** | HER2 증폭 확인 | HER2 ISH | IHC 2+ 추가 판정 |
| **유전자발현 프로파일링** | 유전자 활성 수준 | Oncotype DX·MammaPrint·BCI | 항암 추가 여부·연장 결정 |
| **유전자 변이 검사** | DNA 서열 이상 | BRCA1/2·NGS·ctDNA | 유전성 위험·표적약 선택 |
| **전이 평가 영상** | 원격 전이 확인 | CT·뼈스캔·PET-CT | 병기 결정 |

## 임상적 의의

- 맘모그래피 + 초음파 병용이 치밀 유방 한국 여성에게 특히 유효
- 조기 발견 시 (1기) 5년 생존율 ~99%, 전체 유방암 5년 생존율 90% 이상
- 타병원에서 진단 받고 치료 병원 이동 시: 조직 검사 결과지 + 보관 조직 반드시 지참
- ER+/HER2- 유방암은 20년까지 재발 가능 → 장기 추적 관찰 필수
- **침윤암 여부(DCIS vs 침윤성)** 를 반드시 파악해야 전이 평가 검사(뼈 스캔 등) 적용 범위가 달라짐
