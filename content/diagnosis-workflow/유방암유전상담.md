# 유방암 유전상담 — 검사 적응증·가족 동선·보험·심리

## 개요

유방암 유전상담(Genetic Counseling)은 **유전성 유방암 검사 전·후의 의학적·심리적 의사결정 지원**을 제공하는 표준 진료 절차다. 유방암의 5~10%는 유전성으로, 유전상담은 환자 본인뿐 아니라 가족 전체의 예방·검진·치료 결정에 결정적 영향을 미친다.

검사 결과는 단순 양성·음성이 아닌 다층 구조(병원성 변이·VUS·불확실 등)로 해석해야 하며, 예방적 수술·검진 강화·약물 예방·가족 cascade testing 등 복잡한 다음 결정이 뒤따른다. 한국은 산정특례 + 보험 적용으로 검사 비용은 낮으나(5만원대), 유전상담사 인프라(약 30명)가 부족해 종양내과 통합 상담 모델이 현실이다.

유전자 자체 정보는 [[biology/BRCA유전자|BRCA유전자]], 검사 기술은 [[diagnosis-tests/유전자검사|유전자검사]], 위험 평가는 [[biology/유방암위험인자|유방암위험인자]] 참조.

## 빠른 참조

| 항목 | 핵심 내용 |
|------|-----------|
| **검사 적응증 핵심** | 유방암 진단 ≤45세, TNBC ≤60세, 1차 친족 유방암 ≤50세, 양측/남성 유방암 |
| **유전상담 3단계** | Pre-test 상담 → NGS 채혈 → Post-test 결과 통보·다음 결정 |
| **결과 4카테고리** | Pathogenic / Likely Pathogenic / VUS / Benign |
| **VUS 주의** | 임상 결정 미반영 — 시간 지나며 재분류 가능 |
| **양성 후 주요 선택** | RRM(위험 90~95% 감소), RRSO(35~40세), 검진 강화(MRI 매년), 약물 예방 |
| **한국 인프라** | 유전상담사 약 30명, 대형 병원 클리닉 6곳, KSHOC 권고안 |
| **보험 영향** | 유전정보보호법(2014) — 차별 금지, 그러나 신규 가입 거절 사례 있음 → 검사 전 가입 권장 |
| **PALB2 보험** | 현재 PARP 보험 BRCA1/2 한정 — PALB2 적용은 2027~2028 예상 |

## 임상적 의의

- 유방암의 5~10%가 유전성 — 유전상담은 환자·가족 모두에게 결정적 정보
- 한국 인프라 부족(유전상담사 약 30명) — 종양내과 통합 상담이 현실
- 산정특례·보험 적용으로 검사 비용은 낮으나 **상담 시간·심리 지원**은 부족
- 가족 cascade testing은 예방적 수술 결정의 출발점 (한국 도달률 20~30%)
- VUS 비율 10~20% — 환자 혼란 원인 → 상담 중요
- 유전 정보 보호법으로 차별 금지하지만 **신규 보험 가입 거절 사례** 있음 — 검사 전 가입 권장
- **ASCO 2026 후 BRCA·PALB2 의사결정 동선 강화** — OlympiA 10년·POSITIVE 5년·PALB2 보험 확대 진행
