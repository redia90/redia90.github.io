# 호스피스·완화의료 — 환자·가족 의사결정 가이드

말기·시한부 판정 후 환자·가족이 마주하는 결정을 단계별로 정리한 페이지다. 5단계 의사결정 흐름, ASCO 2026 이후 4기 약제 다양화 시대의 적극치료 vs 완화 전환 결정, 4기 통합 의사결정 동선, DA 도구 활용, 한국 진료실 질문, 카페 사례를 포함한다.

---

## 환자·가족 의사결정 가이드 — 단계별

### 1단계 — 진단 직후 (시한부 통보 1~2주)
- 충격·부정·분노가 정상 — 즉시 결정 강요하지 말 것
- 가능하면 **가족 모두가 함께** 의료진 설명 듣기
- **세컨드 오피니언** 검토 — 진단·예후 확인
- **본인의 의사**가 가장 중요 — 가족 의견은 보조

### 2단계 — 옵션 탐색 (수주~수개월)
- **표준치료 계속 vs 중단·전환** 의료진과 상의
- **완화의료 의뢰** 시점 — 4기 진단 시점부터 가능 (이른 통합)
- **호스피스 유형** 5가지 검토 — 본인 상태·가족 자원·거주지
- **사전연명의료의향서** 작성 — 평소에 안 했다면 이제라도
- **재정·행정 정리** — 보험·장애연금·산정특례 ([[보험행정]])

### 3단계 — 호스피스 등록 (수일~수주)
- 등록기관 선택 — 입원·가정·자문형
- **VRE 등 항생제 내성균 사전 확인** — 입원 가능 기관 영향
- 야간·주말 응급 연락 체계 확인
- **POLST 작성** — 담당의와 4가지 연명의료 결정

### 4단계 — 임종기 (수일~수주)
- 통증·증상 관리 최우선 — 마약성 진통제 죄책감 없이
- 가족 시간 — 사진·영상·편지·대화
- **종교·영적 돌봄** — 본인 신앙·전통 따라
- **임종 환경** — 자택 vs 시설 선택
- 사후 절차 — 장례·서류·재정 인지 (보호자 준비)

### 5단계 — 사별 후 (수개월~1년+)
- 가족 사별 돌봄 — 일부 호스피스 기관은 1년간 가족 지원
- 자녀 사별 돌봄 — 별도 자원 (초록우산·정신건강 상담)
- 보호자 본인 건강 점검 — 사별 후 우울·신체화 증상 흔함
- → [[보호자심리지지]] 사별 후 돌봄 섹션

## 적극치료 vs 완화 전환 결정 — ASCO 2026 후 4기 약제 다양화 시대 (2026-06)

### 4기 약제 다양화로 인한 의사결정 복잡성 ↑

ASCO 2026 후 4기 환자가 마주하는 옵션이 크게 늘었다 — **"끝까지 치료" vs "완화 전환"** 결정이 더 복잡:

| 서브타입 | 2026 1~6차 약제 옵션 |
|----------|----------------------|
| **ER+/HER2-** | CDK4/6 + AI → CDK4/6 변경·PI3K/AKT (capivasertib·inavolisib) → vepdegestrant/엘라세스트란트 (ESR1) → 화학요법 → 임상시험 |
| **HER2+** | THP → T-DXd (DESTINY-Breast09) → T-DM1 → 투카티닙 + 카페시타빈 → 임상시험 |
| **HER2-low** | 호르몬 → 엔허투 (DESTINY-Breast06 1차 도입 시) → 화학·면역 → ADC 임상 |
| **TNBC** | 펨브로 + 화학 (PD-L1+) → SG (트로델비) → Dato-DXd → 면역·PARP 임상 |
| **BRCA+ 진행성** | 위 + PARP → PARP 후 reversion → 화학·면역·ATR 임상 |

> 💡 **결과**: 4기 환자가 평균 **3~6개 약제 순차 사용** — 환자가 "치료 vs 완화" 결정을 여러 번 마주함.

### 적극치료 vs 완화 전환 결정 시점 — 의사결정 신호

**적극치료 지속 권장 신호**:
- ECOG 0~2 (일상 가능)
- 다음 약제 옵션 명확 + 적응증 충족
- 환자·가족이 적극치료 의지
- 부작용 관리 가능
- 임상시험 등록 가능성

**완화 전환 검토 신호**:
- ECOG 3~4 (대부분 침상 생활)
- 표준 옵션 소진 + 임상시험 등록 불가
- 약제 효과 미미 + 부작용 누적
- 환자 본인이 "그만하고 싶다" 의사 표현
- 가족·돌봄 자원 한계
- 다발성 장기 기능 저하

> ⚠️ **두 신호는 단번에 결정되지 않음** — 약제 1~2회 시도 후 평가, 환자 의사 변동 가능. **반복 의사결정**.

## 4기 환자 의사결정 통합 동선 (2026-06)

```
[4기 진단·전이 확인]
    ↓
[1차 약제 + 임상시험 등록 가능성 검토] → [research/임상시험]
    ↓
[ECOG·약제 반응·환자 가치관 정기 평가] (3~6개월마다)
    ↓
├── 반응 양호 + 환자 의지 → 약제 지속·다음 약제 준비
├── 반응 부족 + 부작용 ↑ → 다음 약제 변경 시도
└── 표준 옵션 소진·ECOG ↓ → 완화의료 통합 시작 (이른 완화)
       ↓
[조기 완화의료 통합 (Early Palliative Care) — Temel NEJM 2010]
    ↓
[자문형 완화 → 가정형 → 입원형 (상태 따라)]
    ↓
[POLST·사전연명의료의향서 작성·검토]
    ↓
[임종기 — 통증 관리·가족 시간·종교·영적 돌봄]
```

## 환자 의사결정 도구 ([[mental-experience/환자의사결정도구|DA]]) 활용

- **PREDICT Treatment**: 약제별 절대 이득·생존율 시각화
- **Question Prompt List (QPL)**: 4기 환자용 — "어떤 약제 옵션이 있나요?"·"부작용이 가능한 일상 활동에 영향을 주나요?"·"임상시험 등록 가능한가요?"·"완화의료 의뢰 시점은?"
- **Goal Concordant Care**: 환자 가치관·목표 명확화 도구
- **VOICES** (한국 표준화 미흡): 임종기 의사결정 도구

## 한국 4기 환자 진료실 질문 (2026-06)

1. 제 서브타입·BRCA·HER2-low 상태에서 **다음 약제 옵션**은 몇 개나 남았나요?
2. **임상시험 등록** 가능성은? (한국 신약 페니트리움·JW2286 포함)
3. **완화의료 의뢰**는 언제부터 가능한가요? (4기 진단 시점부터)
4. 약제 효과가 부족할 때 **다음 단계 결정**은 어떻게 하나요?
5. **POLST** 작성 시점은? 변경 가능한가요?
6. 가족 의견과 본인 의견이 다를 때 **환자 본인 의사 우선** 권리는?
7. **호스피스 5가지 유형** 중 제 상황에 맞는 것은?
