# HER2-low 유방암 치료 — ADC 혁명

## 개요
2022년 DESTINY-Breast04 연구로 HER2-low(IHC 1+ 또는 2+/FISH-) 유방암이 ADC(항체약물접합체) 치료 대상으로 편입되면서, 기존에 "HER2 음성"으로 분류돼 표적치료를 받지 못하던 환자들에게 새로운 선택지가 생겼다. 유방암 환자의 40~50%를 차지하는 HER2-low군과, 최근 발견된 HER2-ultralow까지 포함하면 영향 범위는 유방암 환자 절반 이상으로 확대된다.

## HER2 분류 체계의 진화

### 기존 이분법 vs 새로운 분류

| 분류 | IHC 점수 | 기존 치료 | ADC 도입 후 |
|-----|---------|---------|-----------|
| HER2 양성 (HER2+) | 3+ (또는 2+/FISH+) | 표적 치료 (트라스투주맙 등) | 기존 + 엔허투 확대 |
| **HER2-low (신규)** | **1+ 또는 2+/FISH-** | 화학항암제만 가능 | **엔허투(T-DXd) 적용** |
| HER2-ultralow (최신) | 0이지만 극미량 발현 | 화학항암제만 가능 | 임상시험 적응 중 |
| HER2 완전 음성 | 0 (극미량 없음) | 화학항암제만 가능 | 현재 미적용 |

> 💡 기존 유방암 환자의 80~85%가 "HER2 음성"으로 분류됐으나, 이 중 상당수가 HER2-low에 해당 → ADC 치료 적용 가능

## DESTINY-Breast04 연구 (핵심 근거)

- **연구 설계**: HER2-low 전이성 유방암 환자에서 T-DXd(엔허투) vs 화학요법 비교
- **발표**: 2022년 ASCO / NEJM

| 지표 | T-DXd (엔허투) | 화학요법 |
|-----|-------------|--------|
| 중앙 전체 생존 기간 | 23.9개월 | 17.5개월 |
| 생존 기간 연장 | **+6.4개월** | — |

- **의미**: 전이성 유방암에서 약 6개월의 생존 기간 연장 — 임상적으로 유의미한 개선
- **FDA 승인**: 2023년 / **한국 건강보험 적용**: 2023년 말

## ADC (항체약물접합체) 기전

```
트라스투주맙 (HER2 찾는 네비게이션)
        +
    링커 (절단 가능)
        +
DXd (토포이소머라제1 억제제 — 강력한 항암제)
```

- **선택성**: HER2 발현 암세포만 표적 → 기존 항암제 대비 정상 세포 피해 감소
- **Bystander effect**: 인접 HER2 음성 암세포도 공격 (낮은 HER2 발현에도 효과적인 이유)

## HER2-ultralow (2024~2025 최신)

- **정의**: IHC 0 판정이지만 실제로는 극미량의 HER2 발현이 있는 경우
- **임상 결과**: 객관적 반응률(ORR) 30~40%
- **영향**: HER2-low + HER2-ultralow 합산 시 유방암 환자 **절반 이상**이 ADC 혜택 가능

## 2025-2026 신보조요법 확장

- 기존: 전이성 유방암에서만 엔허투 사용
- **2025년 신결과**: 수술 전 신보조요법으로 완전관해(pCR)율 향상 확인
  - non-pCR 환자에서도 기존 약보다 효과적
- 적용 범위가 조기 유방암으로 확대될 전망

## 주요 ADC 약물 현황

| 약물 | 표적 | 적응증 |
|-----|------|-------|
| **엔허투 (T-DXd)** | HER2 | HER2+, HER2-low, HER2-ultralow |
| 트로델비 (삭시투주맙) | Trop-2 | TNBC |
| 파트리투맙 데룩스테칸 | HER3 | 임상시험 중 |

## 한국 보험 적용 현황 (엔허투)

| 구분 | 조건 | 비용 |
|-----|-----|-----|
| **HER2-low (급여)** | 전이성(4기) + 선행 항암제 1~2가지 후 | 주사당 20~30만 원 (산정특례 5%) |
| **HER2-ultralow (비급여)** | 비급여 (현장 처방 가능) | 주사당 400~500만 원 |

> 💡 HER2-ultralow 환자: 제약사 환자 지원 프로그램 활용 가능 (다이이찌산쿄/아스트라제네카)

## 부작용 — 간질성 폐렴 (ILD)

- **발생률**: 10~15%
- **발생 시기**: 주로 치료 시작 후 3~6개월 내
- **증상**: 기침, 호흡곤란
- **관리**: 조기 스테로이드 투여 시 대부분 회복
- ⚠️ **증상 발생 즉시 의료진 연락 필수** — 지체 시 심각해질 수 있음

## HER2 검사 신뢰도 이슈

- **판독 의사 간 일치도**: 70~80% (20~30%는 다른 의사가 다르게 판독)
- **HER2 상태 변화**: 원발암 vs 재발·전이 시 달라지는 비율 20~30%
- **권고**:
  - 재발·전이 시 반드시 재생검 + HER2 재검사
  - 대형 병원 세컨드 오피니언 고려 (특히 HER2-low 경계 케이스)

## 예후 개선 수치

- 전이성 유방암 4기 3년 생존율: 기존 10% 미만 → ADC 도입 후 20~25%
- 림프절·내장 전이 환자: 생존 기간 2~4년 연장

## 임상적 의의
- HER2-low 개념 등장으로 수십만 명의 유방암 환자가 표적 치료 대상이 됨
- ADC는 기존 표적치료제와 화학항암제의 장점을 결합한 새로운 패러다임
- 비용과 보험 문제가 실질적 접근의 핵심 장벽 — 환자 지원 프로그램 적극 활용 필요

## 환자 실전 조언
- 자신의 정확한 IHC 점수 확인 (0 / 1+ / 2+ / 3+)
- "제가 HER2-low인데 엔허투 치료 가능한가요?" 적극 질문
- 재발·전이 시 재생검 요청
- 소규모 병원에서 최신 개념 미숙 가능 → 적극적 정보 탐색
