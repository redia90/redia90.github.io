# 트리플 네거티브 유방암 (TNBC) 치료

## 개요
트리플 네거티브 유방암(ER-, PR-, HER2-)은 전체 유방암의 15-20%이나,
호르몬요법과 HER2 표적치료 모두 적용되지 않아 오랫동안 화학요법만 가능했다.
최근 면역관문억제제(펨브롤리주맙)와 [[PARP억제제]], ADC(삭시투주맙 고비테칸)가 도입되면서
치료 옵션이 빠르게 확장되고 있다.

## TNBC는 한 가지 병이 아니다 — Lehmann 분자 서브타입 (2011·2016)

TNBC를 단일 질환으로 보면 안 됨. 6개 분자 서브타입이 존재 (Lehmann 분류):

| 서브타입 | 약자 | 특성 | 치료 적응 가능성 |
|----------|------|------|-------------------|
| **Basal-like 1** | BL1 | DNA 손상 복구 결핍 — gBRCA-like | **백금 + PARP 반응 ↑** |
| **Basal-like 2** | BL2 | Wnt/IGF1R 경로·세포 성장 | EGFR·mTOR 표적 임상 |
| **Mesenchymal** | M | EMT·운동성 | 항섬유화 표적 |
| **Mesenchymal Stem-like** | MSL | EMT + 줄기세포성 | TGF-β·angiogenesis 표적 |
| **Luminal AR** | **LAR** | **AR 양성**, ER-/PR- | **bicalutamide·enzalutamide** 임상 |
| **Immunomodulatory** | IM | 면역 활성 (면역항암 반응 ↑) | **펨브롤리주맙·면역항암 표적** |

**임상 활용**:
- 본 분류는 **연구 단계** — 일상 임상에 아직 통합 안 됨
- 그러나 **AR+ TNBC**·**IM 서브타입**은 특수 임상시험 등록에 영향
- 진료실에서 환자가 "**제 TNBC 분자 서브타입이 뭔가요?**" 라고 물을 가치

### AR+ TNBC (Luminal AR / LAR)

전체 TNBC의 약 **10~15%**:
- **AR (Androgen Receptor) 양성**
- **상대적으로 천천히 자라는** 경향
- 예후는 평균적인 TNBC보다 나을 수 있음
- 표준 화학요법 반응 ↓ (BL1 대비)
- **임상시험 (bicalutamide·enzalutamide)** 일부 진행
- AR IHC ≥10% → AR+ 분류 (검사실별 cutoff 차이)

### IM 서브타입 — 면역항암 반응이 높은 군

- TIL ↑·PD-L1 ↑·면역 시그니처
- KEYNOTE-522·KEYNOTE-355에서 가장 좋은 반응 군
- → [[유방암면역_미생물군]] sTIL·PD-L1 CPS 측정 참조

### BRCA+ TNBC

- 전체 TNBC의 **약 15~20%**가 gBRCA 변이 양성
- **PARP 억제제 + 백금** 반응 ↑
- 신보조 → 수술 후 잔존병변 → **OlympiA 보조요법** (올라파립 1년)
- → [[BRCA유전자]]·[[PARP억제제]] 참조

## 임상시험 등록 동선

TNBC는 표적이 적어 임상시험이 가장 활발한 영역:

| 환자 상태 | 임상시험 등록 가능성 |
|-----------|----------------------|
| **PD-L1+ TNBC 1차** | ASCENT-04 (SG+pembro), TROPION-Breast03 |
| **PD-L1- TNBC 1차** | TROPION-Breast02 (Dato-DXd), 다트로웨이 |
| **TNBC + BRCA 변이** | [[PARP억제제\|PARP + 면역항암]] 병용 |
| **고위험 조기 TNBC** | KEYNOTE-522 후속 임상 |
| **TNBC 2차 후** | MK-2870 (사시투주맙 티르ぃ뮈탄) 3상 |
| **한국 신약** | 페니트리움 (현대ADM)·JW2286 (JW중외제약) 1상 |
| **HER2-low 전환된 TNBC** | [[HER2-low치료\|엔허투]] 적응증 |

→ [[임상시험|등록 흐름·환자 권리]] 참조

## 핵심 내용

### 표준 화학요법 (조기 TNBC)
- **신보조요법(NAC)**: 안트라사이클린 + 탁산 기반
- **병리학적 완전관해(pCR)**: 치료 성공 지표. TNBC에서 pCR 달성 시 예후 좋음
- **pCR 미달성 시**: 카페시타빈(젤로다) 보조요법 (CREATE-X 연구)

### 신보조요법 표준 레지멘 (KEYNOTE-522 기반)
1단계 (12주): 파클리탁셀 매주 + 카보플라틴 + 펨브롤리주맙(3주마다)
2단계 (12주): AC/EC(안트라사이클린+사이클로포스파마이드) 3주마다 + 펨브롤리주맙
→ 수술
보조: 펨브롤리주맙 유지 9사이클 (1년)
잔존 병변: 카페시타빈(젤로다) 추가

자세한 내용 → [[신보조화학요법]]

### 면역관문억제제 — 펨브롤리주맙 (키트루다)

#### KEYNOTE-522 (NEJM 2020·2022) — 조기 고위험 TNBC 신보조 ⭐

| 지표 | 펨브로 + 화학 | 위약 + 화학 |
|------|--------------|--------------|
| pCR | **64.8%** | 51.2% |
| 3년 EFS | **84.5%** | 76.8% |
| 5년 EFS (2024 update) | **81.3%** | 72.3% |
| 5년 OS | **86.6%** | 81.7% |

- **PD-L1 무관하게 효과** (조기 신보조에서)
- 보조: 펨브롤리주맙 1년 유지
- 잔존병변 (non-pCR): 카페시타빈 추가 (CREATE-X)
- **한국 보험 적용** ✅

#### KEYNOTE-355 (NEJM 2022) — 전이성 TNBC 1차 ⭐

| 지표 | 펨브로 + 화학 | 화학 단독 |
|------|--------------|----------|
| PFS (CPS≥10) | **9.7개월** | 5.6개월 (HR 0.65) |
| OS (CPS≥10) | **23.0개월** | 16.1개월 |
| PFS (전체) | 7.5 | 5.6 (유의 ❌) |

- **CPS ≥10에서만 유의** — 검사 핵심
- 화학요법 옵션: 파클리탁셀·nab-파클리탁셀·젬시타빈+카보플라틴
- 한국 보험 적용 ✅

#### 국내 허가: ✅ (CPS ≥10 전이성, 조기 고위험)

### 2026 1차 치료 분기 — PD-L1 양성 vs 면역항암 부적합

| 연구 | 대상 | 결과 |
|------|------|------|
| **ASCENT-04/KEYNOTE-D19** (NEJM 2026) | PD-L1+ 전이성 1차 | SG + pembro 중앙 PFS **11.2개월** vs chemo+pembro 7.8개월, ORR 60% vs 53%, DOR 16.5 vs 9.2 |
| **TROPION-Breast02** (Annals of Oncology 2026) | 면역항암 부적합 1차 | Dato-DXd 중앙 PFS **10.8개월** vs chemo 5.6, 중앙 OS **23.7개월** vs 18.7 |
| **carbo+nivolumab** (Nature Comm 2026) | 1차 전이성 | 전체군 PFS 유의 개선 **실패**, PD-L1+에서만 호전 경향 |

→ 학술 출처와 상세는 [[2026임상연구업데이트]]

### PARP 억제제 ([[BRCA유전자]] 돌연변이 보인자)
- **올라파립 (린파르자)**: gBRCA1/2 변이, HER2- 전이성 유방암
  - OlympiAD 연구: PFS 개선
- **탈라조파립 (탈젠나)**: gBRCA1/2 변이 전이성 유방암
  - EMBRACA 연구: PFS 개선
- 조기 유방암 보조요법: **OlympiA 연구** — 고위험 HER2- gBRCA 변이 조기 유방암에서 OS 개선
- **국내 허가**: ✅

### ADC — 삭시투주맙 고비테칸 (트로델비, Trodelvy)

#### ASCENT (NEJM 2021) — 2차+ 표준 정착

| 지표 | 트로델비 | 화학요법 |
|------|----------|---------|
| PFS | **4.8개월** | 1.7개월 (HR 0.41) |
| OS | **11.8개월** | 6.9개월 (HR 0.51) |
| ORR | 31% | 4% |

- **기전**: Trop-2 표적 ADC + SN-38 탑재
- **적응증**: 전이성 TNBC 2차 이상 (2회 이상 선행치료)
- **부작용 감시**: **호중구 감소·설사·구내염** — 신독성 카보플라틴 대비 적음
- **국내 허가**: ✅

#### ASCENT-04 (2024) — 1차 PD-L1+ 트로델비 + 펨브롤리주맙 ⭐

| 지표 | 트로델비 + 펨브로 | 화학 + 펨브로 |
|------|---------------------|---------------|
| PFS (CPS≥10) | **11.2개월** | 7.8개월 |
| ORR | 60% | 53% |
| DOR (반응 지속 기간) | **16.5개월** | 9.2개월 |

- **임상적 함의**: PD-L1+ 전이성 TNBC 1차에서 **화학 → ADC 전환** 가능성
- 한국 도입 진행 — 보험 적용 검토

#### ASCENT-03·05·07 (진행 중)
- 추가 적응증 확장 임상 — 1차 단독·신보조·조기 보조

**2026 진행**: 국내 급여 협의, PD-L1 음성 환자 대상 **1차 치료 단독 임상** 진행, 키트루다 병용 임상 중간 결과 발표

### 차세대 ADC (2026 임상)

| 약제 | 표적 | 단계 |
|------|------|------|
| **다트로웨이 (Dato-DXd)** | Trop-2 | PD-L1 낮은 환자에서도 효과 보고, 일부 승인 진행 |
| **MK-2870 (사시투주맙 티르고테칸)** | Trop-2 | 전이성 TNBC 1차 3상 임상 승인 |
| **페니트리움 (국내)** | — | 전임상·1상 (현대ADM), 키트루다 병용 1상 IND |
| **JW2286 (국내)** | STAT3 | 1상 승인 (JW중외제약) |

### 전이성 TNBC 1상 병용 임상 (카페 TOP50 #37)

카페에서 회자된 전이성 TNBC 임상 신약·병용 조합:

| 조합 | 핵심 |
|------|------|
| **티센트릭 + 아브락산 + 이파타서팁** | 면역항암제 + nab-paclitaxel + AKT 억제제 — IPATunity130 |
| **오니바이드 (이리노테칸 리포좀)** | 전이성 TNBC 후기 치료 옵션 임상 |
| 트로델비 + 키트루다 | Trop-2 ADC + 면역 — 중간 결과 발표 |

> 💡 환자 활용 포인트: 표준치료 진행·내성 시점에 **임상시험 등록을 미리 준비**. 임상은 약효뿐 아니라 대상 조건·이전 치료 이력·바이오마커·거리·비용을 함께 평가.

### 백금 기반 항암제
- [[BRCA유전자]] 돌연변이 TNBC에서 특히 효과적
- 카보플라틴, 시스플라틴
- 상동재조합결핍(HRD) 양성에서 효과 예측

### BRCA+ TNBC 치료 동선

BRCA 변이 TNBC는 **표준 TNBC와 다른 동선** — 환자별 적응증 변동:

#### 조기 (수술 가능)
1. **신보조요법** — 표준 KEYNOTE-522 (펨브로 + 화학)
   - 또는 BRCA+ 환자에서 **백금 추가** 임상 (BrighTNess·GeparOcto)
2. **수술 + 보조**
3. **pCR 달성** → 펨브롤리주맙 유지만
4. **잔존병변 (non-pCR) + BRCA+** → **올라파립 1년 (OlympiA)** + 펨브롤리주맙
   - **OlympiA (NEJM 2021)**: 4년 iDFS 82.7% vs 75.4% (HR 0.63)
   - OS 4년 89.8% vs 86.4%

#### 전이성 TNBC + BRCA+
1. **1차**: PARP 억제제 또는 화학요법 (펨브로 PD-L1+ 시)
   - **OlympiAD (NEJM 2017)**: 올라파립 PFS 7.0 vs 4.2개월
   - **EMBRACA**: 탈라조파립 PFS 8.6 vs 5.6개월
2. **2차+**: 트로델비 + 면역항암 (PD-L1+)
3. **3차+**: 임상시험·HRD 기반 추가 옵션

#### gBRCA 검사 — 모든 TNBC 환자
- **60세 미만 TNBC 전수 검사** 권고 (NCCN)
- 양성 시 가족 검사 + 예방적 절제 검토
- → [[유전자검사]]·[[BRCA유전자]]·[[PARP억제제]]

## 치료 알고리즘 (전이성 TNBC)
```
1차:
  - PD-L1(CPS≥10): 펨브롤리주맙 + 화학요법
  - gBRCA 변이: PARP 억제제 고려
  - 기타: 화학요법 (젬시타빈/카보플라틴, 카페시타빈 등)
  ↓ 진행
2차:
  - 트로델비 (삭시투주맙 고비테칸)
  - gBRCA 변이: PARP 억제제 (미사용 시)
  ↓ 진행
3차 이상: 임상시험 적극 고려
```

## 뇌전이 TNBC

TNBC는 **뇌전이 발생률 30~50%** (특히 4기에서)로 가장 높은 서브타입 중 하나:

### 뇌전이 빈도
- 전체 TNBC: 진단 시 5~10%
- 전이성 TNBC 진행 중: 누적 30~50%
- 다른 서브타입 대비 약 2배

### 치료 옵션
| 옵션 | 적응증 |
|------|--------|
| **국소 방사선 (SRS·WBRT)** | 1~5개 병변 — 사이버나이프/감마나이프 |
| **전뇌 방사선 (WBRT)** | 다발성 (5개+) — 인지 부작용 평가 |
| **수술** | 단일 큰 병변·증상성 |
| **펨브롤리주맙** | 뇌·뇌막 부분 침투 가능성 |
| **트로델비** | 뇌 내 효과 일부 보고 |
| **이리노테칸 (오니바이드)** | 임상 |
| **카페시타빈** | 뇌 통과 가능, 일부 효과 |
| **HER2-low로 전환된 경우** | [[HER2-low치료\|엔허투]] 뇌 효과 일부 |

### 예방·감시
- 뇌 MRI는 **증상 있을 때**만 권고 (무증상 정기 미권고)
- 새 두통·시야 변화·신경학적 변화 → 즉시 평가
- → [[전이경고신호]] 뇌·연수막 섹션

## 부작용 프로파일

### 면역관문억제제 (펨브롤리주맙/키트루다) — 자가면역 반응
면역세포를 활성화시켜 암세포를 공격하게 만드는 약제 특성상, **암세포뿐 아니라 정상 세포도 공격**할 수 있음.

**내분비 기관 자가면역 (가장 흔한 패턴)**:
- 갑상선 기능 이상 (갑상선염, 갑상선기능저하증)
- 부신 기능 저하 (부신 피질 호르몬 부족)
- 뇌하수체 기능 저하

**기타 자가면역 부작용**:
- **폐**: 자가면역성 폐렴 (호흡 곤란, 기침)
- **간**: 자가면역성 간염 (간수치 상승)
- **피부**: 두드러기, 심한 발진

> ⚠️ 면역관문억제제 부작용은 다른 항암제와 양상이 완전히 다름. 새로운 증상 발생 시 즉시 담당의에게 보고 필요. 조기 발견·치료(스테로이드 등)가 중요.

## 미해결 질문 / 연구 방향
> 💡 펨브롤리주맙 반응 예측 바이오마커 (PD-L1 외)

>
> 💡 ADC 병용 요법 독성-효과 균형
>    → **답변**: 트로델비 + 펨브로 (ASCENT-04) — PFS 11.2개월 vs 7.8 (PD-L1+). 다트로웨이·MK-2870 병용 임상 진행. 독성 (호중구·구내염·설사) 누적 — 용량·일정 조정이 핵심.
>
> 💡 뇌전이 TNBC 치료 옵션
>    → **답변**: 표준 — 방사선 (SRS·WBRT) + 화학요법. 새 옵션 — 펨브로·트로델비·HER2-low 전환 시 T-DXd. 임상시험 등록 적극 검토. 사이버나이프·감마나이프 우선.
>
> 💡 Lehmann LAR 한국 임상시험 기관
>    → **답변**: 서울대·삼성·아산·세브란스·국립암센터에서 Lehmann 분류 연구 일부 진행. AR+ TNBC 환자 — bicalutamide·enzalutamide 임상시험 cris.nih.go.kr·clinicaltrials.gov 검색.
>
> 💡 ASCENT-04 한국 도입·보험 적용
>    → **답변**: 결과 발표 (2024) — PD-L1+ 1차 PFS 11.2 vs 7.8개월. 한국 도입 진행 — 보험 적용 평가 단계. **2027** 예상.
