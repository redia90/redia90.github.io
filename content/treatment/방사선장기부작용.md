# 방사선 치료의 장기 부작용 — 심장·폐·이차암 추적

## 개요
[[방사선치료|유방암 방사선 치료]]는 치료 즉시 효과가 크지만 **5~30년 후 심장·폐·이차암 위험**이 보고된다. 1990년대 이전 기법에서 가장 컸고, IMRT/IGRT/DIBH 등 정밀 기법 도입 후 위험은 크게 감소했다. 그러나 좌측 유방 환자·젊은 환자·고용량 방사선 환자에서는 여전히 **장기 추적이 필요**하다. 이 페이지는 단기 피부 반응([[방사선치료]]·[[치료준비물]] 참조)과 분리해 **5년 이후 장기 부작용**을 정리한다.

## 핵심 내용

### 1. 심장 독성 (Cardiac Toxicity) — 가장 중요

**Darby NEJM 2013 핵심 연구**:
- 좌측 유방암 환자 2,168명 분석
- **심장 평균 선량 1 Gy 증가당 허혈성 심질환 위험 7.4% 증가**
- 효과는 노출 후 **5~10년 이내** 나타나기 시작, **20년 이상 지속**

**고위험 환자**:
- 좌측 유방암 (심장이 왼쪽으로 치우침)
- 고용량 방사선 노출 (특히 보조 부스트)
- 기존 심혈관 질환·당뇨·고혈압·흡연
- 안트라사이클린(독소루비신·에피루비신) 또는 [[HER2표적치료|허셉틴]] 동반 노출

**누적 심독성 — 안트라사이클린 + 허셉틴 + 방사선 삼중 노출**:
- [[항암화학요법|안트라사이클린(독소루비신·에피루비신)]]: 누적 용량 의존성 심독성
- [[HER2표적치료|허셉틴]]: LVEF 감소 (보통 가역적)
- 좌측 방사선: 심장 노출 추가
- 세 노출 동반 환자는 **누적 위험 증가** — 정기 심초음파 강화 필요

**현대 기법으로 위험 감소**:
- **IMRT/VMAT**: 심장 노출 평균 선량 감소
- **DIBH (깊은 숨 멈춤)**: 심장이 뒤·아래로 이동 → 노출 줄어듦
- **3D 정밀 계획·IGRT**: 일관된 자세 보정
- 현재 평균 심장 선량은 과거 대비 약 1/3~1/2 수준

#### 기법별 평균 심장 선량 (MHD, Mean Heart Dose) 비교

| 기법·시점 | 평균 MHD (좌측 유방) | Darby 1Gy당 7.4% 위험 적용 |
|----------|---------------------|--------------------------|
| **1980~1990년대 2D** | 약 5~6 Gy | +37~44% 허혈 위험 |
| **3D 적합 (3D-CRT)** | 약 3~4 Gy | +22~30% |
| **IMRT/VMAT** | 약 1~2 Gy | +7~15% |
| **IMRT + DIBH** | 약 0.5~1 Gy | +4~7% |
| **양성자치료 (선택 환자)** | <0.5 Gy | <4% |

> 💡 **본인 치료 시점·기법 확인**이 위험 평가의 출발점. 1990년대 이전 환자 ≠ 2020년대 환자. 본 병원 방사선종양학과에 **본인 MHD** 문의 가치 ↑.

#### DIBH (Deep Inspiration Breath Hold) 적응증·효과

| 항목 | 내용 |
|------|------|
| **적응증** | 좌측 유방암 + 심장 가까운 환자 (선택적 — 모든 환자는 아님) |
| **방법** | 환자가 숨을 깊이 들이마신 후 멈춘 상태로 방사선 조사 (각 분획 약 15~25초) |
| **효과** | MHD 약 **50% 감소** (1.2 → 0.6 Gy 등) |
| **단점** | 환자 협조 필요 (호흡 패턴 훈련), 치료 시간 약 5~10분 추가 |
| **한국 도입** | 대형 종합병원·일부 검진센터·민간 방사선치료센터 도입 중 |
| **비용** | 기본 방사선치료에 포함 — 추가 비용 ❌ (보통) |

#### 양성자치료 (Proton Therapy) — 선택적 옵션

- **장점**: Bragg peak 특성으로 심장·폐 노출 거의 ❌
- **적응증**: 좌측 유방암 + 림프절 조사 필요 + 심장 가까운 경우 + 젊은 환자
- **한국 시설**: 국립암센터·삼성서울 등 (양성자치료센터 운영)
- **비용**: 보험 일부 적용 (적응증별), 비급여 시 약 2,000~3,000만 원
- **단점**: 비용, 접근성, 일부 환자에서만 명확한 이득

**추적 권고**:
- 치료 종료 후 5년부터 심혈관 위험 평가 시작
- 흉통·운동 시 호흡곤란 시 즉시 평가
- 좌측 유방 + 고위험 인자 보유 시 **정기 심초음파·LVEF 검사** 고려

### 2. 방사선 폐렴·폐섬유증

**급성 방사선 폐렴 (Radiation Pneumonitis)**:
- 치료 종료 후 **1~6개월** 발생 (치료 시작 후~종료 1~3개월 사이 흔함)
- 빈도: 1~3% (현대 기법)
- 증상: **마른 기침·운동 시 호흡곤란·미열·가래·흉통** — 감기처럼 시작해 빠르게 진행 가능
- 치료: 스테로이드 (프레드니솔론) 4~6주, 감염 동반 시 항생제, 휴식

> ⚠️ **응급 평가 기준** (카페 환자 경험 정리, 게시글 #47): **38도 이상 발열·녹색/누런 가래·흉통·호흡곤란** 동반 시 즉시 본병원·응급실. 일반 감기로 자가 판단 후 진행되면 입원이 길어진다.

**만성 방사선 폐섬유증**:
- 치료 종료 후 **6개월~수년** 진행
- 영상에서 방사선 조사 부위에 섬유성 변화
- 무증상~경증 호흡곤란
- 비가역적 — 예방이 핵심

**위험 요인**:
- 폐 선량 V20 (20Gy 받는 폐 부피) 증가
- 흡연
- 기존 폐질환 (COPD·간질성 폐질환)
- [[HER2표적치료|T-DXd 등 ILD 위험 약제]] 병용

### 3. 이차암 (Second Malignancy)

방사선 노출 부위·인접 부위의 이차암 위험:

| 이차암 | 위험 증가 | 잠복기 |
|---------|-----------|--------|
| **반대편 유방암** | 약간 증가 (특히 45세 미만 진단) | 10년 이후 |
| **혈관육종 (Angiosarcoma)** | 절대 위험 0.05~0.3%, 상대 위험 16~70배 | 5~10년 |
| **폐암** | 좌측 환자·흡연자에서 증가 | 10~20년 |
| **식도암** | 미미한 증가 | 10년 이후 |
| **갑상선암** | 미미한 증가 | 10년 이후 |
| **혈액암 (백혈병)** | 안트라사이클린 동반 시 증가 (방사선 단독 영향 작음) | 5~10년 |

**가장 우려되는 이차암 — 혈관육종**:
- 절대 빈도는 매우 낮음 (0.05~0.3%)
- 그러나 진단 시 예후 매우 나쁨
- 방사선 부위 피부에 **새 멍울·변색·궤양** 발견 시 즉시 평가
- 카페 사례에서도 드물지만 보고됨

### 4. 림프부종 — 수술 + 방사선 동반 시

- 액와 림프절 곽청술 + 방사선 동반 시 림프부종 위험 약 **30%**
- 감시 림프절 생검 + 방사선만이면 **5~10%**
- [[유방암수술|림프부종 예방·재활]] 참조

### 5. 어깨·팔 기능 제한

- 방사선 후 어깨·겨드랑이 섬유화
- 수술 후 재활과 함께 6~12개월 적극 관리
- 림프 도수치료·물리치료 도움 가능 ([[요양병원선택]])

### 6. 골밀도 감소 — 늑골 골절 위험

- 방사선 조사 부위 늑골의 골밀도 감소
- 5~10년 후 가벼운 충격으로 늑골 골절 가능
- 칼슘·비타민D 보충, 골밀도 검사 정기 추적
- [[호르몬치료|AI 복용]]과 합쳐지면 위험 증가

### 7. 피부·연조직 만성 변화

- 색소 침착·모세혈관 확장 (telangiectasia)
- 피부 위축·탄력 저하
- [[유방재건수술|보형물 재건]] 시 피막 구축 위험 증가
- 미용 결과 시간에 따라 변화

## 좌측 유방암 환자의 특별 고려

**위험 인자가 겹치는 그룹**:
- 좌측 유방암 (심장 위치)
- 안트라사이클린 사용 (심장독성 누적)
- [[HER2표적치료|허셉틴]] 사용 (LVEF 감소)
- 고령·고혈압·당뇨·흡연 동반

**권고**:
1. DIBH·IMRT 가능 병원 선택 검토
2. 치료 전·중·후 LVEF 추적 (특히 허셉틴 동반 시)
3. 치료 종료 5년 후부터 심혈관 위험 평가 시작
4. 금연·체중 관리·운동 ([[운동수면위생]])

## 추적 일정 — 장기 부작용 평가

| 시점 | 평가 항목 |
|------|-----------|
| 치료 종료 후 6개월 | 급성 폐렴·피부 회복 |
| 1~2년 | 어깨·팔 기능, 림프부종, 피부 변화 |
| **3~5년** | 골밀도(특히 AI 복용), 림프부종 추적 |
| **5~10년** | **심혈관 위험 평가 시작** (좌측·고위험) |
| 10년 이후 | 반대편 유방 모니터, 이차암 인지 (혈관육종·폐암) |
| 20년 이후 | 누적 심혈관 위험 — 환자 자가 인지 필요 |

→ 추적 일정 통합은 [[치료후삶]] 참조

### 통합 추적 가이드 — 환자별 시나리오

#### 시나리오 A: 좌측 유방 + 안트라사이클린 + 허셉틴 + IMRT/DIBH
**누적 심독성 최대 위험군** — 통합 추적:

| 시점 | 검사 | 주관 과 |
|------|------|---------|
| 치료 시작 전 | LVEF (심초음파 또는 MUGA), 심전도 | 종양내과 + 심장내과 |
| 허셉틴 중 3·6개월 | LVEF 추적 | 종양내과 |
| 방사선 종료 후 6개월 | 흉부 X-ray (폐렴) | 방사선종양학과 |
| 1·2·3년 | LVEF·심전도, 흉부 X-ray | 종양내과 + 심장내과 |
| **5년부터** | 심혈관 위험 평가 (콜레스테롤·혈압·당뇨) | 심장내과 |
| 10년 이후 | 혈관 영상 (관상동맥 칼슘 score·CT 등) | 심장내과 |
| 20년 이후 | 환자 자가 인지 (흉통·운동 시 호흡곤란) | 본인 |

#### 시나리오 B: 우측 유방 + IMRT (심장 위험 낮음)
- 5년까지 어깨 ROM·림프부종·피부 추적
- 10년 이후 이차암 (반대편 유방·드물게 폐암) 추적
- 심혈관 위험은 일반 인구 기준

#### 시나리오 C: 좌측 유방 + 2D 방사선 (1990년대 이전)
- **누적 심독성 가장 큼** — 정기 심혈관 검진 필수
- 20년 이후도 환자 자가 인지·증상 시 즉시 평가
- 카페에서 "오래 전 방사선 후 50대에 심근경색" 사례 보고 多

#### 시나리오 D: 노인 + 저위험 + 호르몬 치료 단독 (방사선 생략)
- **PRIME II (NEJM 2023)**: 65세 이상 저위험 환자에서 방사선 생략 가능성 — 10년 국소 재발 9.5% vs 0.9% (방사선 ↓ 차이), 그러나 사망률 동일
- 본인 케이스가 PRIME II 적응증인지 의료진 상의 가치

### 환자가 본인 위험 평가 시 확인할 항목

방사선 종료 후 의무기록·치료 보고서에서 확인:
1. **방사선 부위**: 좌측 vs 우측, 흉벽 vs 림프절 포함
2. **총 선량 (Total Dose)**: 보통 40~50 Gy, 부스트 포함 시 60 Gy+
3. **분획 (Fractionation)**: 표준 25회 vs 소분할 15~16회 vs 초소분할 5회
4. **기법**: 2D vs 3D vs IMRT/VMAT vs DIBH vs 양성자
5. **MHD (Mean Heart Dose)**: 본 병원 방사선종양학과에 요청 — 정확한 본인 수치
6. **MLD (Mean Lung Dose) + V20**: 폐 위험 평가
7. **동반 약제**: 안트라사이클린·허셉틴 노출 여부
8. **방사선 시점**: 1990년대 이전 vs 2010년대 이후

> 💡 본 정보가 정리되어 있으면 향후 어느 병원에서도 본인 장기 위험을 정확히 평가받을 수 있다. **치료 종료 시 의무기록 사본 보관** 권장.

## 종료 후 1~2주 피부 악화 — 환자 경험 패턴 (TOP50 2페이지 2026-05)

방사선 단기 부작용으로 분류되지만, 카페 경험에서 반복되는 **종료 후 피부 악화 시기**는 별도 주의 필요:

| 시점 | 증상 | 대응 |
|------|------|------|

### 카페 환자 경험 — 종료 후 피부 관리 핵심 (TOP50 2페이지)
- 종료 후 1~2주에 가장 나빠질 수 있음 — **종료 = 안심** 아님
- 처방 보습크림으로 진물 안 잡히면 본원 → 피부과 → **화상 전문병원** 단계 검토
- 분당서울대병원 안내서 (게시글 #46): 치료부위 **문지름·반창고·테이프·로션·화장·직사광선·뜨거운 찜질 모두 금지**, 느슨한 부드러운 옷, 수술 팔 주사·수혈·무거운 물건 회피

## 환자 자가 인지 — 즉시 평가가 필요한 신호

- 흉통·운동 시 호흡곤란 → 심혈관 평가
- 마른 기침·호흡곤란 (특히 종료 후 1~6개월) → 폐렴 평가
- 방사선 부위 피부의 **새 멍울·변색·궤양** → 혈관육종 의심
- 가벼운 충격 후 갈비뼈 통증 → 골절 평가
- 팔 부종·무거움·뻐근함 → [[유방암수술|림프부종]] 평가
