# 약사 협진 — 약물 상호작용·다약제 검토

## 개요
유방암 환자는 항암·표적·호르몬·CDK4/6·진통제·정신과 약·만성질환 약 등 **5~10가지 약물**을 동시 복용하는 경우가 많다. 약물 상호작용(특히 **CYP3A4·CYP2D6·QT 연장**)을 놓치면 치료 효과 감소 또는 부작용 증가로 이어진다. 본 페이지는 환자·보호자·의료진이 약사 협진을 활용할 방법과 핵심 상호작용을 정리한다.

## 핵심 상호작용 — 유방암 환자에서 자주 발생

### 1. 타목시펜 ↔ CYP2D6 억제제

**[[호르몬치료|타목시펜]]은 CYP2D6에 의해 활성 대사물 (endoxifen)로 전환**:

| 회피·신중 | 비교적 안전 |
|------------|--------------|
| 파록세틴 (Paxil) | 시탈로프람 (Celexa) |
| 플루옥세틴 (Prozac) | 에스시탈로프람 (Lexapro) |
| 부프로피온 (Wellbutrin) | 벤라팍신 (Effexor) |
| 일부 항부정맥 약 | 데스벤라팍신 |

→ 우울·갱년기 증상 약물 시작 전 약사 협진 — [[유방암환자정신건강]] 참조

### 2. CDK4/6 억제제 ↔ CYP3A4

**[[CDK46억제제|입랜스·키스칼리·버제니오]]는 CYP3A4 대사**:

| 회피 (강한 CYP3A4 억제·유도) |
|---------------------------|
| 자몽·자몽주스·세빌리야 오렌지·포멜로 |
| 케토코나졸·이트라코나졸 (항진균) |
| 클라리스로마이신·에리스로마이신 (항생) |
| 일부 칼슘 길항제 (베라파밀) |
| 리팜핀·페니토인 (CYP3A4 유도) |

### 3. QTc 연장 약물 ↔ 리보시클립 (키스칼리)

[[CDK46억제제|리보시클립]]은 자체 QTc 연장 위험 — 함께 회피:
- 항부정맥 (amiodarone·sotalol)
- 일부 항생제 (azithromycin·moxifloxacin)
- 일부 항우울제 (citalopram 고용량)
- 항진균제 (fluconazole)
- 항구토제 (ondansetron 고용량)

### 4. vepdegestrant ↔ QTc·CYP

[[호르몬치료|vepdegestrant]] (PROTAC ER degrader):
- QTc 연장 — 위와 동일 약물 회피
- CYP3A4 영향 약물 검토
- 강한 태아독성 — 가임 환자 [[가임력보존]] 검토

### 5. PARP 억제제 ↔ 골수억제 약물

[[PARP억제제|올라파립·탈라조파립]]:
- 다른 골수억제 약물과 누적 효과
- 항생제 일부 (TMP-SMX 등)
- 항암제 동시 사용 신중

### 6. 마약성 진통제 ↔ 진정제·항우울제

- 호스피스·말기 환자에 자주 동시 처방
- 호흡 저하·진정 증강 위험
- [[호스피스완화의료|완화의료팀]]·약사 협진 필수

### 7. 한약·보충제 ↔ 표준치료

[[보조요법주의|보조요법]]·민간요법 중 약물 상호작용 우려:
- **세인트존스워트 (St. John's wort)**: CYP3A4 강력 유도 — 거의 모든 표적치료 감소
- **고용량 비타민 C**: 항암제 일부 효과 감소 가능
- **녹차 추출물**: 보르테조밉 등 일부 약제 길항
- **홍삼·인삼**: [[호르몬양성식이|호르몬 양성 회피]] + 항응고제 상호작용
- **마늘 보충제**: 항응고제 ↑

### 8. OTC 진통·소화·감기약 ↔ 항암·표적치료

약국에서 처방전 없이 구입하는 약도 상호작용 가능:

| OTC 약물 | 주요 우려 | 권장 행동 |
|----------|-----------|------------|
| **NSAID** (이부프로펜·나프록센·아스피린) | 혈소판 감소 시기 출혈 위험 ↑, 신독성 약제(시스플라틴) 누적, [[PARP억제제]] 골수억제 누적 | 항암 중 가능한 아세트아미노펜 우선 |
| **아세트아미노펜 (타이레놀)** | 일반적 안전, 단 **간수치 ↑·간 부담 항암제**와 누적 | 하루 3g 이내, 간수치 모니터링 |
| **PPI** (오메프라졸·란소프라졸 등) | **카페시타빈(젤로다)** 흡수 ↓, 일부 TKI(라파티닙) 흡수 ↓ | 시간 간격·H2 차단제 대안 검토 |
| **H2 차단제** (라니티딘·파모티딘) | 위 흡수 변화 약제와 시간 간격 | 의료진 상의 |
| **항히스타민제** (지르텍·알레그라) | QTc 연장 일부 약제와 누적, 진정 중복 | 키스칼리·말기 진정 시 신중 |
| **감기약 (디히드로코데인 함유)** | 마약성 진통제와 누적 호흡 저하 | 호스피스 환자 회피 |
| **변비약** (마그밀·둘코락스·락툴로오스) | 일부 항암제 흡수에 영향, 전해질 변동 | 의료진 상의 후 사용 |
| **지사제** (로페라마이드) | 아베마시클립 설사 표준 — 의료진 가이드 따라야 | 자가 용량 임의 증량 금지 |

> 💡 카페에서 "감기약 먹어도 되나요" 질문 빈도 1위 — 일반 감기 증상은 **수분·휴식·아세트아미노펜** 우선, 코데인 함유 종합감기약은 회피.

### 9. 만성질환 동반약 ↔ 유방암 치료 (한국 흔한 시나리오)

한국 유방암 환자는 50대 진단이 많아 **고혈압·당뇨·갑상선·고지혈증** 동반이 흔하다:

#### 고혈압약
| 약물 | 유방암 치료 상호작용 |
|------|---------------------|
| **베라파밀·딜티아젬** | CYP3A4 억제 → [[CDK46억제제\|CDK4/6]]·일부 표적치료 농도 ↑ → 회피 또는 대안 |
| **암로디핀·로사르탄·텔미사르탄** | 비교적 안전 |
| **아테놀롤·비소프롤롤 (β차단제)** | QTc 환자 모니터링 |
| **이뇨제** | 전해질 변동 — 리보시클립 QTc 환자 주의 |

#### 당뇨약
| 약물 | 유방암 치료 상호작용 |
|------|---------------------|
| **메트포민** | 안전·일부 항암 보조 가능성 연구 |
| **DPP-4·SGLT-2 억제제** | 비교적 안전 |
| **인슐린** | 항암 중 식사 변화·스테로이드 사용으로 용량 조정 |
| **설포닐우레아** | 저혈당 위험 — 식욕부진 시기 주의 |
| **PI3K 억제제 (알페리시브)** | 고혈당 부작용 — 당뇨약 강화 필요 가능 |

#### 갑상선약
| 약물 | 유방암 치료 상호작용 |
|------|---------------------|
| **레보티록신 (씬지로이드)** | 식이섬유·칼슘·철분과 흡수 ↓ → 공복 복용 + 30분 간격 |
| | 면역항암제 (키트루다)로 인한 **자가면역성 갑상선염** 시 용량 조정 |

#### 고지혈증약
| 약물 | 유방암 치료 상호작용 |
|------|---------------------|
| **심바스타틴·로바스타틴** | **CDK4/6 억제제와 자제** — CYP3A4 경쟁 |
| **로수바스타틴·프라바스타틴** | 비교적 안전 |
| | 항암 중 일부 약제 간수치 ↑ 시 일시 중단 검토 |

#### 항응고·항혈소판
| 약물 | 유방암 치료 상호작용 |
|------|---------------------|
| **와파린** | CYP 변동 약제 시작 시 INR 모니터 |
| **DOAC (자렐토·엘리퀴스)** | 일부 표적치료와 상호작용 — 약사 협진 |
| **아스피린** | 혈소판 감소 시기 출혈 위험 |

> ⚠️ **항암 시작 전 만성질환 약 전체 점검**이 표준. 환자 본인이 "고혈압·당뇨·갑상선약은 평생 먹는 약이라 영향 없다"고 생각해 보고를 누락하는 경우 多 — 모두 보고.

## 약사 협진 절차

### 시점
- **진단 직후 — 1회**: 기존 모든 약물·보충제 평가
- **새 약제 시작 전 — 매번**: 추가 약물과 기존 약물 상호작용 평가
- **6개월~1년 — 정기**: 누적 약물 재평가
- **부작용 발생 시**: 즉시 약사 협진

### 환자가 준비할 것
1. **현재 복용 약물 전체 목록**:
   - 처방약 + OTC + 한약 + 보충제 + 영양제
   - 용량·복용 시간·시작일
2. **알레르기·부작용 이력**
3. **만성질환 동반** (당뇨·고혈압·갑상선 등)
4. **임신 계획**·[[가임력보존]] 검토 여부

### 카페 실전 팁 — 새 영양제·보충제 시작 동선 (TOP50 #17, #28)

새 영양제·한약·보충제를 시작하기 전:

1. **성분표 사진** 촬영 (앞·뒤·옆 라벨 전체)
2. 진료 시 또는 메시지로 **담당의·약사에게 사진 전송**
3. 답변 확인 전까지 **복용 시작 보류**
4. 시작 후 **첫 1주 간수치·증상 변화** 모니터링
5. 의심 증상 시 즉시 중단 + 보고

> 💡 환자들이 가장 자주 빠뜨리는 약: **눈 영양제·홍삼·즙류·한약** — "건강식품이라 약이 아니다"라고 생각해 보고를 누락하는 경향. **모든 입에 들어가는 것은 약**으로 간주.

### 한국 자원
- **대형 암 센터 종양약학과**: 약사 직접 상담 가능 (서울대·아산·삼성·연세 등)
- **약국 약사 상담**: 일반 처방 검토
- **공공기관**:
  - 식약처 의약품안전정보 (drugsafe.mfds.go.kr)
  - 의약품 상호작용 데이터베이스 (DrugInfo)
- **모바일 앱**: Lexicomp·Medscape (영어), 일부 한국 앱

## 자주 묻는 약물 검토 사례

### 사례 1: 타목시펜 + 우울증
- 환자: ER+ 폐경 전, 타목시펜 5년 + 산후 우울
- 평가: 파록세틴 회피 → 시탈로프람으로 처방 변경
- 결과: 타목시펜 활성 유지 + 우울증 치료

### 사례 2: CDK4/6 + 자몽
- 환자: 전이성 ER+ 1차, 키스칼리 처방
- 평가: 자몽주스 매일 섭취 발견 → 회피 권고
- 결과: 약제 농도 정상화·QTc 안정

### 사례 3: 4기 환자의 다약제
- 환자: 70세, 4기 ER+, 페마라+버제니오+골다공증 약+고혈압·당뇨 약+우울증 약
- 평가: 12가지 약물 — 8가지 상호작용 확인
- 결과: 일부 약제 변경·시간 조정·정기 모니터

→ [[노인유방암|노인 환자]]에서 특히 중요

### 사례 4: 50대 동반 만성질환 (한국 흔한 패턴)
- 환자: 52세, ER+ 2기, **고혈압 + 당뇨 + 갑상선기능저하 동반**
- 기존 약: 암로디핀, 메트포민, 레보티록신 (씬지로이드)
- 새 처방: 타목시펜 + 졸라덱스 + 칼슘·비타민 D
- 평가:
  - 암로디핀·메트포민·레보티록신은 타목시펜과 직접 상호작용 ❌ (안전)
  - **레보티록신 공복 복용 + 칼슘은 30분 간격** 필요
  - 타목시펜 → CYP2D6 정상 활성 확인 (특이 약물 없음)
- 결과: 약 5종 모두 유지, 복용 시간 재구성

### 사례 5: PPI + 카페시타빈 (젤로다)
- 환자: 60대 ER+ 전이성 + 위염으로 오메프라졸 장기 복용
- 새 처방: 카페시타빈 (젤로다) — 위 산성 환경에서 흡수
- 평가: PPI가 카페시타빈 효과를 약 20~30% 감소시킬 수 있음
- 결과: PPI → H2 차단제 (파모티딘) 변경, 또는 카페시타빈 복용 후 2시간 후 PPI

### 사례 6: 감기·복통 OTC
- 환자: 40대 ER+ 1기, 항암 중 (TC 3회차) 감기 증상
- 환자 자가 복용: 종합감기약 + 이부프로펜
- 평가: 호중구 최저점 시기 → 발열 평가 우선 (응급실 기준), 이부프로펜은 출혈·신장 위험
- 결과: 종합감기약 중단, 아세트아미노펜 + 38℃ 이상 시 응급실 평가

## 임상적 의의

- 약물 상호작용은 **무증상으로 약제 효과를 떨어뜨리는** 가장 흔한 오류
- 자몽 회피·타목시펜 SSRI 같은 단순 정보가 환자 결과에 직결
- 노인·4기 환자는 다약제 위험이 가장 큼 — 약사 협진이 필수
- 한약·보충제 자가 도입은 [[보조요법주의|보조요법 판단]] + 약사 협진 필요
- **한국 50대 진단 환자**는 동반 만성질환 동반 비율 높음 — 항암 시작 전 전체 약 점검 필요
- OTC 약은 환자가 자가 판단으로 복용하는 경우 多 — 진료 시 매번 "처방전 없이 사 먹는 약 있나요?" 질문 권장

## 환자가 가져갈 약 목록 양식 (병원 공유용)

진료실·약사 협진 시 휴대폰 메모 또는 종이에 다음 형식으로 정리:

```
[처방약]
1. 약 이름·용량·복용 시간 (예: 타목시펜 20mg, 매일 저녁 9시)
2. ...

[OTC·일반의약품]
1. 약 이름·용량·복용 빈도 (예: 타이레놀 500mg, 두통 시 PRN)
2. ...

[영양제·건강식품]
1. 제품명 + 성분명 (예: 종합비타민·비타민D 1000IU·오메가-3)
2. ...

[한약·보조식품]
1. 제품명 + 성분 (가능한 만큼)
2. ...

[복용 빈도]: 매일 / 주 N회 / 필요 시 (PRN)
[시작일]: YYYY-MM-DD
[특이사항]: 알레르기·과거 부작용
```
