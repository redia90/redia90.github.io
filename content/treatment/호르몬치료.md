# 유방암 호르몬 치료 (내분비 치료)

## 개요
에스트로겐 수용체(ER) 또는 프로게스테론 수용체(PR) 양성 유방암에서 호르몬 신호를 차단하는 치료다. 전체 유방암의 70~80%에 해당하며, 수술 후 재발 방지를 위해 일반적으로 5~10년간 지속한다. 폐경 전후에 따라 사용 약제가 달라지며, 최근에는 CDK4/6 억제제와 병용으로 효과를 높이고 있다.

## 역사 — "표적 치료의 어머니"

호르몬 치료는 **유방암 표적 치료의 시초**다 (한원식 강의, 2026):

| 시대 | 사건 |
|------|------|
| **1896 (영국)** | **George Thomas Beatson** — 양 난소 절제 시 젖 분비 멈춤 관찰 → 유방암 환자 난소 절제 시 진행 멈춤 발견 |
| **1970년대** | 에스트로겐 수용체(ER) 분자적 발견 |
| **1970~80년대** | **타목시펜** 개발·임상 도입 — 50년+ 사용, "가장 많은 암 환자를 살린 약" |
| **1990s 말~2000s** | **아로마타제 억제제 (AI)** 개발 — 폐경 후 표준 |
| **2002~** | **풀베스트란트 (파슬로덱스)** — 수용체 분해 (SERD) |
| **2010년대** | **난소기능억제 (OFS)** — 고위험 폐경 전 표준 추가 |
| **2015~** | **CDK4/6 억제제** — 호르몬 + 신호경로 병합 |
| **2025~2026** | **Oral SERD** (디레스트란트·엘라세스트란트) + **PROTAC** (vepdegestrant) — 새 작용기전 |

> 💡 "호르몬 치료 = 표적 치료의 어머니" — 환자 맞춤 치료·정밀의학의 시초. 현재의 모든 표적 치료가 이 흐름을 따라옴.

## 핵심 내용

### 적응증
- ER+ 또는 PR+ 유방암 (IHC로 확인)
- 수용체 발현 비율(%)이 높을수록 치료 효과 좋고 예후 양호
- 약한 양성(낮은 %)은 치료 반응이 적고 더 공격적인 경우 있음

### 항호르몬 치료 방식 한눈에 보기

| 방식 | 대표 약·치료 | 주로 언급되는 대상 |
|------|--------------|---------------------|
| 수용체 차단 (SERM) | 타목시펜, 놀바덱스 등 | 폐경 전, 0기 포함 |
| 수용체 분해 (SERD/PROTAC) | 풀베스트란트, 디레스트란트, vepdegestrant | 진행성·ESR1 변이 |
| 호르몬 생성 억제 (AI) | 아로마타아제 억제제 | 폐경 후 |
| 난소 기능 억제 (OFS) | GnRH 작용제 주사 (졸라덱스·루프린) | 폐경 전 고위험 |

### 두 가지 전략 — 한원식 강의 (2026)

```
유방암 호르몬 전략 = ① 에스트로겐 자체 제거 + ② 수용체 차단·분해
        ↓                                ↓
[난소억제·AI]                  [타목시펜·SERD·PROTAC]
```

> 💡 **핵심**: 에스트로겐 수용체는 유방뿐 아니라 **온몸**에 (뼈·자궁·뇌·심혈관 등). 그러나 **유방암 세포에는 특히 많이 발현** → 표적치료 가능.

### SERM (선택적 에스트로겐 수용체 모디파이어) — 타목시펜의 특이성

타목시펜은 기관에 따라 **다르게 작용**:

| 기관 | 타목시펜 작용 |
|------|----------------|
| **유방 (암세포)** | 차단 — 치료 효과 |
| **뼈** | **활성화** — 골 보호 (골다공증 안 일으킴) |
| **자궁 내막** | **활성화** — 두꺼워짐 → **자궁내막암 위험 ↑** |
| **혈관·간** | 일부 활성화 — 혈전 위험 |

> 💡 그래서 타목시펜은 **연 1회 자궁 초음파 필수** (자궁내막 두꺼워짐 모니터).

### 타목시펜 (Tamoxifen)

- **기전**: 에스트로겐 수용체에 경쟁적 결합, 에스트로겐 신호 차단 (SERM)
- **대상**: 주로 폐경 전 여성 (폐경 후에도 골다공증 심한 경우 사용)
- **용법**: 경구 매일 복용, 5~10년
- **부작용**: 자궁내막암 위험 소폭 증가, 혈전, 안면홍조, 질건조증
- **특이점**: 폐경 후에도 효과가 있어 아로마타제 억제제 사용 불가 시 대안

#### 환자 자가 관리 체크리스트 (경험담)

| 부작용 | 관리 포인트 |
|--------|--------------|
| 자궁내막 변화 | 산부인과 정기검진 |
| 혈전 위험 | 오래 같은 자세 피하기, 수술 전 중단 여부 확인 |
| 갱년기 증상 (열감·우울·관절통·피로) | 기록 후 상담 |
| 안과 문제 | 시야 이상이 있으면 안과 검진 |
| 지방간·간수치 | 정기 피검사 확인 |
| 탈모 | 먹는 탈모약은 상호작용 가능성 확인 |

복용 습관 팁:
- 기본 복용 기간은 5년, 고위험군은 10년까지 권고
- 매일 같은 시간에 복용해 습관화
- 비상용 약을 가방에 소량 보관해 누락 방지
- 임신 계획·수유·수술 전 중단 여부는 반드시 담당의와 상의

> 💡 부작용을 알고 대비하되, 미리 과도하게 걱정하면 증상을 더 크게 느낄 수 있다는 경험담이 반복된다. 체중 관리와 꾸준한 [[운동수면위생|걷기·스트레칭]]이 재발 관리와 부작용 완화에 도움이 된다.

### 아로마타제 억제제 (Aromatase Inhibitor, AI)

- **기전**: 말초 지방 등에서 안드로겐→에스트로겐 전환을 담당하는 아로마타제 억제
- **대상**: 폐경 후 여성 (폐경 전에는 효과 없음 — 난소에서 주된 에스트로겐 생성)
- **약제**:
  - **레트로졸 (페마라, Femara)**
  - **아나스트로졸 (아리미덱스, Arimidex)**
  - 그 외 엑세메스탄(아로마신)
- **용법**: 경구 매일, 5~10년
- **부작용**: 골다공증(골밀도 감소), 관절통, 근육통, 안면홍조

### 난소 억제 (OFS, Ovarian Function Suppression)

- **대상**: 폐경 전 여성, 특히 위험이 높다고 판단되는 경우
- **약제 (GnRH 작용제)**:
  - 졸라덱스 (Zoladex): 1개월 또는 3개월 간격 피하주사
  - 루프린 (Lupron): 1개월·3개월·6개월 간격 주사
- **원리**: 뇌하수체에서 LH/FSH 분비 억제 → 난소 에스트로겐 생산 차단
- **병용**: 타목시펜 + OFS 또는 AI + OFS (고위험군)
- **초기 저위험**: 타목시펜 단독도 가능

#### 한국 보험 — 폐경 전 AI + 난소억제주사 급여 기준 (카페 TOP50 #1, 2026-05)

폐경 전 환자가 AI를 사용하려면 **인위적 폐경** 상태 필요 → 졸라덱스·루프린·난소절제 병용:

| 조합 | 한국 급여 기준 |
|------|----------------|
| **타목시펜 + 난소억제주사** | 별도 고위험 조건 없이 급여 가능 |
| **AI + 난소억제주사** | **다음 중 1개 이상** 충족 시 급여:<br>① 40세 미만<br>② 림프절 양성<br>③ 조직학적 등급 2 또는 3 |
| **3·6개월 지속형 주사** | 임상 근거가 **4주 제형 기준** — 편의로 임의 변경 어려움 |

> 💡 카페에서 자주 묻는 질문: "**만 41세인데 등급 1·림프절 음성이면 AI+주사 급여 안 되나요?**" → 위 조건 미충족 시 타목시펜+주사 또는 자비. 주치의 + 원무팀 + 심평원 고시 동시 확인.

> ⚠️ 병원 내부 공지가 최신 심평원 개정안을 늦게 반영하는 경우 있음 → 환자가 고시 번호 들고 문의한 사례 多 ([[유방암보험청구쟁점]])

### CDK4/6 억제제

- **기전**: 세포 주기 조절 인자(CDK4, CDK6) 억제 → 암세포 증식 억제
- **약제**:
  - 팔보시클립 (버제니어 / 아베마시클립): 고위험 조기 유방암
  - 리보시클립 (키스칼리, Kisqali): 조기/전이성 유방암
  - 팔보시클립 (이브란스, Ibrance)
- **적응증 변화**: 원래 전이성 유방암 치료제였으나, **고위험 조기 ER+/HER2- 유방암에도 효과 확인** → 보조 치료로 사용 확대
- **병용**: 아로마타제 억제제 또는 풀베스트란트와 병용
- **부작용**: 호중구 감소증, 간독성(리보시클립), 설사(아베마시클립)

## 치료 원칙 요약

```
폐경 전 저위험:
  타목시펜 5~10년
  
폐경 전 고위험:
  타목시펜 + 난소 억제(OFS) 주사
  또는 AI + OFS
  고위험군 → CDK4/6 억제제 병용 고려
  
폐경 후:
  아로마타제 억제제 5~10년
  (골다공증 시 타목시펜 대체 가능)
  고위험군 → CDK4/6 억제제 병용 고려
```

## 부작용 프로파일

### 아로마타제 억제제 / 호르몬 억제제 공통
- **관절통**: 가장 흔한 호소. 손가락, 무릎, 어깨 등 전신 관절. "할머니가 된 것 같다"고 표현하는 환자 많음
- **갱년기 증상**: 안면홍조, 발한, 기분 변화, 우울증 (특히 폐경 전 OFS 병용 시 심함)
- **골다공증**: 장기 복용 시 골밀도 감소 → 정기적 골밀도 검사 권고
- **질건조증, 성기능 저하**

### 타목시펜 추가 주의사항
- 자궁내막암 위험 소폭 증가
- 혈전 위험 (정맥혈전색전증)

> ⚠️ 관절통으로 인한 치료 순응도 저하가 문제 — 증상이 심한 경우 담당 의사와 상의하여 타 약제 전환 또는 보조 진통제 사용 검토

### 부작용 관리 약제 — 한원식 강의 (2026)

| 부작용 | 1차 관리 | 약제 옵션 | 비고 |
|--------|-----------|-------------|------|
| **안면홍조** | 카페인·술 회피, 수면 위생 | **Effexor (벤라팩신)** | 우울증약이지만 안면홍조 효과 ↑ — 정신과 처방 |
| | | **클리마토플라닌** (승마 추출물) | 천연물, 효과 개인차 |
| **관절통** | **규칙적 운동** (최우선), 오메가3 | **Cymbalta (둘록세틴)** | 중추신경계 작용 — **관절통 가장 효과적** |
| | | 진통소염제 | 잘 듣지 않음 |
| **골다공증** | 비타민D·칼슘, 근력+유산소 운동 | **비스포스포네이트** (퍼사맥스·악토넬) | 주 1회 경구 |
| | | **데노수맙 (프롤리아)** | **6개월 1회 주사 — 최근 표준** |
| | 회피 | ❌ 에스트로겐 호르몬요법 | 절대 금기 (유방암 환자) |
| **질건조증** | 윤활제 | 국소 호르몬제 | **흡수 가능성 — 가능한 회피** |
| **우울·정신적 영향** | 정신건강의학과 상담 | SSRI 일부 | 단, [[호르몬양성식이]]·약물 상호작용 회피 (파록세틴·플루옥세틴 회피) |

> ⚠️ **약물 복용률 70% 미만** — 전체 유방암 환자 중 호르몬 치료를 끝까지 복용하는 비율은 70% 미만 (한원식 2026). **임의 중단 금지 — 부작용 시 담당의와 상의해 조절**.

### 타목시펜 복용 실전 — 카페 TOP50 (2026-05)

#### 복용 시간
- **식전·식후, 낮·밤과 무관** — "꾸준히 같은 시간에 먹는 습관"이 핵심
- **불면증이 있으면 아침 복용** 고려
- 복용 시간을 바꾸려면: 하루 건너뛰기 또는 시간을 점진적으로 미루기

#### 복용 누락 시
- **12시간 이내**: 알자마자 즉시 복용
- **12시간 초과**: 다음 정해진 시간에 복용 (이중 복용 금지)

#### 보관
- **습기에 약함** — 냉장고·화장실·싱크대 보관 회피
- 직사광선·고온 회피
- 약통 안에 동봉된 건조제 유지

#### 음식·영양제 (TOP50 #3, #22)

| 식품·영양제 | 가능 여부 | 비고 |
|------------|------------|------|
| 눈 영양제·마그네슘·진통제 | OK | 상황에 따라 |
| 철분제 | OK | **타목시펜과 시간 간격** 두고 복용 (흡수 영향) |
| 두유·두부·콩 (식품) | ✅ 안전 | LACE 연구 — [[식이영양관리]] |
| 홍삼·인삼 | ⚠️ 회피 | 여성호르몬 우려 + 간 부담 |
| 칡즙·석류즙 | ⚠️ 회피 | 식물성 에스트로겐 농축 |
| **고농축 콩 보충제·환** | ⚠️ 회피 | 농축형은 약물 대사 방해 가능 — [[보조요법주의]] |
| 비타민 메가도즈 | ❌ 회피 | **타목시펜 효과 감소 → 재발률 증가** |

#### 정기 모니터링 항목
- **자궁내막** 산부인과 검사 (자궁내막암 위험 약간 ↑)
- **혈전 위험** — 흉통·다리 부종 시 즉시 평가
- **안과** (드물게 망막 변화)
- **간수치** 정기 혈액검사

> 💡 환자들이 직접 만든 부작용 체크리스트: 산부인과 6개월~1년, 안과 1년, 간수치 정기 혈액검사 일정에 미리 등록 ([[치료후삶]] 추적 일정).

### 환자 Q&A — 한원식 강의 (2026)

#### 식이 — 두유·콩·우유 안전 vs 위험?
- **두유·콩·우유 모두 안전** — 유방암 위험을 높인다는 근거 없음
- → [[한국유방암영양가이드]]·[[식이영양관리]]·[[보조요법주의]]

#### 영양제 — 도움 되는 것?
- **암에 도움 입증된 영양제 없음**
- 부족한 영양소 보충은 OK, 그러나 "암에 좋다"고 알려진 보충제는 근거 없음
- → [[보조요법주의]]

#### 폐경기 호르몬 변화 — 위험 인자?
- **임신·출산 부재가 가장 큰 위험인자** (양가소설)
- 초경 이른 / 폐경 늦은 여성 → 위험 ↑ (생리 기간이 길수록)
- 인위적으로 조절 어려움
- → [[유방암위험인자]]

#### 생존율 — 10·20년 전 대비?
- **확실히 향상** (미국 데이터 기준)
- 치료 발전 + 검진 발전 — 사망률 꾸준히 감소
- 그러나 호르몬 치료는 **양날의 칼** — 생존 ↑ vs 삶의 질 ↓
- → [[한국유방암통계]]·[[치료후삶]]

#### 젊은 환자 — 임신 계획?
- **POSITIVE 연구**: 2년 호르몬치료 후 중단 → 임신 → 출산 → 재개 → 재발율 증가 없음
- 그러나 30대 중반 이상에서는 가임력 우려 → **난자 동결 우선**
- 매우 젊은 환자는 5년 다 한 뒤 임신도 옵션
- → [[가임력보존]]

#### 검사 결과 활용 — 다유전자 검사?
- 기본: ER·PR·HER2·Ki-67 (4가지)
- 추가: Oncotype DX, OncoFREE — 항암 추가 결정
- → [[온코타입DX_RS점수]]·[[유전자발현프로파일링]]·[[정밀의학도구]]

#### AI 적용 — 예후 예측?
- 작년 국제학회 발표: **현미경 슬라이드 사진만으로 예후 예측 가능** (오히려 더 잘됨)
- 유방촬영술 사진만으로 5년 위험 예측 가능 — Mirai 등
- → [[유방암AI영상]]

#### 자궁 전이 — 흔한가?
- **거의 없음** — 임상에서 한 번도 본 적 없음 (한원식)
- 이론적으로 가능하나 매우 희박 (몇만 명 중 1명)

#### 유방암 vs 갑상선암 — 연관?
- **직접 연관 없음**
- 둘 다 여성에 흔한 암 + 검진 多 → 동시 발견 빈도 ↑
- "Overdiagnosis" — 같이 발견될 뿐 인과 관계 아님

#### 가족력 — 딸 검진 시작?
- **어머니 발병 연령 - 10년**
- 어머니 45세 발병 → 딸 35세부터 시작
- 늦어도 **40세부터**
- → [[유방암검진2026]]·[[유방암유전상담]]

## 핵심 임상 데이터

### 타목시펜 25년 장기 추적 (스톡홀름 코호트)

**대상**: 림프절 음성, ER 양성 / HER2 음성, 폐경 후 환자.

**핵심 결과**:
- 타목시펜 5년 복용 시 **진단 후 25년까지** 재발 감소 효과 지속
- 효과가 더 큰 그룹: **종양 크기 큼 (T1c, T2)**, **Grade 1·2**, **PR 양성**
- PR 음성에서는 25년 장기 효과 없음
- Grade 3에서는 효과가 미미
- Ki67 수치와 무관하게 타목시펜 그룹의 장기 원격전이 위험이 낮음

**25년 생존율**:
| 종양 크기 | 타목시펜 복용 | 미복용 |
|-----------|---------------|--------|
| T1a/T1b (≤1cm) | 86% | — |
| T1c (≤2cm) | 79% | 69% |
| T2 (2~5cm) | 79% | 46% |

### 폐경 전/후 호르몬 치료 효과 (큐슈대 2020 리뷰)

**폐경 전 — 타목시펜 5년 복용**:
- 재발률 **15.8% 감소**, 사망률 **9.2% 감소**
- 복용량·항암 유무·시작 나이·림프절·종양 크기와 **무관하게 모든 ER+ 환자에서 유의미한 효과**
- 특히 **45세 미만** 또는 **55~69세** 여성에서 유방암 사망률이 각각 10.6%, 12.7% 유의 감소

**폐경 후 — 아로마타제 억제제(AI) 부작용 특징**:

| 약제 | 두드러진 부작용 |
|------|------------------|
| Anastrozole (아리미덱스) | 자궁내막암 위험 감소, **골절 위험 상승** (복용 중단 시 골절 위험 감소) |
| Letrozole (페마라) | 안면홍조, 식은땀, 관절통·근육통 심함 |

**복합 복용 전략**:
- **타목시펜 2~3년 후 AI 전환 5년 복용**으로도 타목시펜 단독 5년 또는 AI 단독 5년과 유사한 사망률·재발률 감소
- HR 양성 폐경 후: AI를 10년 가까이 지속 시 2차 전이 예방에 확실한 효과
- **ASCO 권고**: HR 양성 폐경 후 여성은 **총 10년 동안** 타목시펜 또는 AI 복용

**폐경 전 고위험군 추가요법**:
- **난소기능억제(OFS, 루프린·졸라덱스) + 타목시펜 또는 AI**
- 효과가 더 큰 군: 가족력, 어린 나이, 크고 많은 종양, 약한 ER·PR, 높은 Grade, 높은 Ki67
- OFS 병합 시 부작용: 안면홍조, 불면증, 고혈압 등이 타목시펜 단독군보다 증가

## 2026 호르몬 치료 신약

### 디레스트란트 (Direstrant) — Oral SERD
- **계열**: 경구용 선택적 에스트로겐 수용체 분해제 (SERD, Selective Estrogen Receptor Degrader)
- **의의**: **2000년대 아로마타제 억제제 이후 호르몬 치료 최초의 혁신**
- **효과**: 기존 호르몬 치료 대비 **재발 30% 추가 감소**
- **발표**: 2025년 12월 San Antonio Breast Cancer Symposium
- **한국 현황**: 보험 미적용, 국내 임상·승인 절차 진행 중

### ESR1 변이 + ctDNA + Vepdegestrant — 통합 동선

> 💡 **이 3개는 한 묶음으로 이해해야 한다** — 각각 다른 페이지에서 다루지만 실제 임상에서는 같은 환자의 같은 결정에서 만난다:
>
> | 토픽 | 위치 | 역할 |
> |------|------|------|
> | **ESR1 변이** (내성 기전) | 본 페이지 ↓ | 왜 검사하나 |
> | **ctDNA Guardant360 CDx** (검사) | [[정밀의학도구]] | 어떻게 검사하나 |
> | **Vepdegestrant** (약제) | 본 페이지 ↓ + [[CDK46억제제]] 후속 옵션 | 변이 확인 시 무엇을 쓰나 |
>
> 진료실 질문: "**제 ESR1 변이를 ctDNA 검사로 확인할 수 있나요? 변이가 있으면 vepdegestrant 적응증인가요?**"

### ESR1 변이 — 전이성 환자의 40%에서 발견 (문용화 2026)

장기 AI(아로마타제 억제제) 사용 환자에서 발견되는 가장 흔한 내성 기전:

- 암세포가 살아남기 위해 **ESR1 (ER 유전자) 자체에 돌연변이**를 일으킴
- 결과: 에스트로겐이 없어도 수용체가 알아서 활성화 → "계속 자라라" 신호 지속
- **전이성·재발 환자의 약 40%에서 ESR1 변이 발견** (Breast Cancer Res 2015, PubMed 32014063)
- 새로 진단된 전이성도 일부 포함
- 검출 방법: **ctDNA 기반 검사** (Guardant360 CDx, Signatera 등)

**임상 시사**:
- ESR1 변이가 있으면 기존 AI·풀베스트란트로는 효과 떨어짐
- **vepdegestrant (PROTAC)** 또는 **엘라세스트란트 (Oral SERD)** 같은 새 SERD 약제가 적응증
- 한국에서 ctDNA 검사 점진적 도입 진행 중

### Vepdegestrant — ESR1 변이 PROTAC ER degrader (2026 FDA 승인)

- **계열**: **PROTAC (Proteolysis Targeting Chimera)** 기반 ER degrader — 새로운 작용기전
- **적응증**: ER+/HER2-, **ESR1 변이**, 1개 이상 내분비치료 후 진행한 진행성·전이성
- **VERITAC-2 결과 (ESR1 변이군)**:
  - 중앙 PFS: vepdegestrant **5.0개월** vs fulvestrant 2.1개월
  - ORR: 19% vs 4%
- **동반진단**: **Guardant360 CDx** (ctDNA 기반) 함께 승인 — ESR1 변이 확인
- **FDA 승인**: 2026-05-01
- **주의사항**: **QTc 연장**, 태아독성, 약물 상호작용, 심전도·전해질 모니터
- **한국 현황**: 도입 준비, ESR1 ctDNA 검사 일부 병원만

> 💡 **ESR1 변이 검사 중요성**: 내분비치료 저항성에서 ctDNA 기반 ESR1 변이 확인이 실제 약제 선택과 연결되는 흐름 — [[2026임상연구업데이트]] 참조

### 자몽·약물 상호작용 종합

[[CDK46억제제|CDK4/6 억제제 (입랜스·키스칼리·버제니오)]]를 포함한 ER+ 치료 약제의 자몽 회피:

- CDK4/6 억제제 (모두): **자몽 회피** — CYP3A4 억제로 약제 농도 변동
- 특히 **버제니오 (아베마시클립)** 에서 자주 강조
- [[호르몬양성식이|호르몬 양성 식이 — 자몽 외에도 호르몬 양성 회피 식품]] 참조
- 자몽 외 약물 상호작용: 일부 SSRI ([[유방암환자정신건강|타목시펜 ↔ SSRI 약물 상호작용]]), 항생제, 항진균제

→ 약물 변경 전 종양내과·약사 협진 필수

### 리보시클립 (Kisqali) 조기 유방암 확대
- **기존**: 전이성 ER+/HER2- 유방암에서 사용
- **신결과 (2025)**: 조기 ER+/HER2- 유방암에서도 **재발 20-30% 감소** 확인
- **한국 현황**: 승인 ✅, **보험 미적용** — 3년 복용, 수천만 원 비용

## 예방 목적 타목시펜 (반대편 유방)
- 한쪽 유방암 치료 후 반대편 발생 위험: 약 7%
- 예방 목적으로 **저용량 타목시펜** 복용 가능 (담당의 확인 후)
- 반대편을 예방적 절제까지 할 수준은 아님 (BRCA 변이 없는 경우)

## 임상적 의의
