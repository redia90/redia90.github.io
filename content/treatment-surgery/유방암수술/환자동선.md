# 유방암 수술 — 환자 동선 & 수술 진행 단계

## 입원 직전 (수술 1~2일 전)
- 입원
- **초음파 재평가** — 가슴 병변 크기·변화 확인
- 의료진·마취과 상담

## 수술 전날 — 5단계 체크리스트

| # | 항목 | 핵심 |
|---|------|------|
| 1 | **동의서** | 수술 방법·합병증·보조 치료 옵션 자세히 설명 — 수술실에서 변경 가능성 포함 |
| 2 | **금식** | **자정(밤 12시)부터 최소 8시간 금식** — 물도 포함, 모르고 마시면 수술 연기 |
| 3 | **쉐이빙 (제모)** | 겨드랑이 등 수술 부위 면도 — 수술 방해 + 가려움증 방지 |
| 4 | **검사** | 외래에서 대부분 완료. 노년층은 동맥혈 검사 추가 |
| 5 | **마음가짐** | 저녁 맛있게, 푹 자기 — 나머지는 의료진이 |

## 수술 당일 오전
- 보통 **7:30~7:40 수술방 도착** (병원별 차이)
- 회복실 환자 확인·재체크 (30분 간격)
- **암 위치 표시** — 만져지지 않는 작은 종양에 영상 가이드 표시
- **감시 림프절 절제 환자**: 핵의학과에서 **방사성 동위원소** 유두·유륜 주위 주입

### 수술 당일 환자 경험 — 카페 검색 TOP50 통합 (2026-06)

50건 카페 게시글에서 반복된 수술 당일 동선·환자 경험:

| 시점 | 절차 | 환자 경험·노하우 |
|------|------|---------------------|
| **새벽 기상** | 6~7시 기상·금식 유지·머리 묶기 | "자고 일어나면 회복실" 마음가짐 (#19·#42) |
| **수술실 입실 전** | 악세사리 제거·면팬티 환복 | 생리 시작 시 간호사에게 알림 (#12) |
| **localization 와이어 삽입** | 작은 종양 위치 표시용 | 비주얼 부담 큼·통증 참을 만함 (국소마취) (#14·#47·#49) |
| **유륜·유두 주사** (감시 림프절) | 방사성 동위원소·파란 염색 | **통증 강하게 느껴질 수 있음** — 마취 가능 여부 사전 문의 (#14·#37·#49) |
| **발등/발목 링거** | 정맥 확보 | 혈관 어려우면 **숙련자 요청** 가능 (#37) |
| **수술실 이동·마취 직전** | 팔 고정·산소·약물 | 보호자와 헤어짐 큰 감정·간호사 토닥임 도움 (#49) |
| **수술 중** | 부분 30분~ / 전절제 1.5~3시간 / 재건 +α | 보호자 알림 시스템·예상 시간 사전 이해 권장 (#28) |
| **회복실** | 마취 깨움·통증 평가 | 통증 즉시 호소 — **무통주사 적극 요청** (#18) |
| **병동 복귀** | 심호흡 2시간·체위 변경 | 무기폐 예방 핵심 (#기존) |

> 💡 **카페 노하우 (#49)**: "**무서운 게 정상**" — 의료진에게 통증·불안을 적극 말하기. 간호사 토닥임이 큰 위로.

### 수술 전 1주 의료 준비 — 4축 체크 (카페 TOP50)

| 축 | 확인 항목 | 카페 사례 |
|----|-----------|-------------|
| **약물·영양제 중단** | 아스피린·올리브오일·들기름·홍삼·석류·자몽·술·일부 비타민 | #9·#26·#39 — 병원별 차이, 안내문 확인 |
| **예방접종** | 대상포진·폐렴·독감·파상풍 | #2·#8·#26·#33·#34 — 항암 예정이면 미리, 임박 시 후로 |
| **치과** | 스케일링·발치·임플란트 | #2·#8 — 골다공증 주사 전 필수 |
| **눈썹문신** | 항암 가능성 시 미리 | #2·#34 — 감염·회복 여유 필요 |

### 수술 비용 — 카페 TOP50 사례 (#7·#38)

| 수술 유형 | 비용 (산정특례 5% 적용 후) |
|----------|------------------------------|
| **부분절제 2박3일** | 57만~300만 원 (병원·병실·재료별) |
| **부분절제 4박5일** | 90만~130만 원대 |
| **전절제 + 즉시 재건** (인공진피 포함) | 200만~500만 원+ |
| **자가조직 재건** (TRAM·DIEP) | 300만~700만 원+ |

추가 변수:
- **인공진피 (ADM)**: +100만~400만 원
- **온코프리·진스웰** 등 유전자검사: 가퇴원 정산금 ↑ (실비 없으면 부담)
- **상급병실료** (1인실): 일당 30~50만 원

> 💡 **카페 #38 노하우**: 짧은 입원에서는 **세면도구·슬리퍼·수건·텀블러·퇴원 시 가디건**만 실제 사용 — 너무 많이 챙기지 않기.

## 수술 중 — 수술 종류별 시간

| 수술 종류 | 소요 시간 |
|----------|-----------|
| **부분 절제 + 감시 림프절** | 약 **1시간 전후** (가장 간단) |
| 전절제 | 1.5~2시간 |
| 전절제 + 림프절 곽청 | **2~3시간** |
| 전절제 + 즉시 재건 | 추가 시간 |
| 로봇 수술 | 추가 시간 (셋업 포함) |

### 수술 중 결정 — 동결 절편 검사 (Frozen Section)
- **절제연·림프절 즉시 평가**로 수술 중 추가 결정
- 추가 절제해도 암세포 잔존 → **전절제 전환** 가능
- 영상·진찰에서 이미 림프절 전이 확인 → **림프절 곽청 (ALND)** 추가
- → 동의서에 모든 가능성 사전 설명 받음

## 수술 후 회복
- 회복실 → 병동
- 통증 평가·관리 ([[통증관리]])
- **심호흡 2시간** — 전신마취 후 무기폐(Atelectasis) 예방 핵심
- 배액관 관리 (대부분 며칠 ~ 2주)

## 입원 기간 — 수술 종류별

| 수술 종류 | 입원 기간 |
|----------|-----------|
| **부분 절제 + 감시 림프절** | 약 **3일 전후** |
| **전절제·림프절 곽청** | 약 **5~7일** (5일 만에 퇴원 원하면 가능) |
| 전절제 + 즉시 재건 | 5~10일 |
| 자가조직 재건 (TRAM·DIEP) | 7~14일 |

## 퇴원·외래
- 봉합사 제거·드레싱 변경 외래
- 최종 병리 결과 외래 (**1~2주 후**)
- 추가 치료 (방사선·항암·호르몬) 일정 확정
- **장액종 (Seroma)** — 수술 부위 물 차는 현상 흔함, 외래에서 흡인 가능 (염증은 거의 없음)

## 로봇 수술 (Robotic Mastectomy) — 한국 도입 확대 (2024~)

| 항목 | 내용 |
|------|------|
| **주 적응증** | **전절제 + 즉시 재건** 함께 할 때 |
| **부분 절제** | 로봇 수술 불가 (원칙) |
| **흉터 크기** | 약 **5cm** (기존 개방 수술 10~15cm 대비) |
| **흉터 위치** | 옆구리·겨드랑이 — 미용적 우수 |
| **회복 시간** | 빠름 — 일반적으로 입원 기간 단축 |
| **한국 도입** | 일부 종합병원만 로봇 장비 보유 |
| **적합 환자** | 종양 크기·위치·환자 체형 평가 후 결정 |
| **비용** | 비급여 부분 多 — 사전 확인 필수 |

> 💡 로봇 수술이 더 좋다는 보장 없음 — **환자별 적합성 평가**가 핵심. 의료진과 충분히 상담 후 결정.

## 수술 후 어깨·팔 재활 — 단계별 권고

수술 직후부터 점진적으로 ROM·근력을 회복해야 만성 합병증 (오십견·림프부종) 예방:

| 시기 | 권고 운동 | 강도 |
|------|------------|------|
| **수술 직후~1주** | 통증 없는 범위 손목·손가락·팔꿈치 ROM, 깊은 호흡 | 매우 가벼움 |
| **1~2주** | 어깨 가벼운 ROM (90도까지), 자가 마사지 | 가벼움 |
| **2~6주** | 어깨 ROM 전 범위 회복 (180도 목표), 가벼운 저항 | 점진적 ↑ |
| **6주 이후** | 점진적 저항 운동 (PAL trial 근거), 수영·요가·필라테스 가능 | 정상 |

### 가정에서 따라할 수 있는 핵심 ROM 회복 운동 (서울대병원tv 2019)

- **월 크롤 (Wall Crawl, 전방)** — 어깨 굴곡 180도 목표
- **사이드 월 크롤** — 어깨 외전
- **백 클라이밍** — 어깨 내회전·내전, 등 뒤 손 깍지 회복
- **암 서클 / W 운동** — 견갑 안정성
- **체스트 오프너 / 암 리프트** — 흉근 단축 예방

> 💡 매일 짧게 자주 (하루 2~3회) — 한 번에 무리하기보다 분산. 통증·붓기 시 즉시 중단.
