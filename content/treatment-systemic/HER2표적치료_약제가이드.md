# HER2 표적치료 — 약제 가이드

> 이 페이지는 [[treatment-systemic/HER2표적치료|HER2 표적치료 허브]]에서 분리된 세부 문서입니다.

## 1세대: 트라스투주맙 (허셉틴, Herceptin)

- **기전**: HER2 세포외도메인(도메인 IV)에 결합, 신호 차단 + ADCC
- **적응증**: HER2+ 조기 및 전이성 유방암
- **용법**: 정맥주사 또는 피하주사 (3주 간격)
- **부작용**: 심장독성 (LVEF 감소) — 정기적 심장초음파 모니터링 필수
- **국내 허가**: ✅

### 페스코 (피하주사) 전환

- 16년 후 폐전이 → 퍼제타 + 허셉틴 + 도세탁셀 → **페스코 피하주사 전환** (카페 #836266 사례)
- **5분 피하주사** · 급여 적용 · 정맥주사보다 편함
- 1년 유지 단계에서 환자 일상 부담 감소

## 퍼투주맙 (퍼제타, Perjeta)

- **기전**: HER2 도메인 II 결합, HER2-HER3 이합체 형성 차단
- **적응증**: 트라스투주맙과 병용 (허셉틴+퍼제타+탁산 = 표준 1차 치료)
- **CLEOPATRA 연구**: 전이성 HER2+ 유방암 OS 56.5개월 → 역대 최장
- **국내 허가**: ✅
- **2026 급여**: 5월 말 고시 → 6월 1일 시행 (Notion 카페 TOP50 #14)
  - 적용 대상·이전 투약분 소급 여부·병원별 청구 방식은 환자가 별도 확인 권장

## T-DM1 (캐싸일라, Kadcyla)

- **기전**: ADC (항체-약물 접합체). 트라스투주맙 + 강력한 세포독성제(DM1)
- **적응증**:
  - 신보조요법 후 잔존병변(non-pCR) 조기 유방암 (KATHERINE 연구) — **조기 보조 급여 적용** (TOP50 #36)
  - 전이성: 허셉틴+탁산 실패 후 2차 치료
- **국내 허가**: ✅

### 케사일라 vs TCHP 환자 경험 비교 (카페 #198)

비완전관해(non-pCR) 환자가 케사일라로 전환할 때 자주 묻는 질문:

| 항목 | TCHP (선항암) | 케사일라 (T-DM1, 후항암) |
|------|----------------|----------------------------|
| **약제 구성** | 도세탁셀 + 카보플라틴 + 허셉틴 + 퍼투주맙 (4약 병합) | T-DM1 단독 ADC |
| **환자 경험** | 카페 다수: 가장 힘듦 (오심·구토·설사·구내염·탈모) | "TCHP보다 덜 힘들다"는 공감대 |
| **주요 부작용** | 호중구·구토·구내염·탈모 | **간수치↑·혈소판↓·피로·말초신경 저림** |
| **사이클** | 3주마다 6회 (선항암) | 3주마다 14회 (후항암 1년 가까이) |
| **모니터링** | CBC·간기능·심장초음파 | **간기능·혈소판·LVEF** 별도 모니터 |
| **탈모** | 거의 100% | 일부 — 덜 심함 |

> 💡 카페 #198 공감대: **케사일라가 TCHP보다 덜 힘들지만, 별도 부작용(간수치·혈소판·저림)** 모니터링 필요. 환자별 컨디션 차이도 큼.

### T-DM1 (케사일라) 부작용 — 임상 의사용 관리 도구

안성귀(강남세브란스), 윤창인(서울성무), 김민경(중앙대), 이장희(동탄 상신), 배승준(강남세브란스) **5인 운영 관리 홈사이트** (전문가용):

- 혈소판 감소증 — 메가카리오사이트(혈소판 만드는 세포) 흡수
- 간독성 — 간 흡수
- 용량 감량·휴약 프로토콜
- 환자 수치·컨디션 기반 부작용 관리

## T-DXd (엔허투, Enhertu) ⭐ 최신

- **기전**: 트라스투주맙 + 토포이소머라제1 억제제(DXd). 방관자 효과(bystander effect) 강점 — 표적 세포 주변 암세포까지 함께 공격
- **적응증**:
  - 전이성 HER2+ 유방암 2차 치료 (DESTINY-Breast03)
  - T-DM1 대비 PFS 대폭 개선 (mPFS: 28.8개월 vs 6.8개월)
  - **T-DM1 대비 질병 진행 위험 72% 감소** (DESTINY-Breast03)
  - **HER2-low** (IHC 1+ 또는 2+/FISH-): DESTINY-Breast04 생존기간 23.9개월 vs 화학요법 17.5개월 → [[HER2-low치료]]
  - **HER2-ultralow**: 극미량 발현에서도 반응률 30~40% 보고 (2024~2025, 아직 표준 치료 미확립) → [[HER2-low치료]]
- **부작용**: 간질성 폐질환(ILD) — 발생률 10~15%, 3~6개월 내 주로 발생. 기침·호흡곤란 시 즉시 보고
- **국내 허가**: ✅ (HER2+ 2차 이상 전이성, HER2-low 전이성)
- **건강보험 비용 변화** (HER2+ 적응증):
  - 2024년 4월부터 한국 건강보험 급여 적용
  - **연 부담액 8천만 원+ → 약 400만 원 수준**으로 대폭 감소 (산정특례 5% 적용)
  - → [[insurance-admin/유방암보험청구쟁점|유방암보험청구쟁점]] 산정특례 적용 동선

## 라파티닙 / 투카티닙 / 네라티닙 (소분자 TKI)

- 뇌전이 HER2+ 유방암에 특히 유용 (뇌혈관장벽 통과)
- 투카티닙 + 트라스투주맙 + 카페시타빈: HER2CLIMB 연구에서 뇌전이 환자 OS 개선
- **2026 국내 시판 허가 완료** (#722405) — HER2 양성 재발·전이, 특히 뇌전이 동반 환자에게 옵션 추가
- 엔허투 건강보험 적용 (#747502)

## 부작용 프로파일

### 트라스투주맙(허셉틴) / 퍼투주맙(퍼제타)

- **심장독성 (LVEF 감소)**: 가장 중요한 모니터링 항목. 환자가 자각 못해도 발생 가능
  - 모니터링: 치료 전 → 3개월 → 6개월 → 이후 6개월마다 심장초음파
- **손톱 이상**: 장기 투여 시 손톱 잘 부서짐 (흔한 호소)
- **피로감** (경미)
- 표적치료제 자체의 부작용은 심하지 않음 — 병용 세포독성 항암제 부작용이 주가 됨

### 세포독성 항암제 공통 부작용

- 구역/구토
- **탈모** (모든 유방암 항암제)
- 식욕 저하, 피로
- 백혈구·혈소판 감소 → 세균 감염 위험, 발열
- 치명적 부작용 1% 미만 — 담당의와 함께 관리하며 치료

## IHC 판독 정밀도와 세컨드 오피니언

- IHC 판독 의사 간 일치도: 약 **70~80%** — 20~30%는 다른 병리의사가 다르게 판독
- **HER2-low 경계(0 vs 1+, 2+ vs 3+)** 판단이 치료 기회를 결정하므로 재발·전이 시 세컨드 오피니언 적극 고려
- 재발·전이 시 원발암과 HER2 상태가 달라지는 경우 **20~30%** → **재생검·재검사 필수**

## 임상시험 등록 동선

HER2 양성 표준 치료 외 또는 내성 후 임상시험 가능성:

| 환자 상태 | 임상시험 등록 가능성 |
|-----------|----------------------|
| **HER2+ 전이 1차** | T-DXd+pertuzumab (DESTINY-Breast09) 임상 |
| **HER2+ 잔존병변 (선항암 후)** | DESTINY-Breast05 후속 보조 임상 |
| **HER2+ 뇌전이** | 투카티닙 + HKI-272 또는 신약 임상 |
| **T-DXd·T-DM1 저항성 후** | 차세대 HER2 ADC 임상 |
| **HER2-low/ultralow** | DESTINY-Breast06 후속 — [[HER2-low치료]] |
| **HER2 백신** | 메이요 클리닉·워싱턴대 임상 (예방·재발 방지) |

→ [[research/임상시험|등록 흐름·환자 권리]] 참조

## 미래 — chemo-free HER2 치료

| 임상 | 핵심 |
|------|------|
| **헤라클레스** (강남세브란스 본원) | 항암제 없이 표적약만 → pCR 도전 |
| **PHERGain** (스페인) | chemo-free response-adapted |
| **ADAPT** (독일) | 표적약만으로 완전관해 |

→ **약 10년 후** 표준 진입 가능성 — anthracycline-free → chemo-free 단계적 전환

## 미해결 질문 / 연구 방향

> 💡 T-DXd 이후 내성·3차 치료 전략
>    → **답변**: HER2 발현 감소·toxin 변형이 주요 내성. 3차: T-DM1·라파티닙/투카티닙·새 ADC 검토. 일부 임상 — T-DXd 후 새 HER2-DXd·HER3-DXd 순차 사용.
>
> 💡 HER2-ultralow 표준 치료 확립·보험 등재
>    → **답변**: DESTINY-Breast06 (NEJM 2024) 데이터 — FDA 일부 적응증 확대, 한국 비급여. 심평원 평가 진행 — **2027~2028** 예상.
>
> 💡 IHC 판독 표준화 — AI 보조
>    → **답변**: Paige·Roche uPath·Lunit SCOPE — HER2 0/1+ 일치도 ↑. HER2-low 시대 핵심 도구. 한국 일부 대형 병원 도입.
