# 호르몬 치료 약제 비교

## 개요
ER+ 유방암 호르몬 치료는 **4세대 약제군**으로 발전했다: (1) SERM (타목시펜), (2) AI (아로마타제 억제제), (3) SERD (선택적 ER 분해제 — 풀베스트란트·디레스트란트), (4) PROTAC (vepdegestrant). 본 페이지는 약제별 작용 기전·적응증·부작용·한국 적용을 한 표에 통합 비교한다. 약제별 상세는 [[호르몬치료]] 참조.

## 약제군 4세대 진화

| 세대 | 작용 기전 | 대표 약제 | 등장 시점 |
|------|-----------|-----------|------------|
| **1세대 (SERM)** | ER 경쟁 결합 | 타목시펜·랄록시펜·놀바덱스 | 1970s~ |
| **2세대 (AI)** | 아로마타제 억제 → 에스트로겐 합성 차단 | 레트로졸·아나스트로졸·엑세메스탄 | 1990s~ |
| **3세대 (SERD)** | ER 분해 (단독) | 풀베스트란트(주사)·디레스트란트(경구) | 2002~, 2025~ |
| **4세대 (PROTAC)** | 표적 단백질 분해 | **vepdegestrant** | 2026 FDA 승인 |

### 작용 기전 한눈에 비교

```
에스트로겐 신호 경로:
  난소·지방 (아로마타제) → 에스트로겐 → ER → 핵 → 암세포 증식

약제별 차단 지점:
  난소·지방   [OFS] 졸라덱스·루프린 — 난소에서 에스트로겐 합성 차단
              [AI] 레트로졸·아나스트로졸·엑세메스탄 — 지방·기타 조직 아로마타제 차단
  ER 결합  ← [SERM] 타목시펜 — ER에 경쟁 결합 (조직별 작용 다름)
  ER 분해  ← [SERD] 풀베스트란트·디레스트란트 — ER 자체 분해
  ER 단백질 분해  ← [PROTAC] vepdegestrant — ER을 유비퀴틴화하여 분해 유도
```

> 💡 **조직 선택성 차이**:
> - 타목시펜 (SERM): 유방 antagonist + **자궁·뼈 agonist** → 자궁내막암↑·골밀도 보호
> - AI: 전신 에스트로겐 차단 → 자궁내막암 ❌, 골밀도 ↓↓
> - SERD/PROTAC: ER 자체 제거 → 모든 조직에서 ER 신호 차단

## 약제 선택 — 환자 상태별

### 폐경 전 환자
- 1차: **타목시펜 5~10년** (저위험)
- 고위험: **타목시펜 + OFS** 또는 **AI + OFS**
- 진행성: **AI + OFS + [[CDK46억제제|CDK4/6]]**

### 폐경 후 환자
- 1차: **AI 5~10년**
- 골다공증·관절통: **타목시펜으로 대체** 또는 약제 변경
- 진행성 1차: **AI + [[CDK46억제제|CDK4/6]]**
- 진행성 2차: **풀베스트란트 + CDK4/6** 또는 알페리시브
- ESR1 변이: **vepdegestrant 또는 엘라세스트란트**

### 임신 계획
- 호르몬 치료 18~30개월 후 일시 중단 → 임신 시도 (POSITIVE 2023, 74% 성공)
- vepdegestrant·PROTAC은 **강한 태아독성** — [[가임력보존]] 참조

## AI 3종 비교 — 레트로졸 vs 아나스트로졸 vs 엑세메스탄

폐경 후 ER+ 환자에서 1차 AI 선택 시 차이가 있다:

| 항목 | **레트로졸** (Femara) | **아나스트로졸** (Arimidex) | **엑세메스탄** (Aromasin) |
|------|------------------------|------------------------------|---------------------------|
| **계열** | 비스테로이드성 | 비스테로이드성 | **스테로이드성 (비가역)** |
| **기전** | 아로마타제 가역 억제 | 아로마타제 가역 억제 | 아로마타제 **비가역** 결합 |
| **에스트로겐 억제** | >99% | ~96% | ~98% |
| **용량** | 2.5mg/일 | 1mg/일 | 25mg/일 (식후) |
| **반감기** | 약 42시간 | 약 50시간 | 약 24시간 |
| **대표 임상** | BIG 1-98 | ATAC | TEAM·IES·MA.27 |
| **타목시펜 대비 DFS** | ✅ 우위 (BIG 1-98) | ✅ 우위 (ATAC) | ✅ 우위 (IES — 2~3년 후 전환) |
| **AI 간 비교 (MA.27)** | — | 아나스트로졸 vs 엑세메스탄 → **동등** | 동등 |
| **골밀도 영향** | 비슷 | 비슷 | **약간 보호적** (스테로이드 구조) |
| **혈중 지질 영향** | 약간 ↑ | 약간 ↑ | 비교적 중립 |
| **관절통 빈도** | 비슷 | 비슷 | 비슷 |
| **약물 상호작용** | CYP3A4 약함 | CYP 영향 적음 | CYP3A4 약함 |
| **한국 보험** | ✅ | ✅ | ✅ |

**선택 시 고려**:
- 임상 효과는 **대체로 동등** — MA.27에서 아나스트로졸 vs 엑세메스탄 직접 비교 동등
- **부작용 발현 시 다른 AI로 전환** (Switching) — 환자의 약 30~50%가 한 번 이상 전환
- 비가역적 차단 (엑세메스탄)이 좋은지에 대한 논쟁 — 임상 차이 미미
- 동반 약물·고지혈증·골밀도 등 환자별 변수로 결정

### AI 전환 (Switching) 시나리오

| 상황 | 권고 |
|------|------|
| 레트로졸 → 관절통 G2 이상 | **아나스트로졸 또는 엑세메스탄으로 전환** |
| AI → 골밀도 급감 | 비스포스포네이트/데노수맙 추가 + 약제 변경 검토 |
| AI → 우울·홍조 심함 | **타목시펜으로 전환** (다른 부작용 프로파일) |
| 5년 AI → 10년 연장 결정 시 | 같은 AI 또는 SERM 전환 (개별화) |
| AI + CDK4/6 진행 | 풀베스트란트 + CDK4/6 또는 ESR1 변이 검사 → vepdegestrant |

> 💡 카페에서 자주 회자: "**같은 AI여도 부작용은 환자마다 다르다 — 한 약이 안 맞아도 포기 말고 다른 AI 시도**"

- **vepdegestrant**: 심장내과 (QTc)
- **모두**: [[약사협진_약물상호작용]] + 1차의원 연동

## 골다공증 주사 ↔ 치과치료 시점 — 턱뼈괴사 회피

AI 복용자가 골다공증 진단 후 비스포스포네이트·데노섭(프롤리아) 주사를 시작하면 **턱뼈괴사 (ONJ, Osteonecrosis of Jaw)** 위험이 누적된다 — 카페에서 가장 자주 묻는 시점 결정:

| 시점 | 권고 |
|------|------|
| **골다공증 주사 시작 전** | 치과 검진 + 필요한 발치·임플란트·치주 시술 **미리 완료** (시작 2~4주 전 권장) |
| **주사 중 정기 치과치료** | 스케일링·충치 치료 등 비외과적 처치는 가능 |
| **주사 중 발치·임플란트·치주 외과 수술** | **가능하면 회피** — 필요 시 주사 휴약 (3~6개월) + 치과·종양내과 협의 |
| **응급 발치 필요 시** | 항생제 예방 + 치과 ONJ 경험 의사 협진 |

> ⚠️ **카페 환자 경험 (게시글 #42)**: 페마라 복용 → 골다공증 진단 → 6개월마다 골다공증 주사 → **턱뼈괴사 위험으로 치과치료 미루라는 설명** 받음. 칼슘·비타민 D 보충 중 역류성식도염 동반 가능. 비스포스포네이트는 식도 자극 — 복용 후 30분 직립 자세 유지 필요.

### 페마라 (레트로졸) 부작용 — 카페 환자 실전 (게시글 #45)
- 호르몬 강양성·HER2 음성 환자 — 항암 종료 후 페마라 복용
- **3개월차부터 부작용 강화** — 타목시펜+졸라덱스와는 다른 체급의 관절·근육·골밀도 증상
- 식사와 무관하게 1일 1회 복용
- 강제 폐경 상황 — **운동·근력 관리** 필수, 칼슘·비타민 D 병행

### 난소억제 + AI 조합 — 식욕부진·골다공증·관절염 (게시글 #22)
- 1년간 여러 시도 후 일상 가능 수준으로 회복
- DEXA에서 골밀도 지속 저하 → 골다공증 진단
- **체중이 너무 적은 것도 골다공증 위험** — 단백질·열량 유지 필요
- 구운달걀 대량 준비로 수시 섭취 — 체중 유지 시도

### 타목시펜 우울감 — 운동 즉시 효과 (게시글 #24)
- 갑작스러운 우울감 — 의지 문제 아닌 약물·호르몬 변화 연관 가능성
- **30분 느린 조깅 + 20분 빠른 걷기 후 기분 안정** 경험 다수
- 가벼운 운동이 급성 기분 저하 끊는 도구 — 지속 시 정신건강의학과 상담

## 약제 변경·중단 — 한국 환자 실전 시나리오

### 부작용으로 변경한 사례 (카페 경험담 패턴)

| 시나리오 | 변경 동선 | 결과 |
|----------|------------|------|
| 레트로졸 → 관절통 못 견딤 | **엑세메스탄**으로 전환 (3개월 후) | 일부 호전 |
| AI → 우울 심해짐 | **타목시펜**으로 전환 (폐경 후라도) | 우울 감소, 자궁검진 추가 |
| 타목시펜 → 자궁내막 비후 | **AI로 전환** (폐경 후) | 자궁 위험 ↓ |
| 5년 완료 → 연장 부담 | **BCI 검사** + 의료진 상의 | 위험 분층 후 결정 |
| AI + CDK4/6 진행 | **ESR1 ctDNA + 풀베스트란트 또는 vepdegestrant** | 약제 전환 |
| 폐경 전 → 폐경 의심 (FSH·E2 확인) | OFS 중단 + AI 단독 검토 | 의료진 평가 후 |

### 임의 중단의 위험

> ⚠️ 호르몬 치료 임의 중단은 휴면 dormant 암세포가 다시 깨어날 위험을 높인다. 부작용이 견디기 어렵다면 약제 변경·용량 조정·시간 변경을 의료진과 상의.

[[휴면암세포_재발메커니즘]]: 타목시펜·AI 임의 중단이 휴면 ER+ 세포를 활성화할 수 있는 트리거로 보고됨.

**약제 복용률 70% 미만** (한원식 2026) — 부작용으로 환자 30% 이상이 임의 중단하는 현실. 의료진과의 적극 소통이 핵심.
