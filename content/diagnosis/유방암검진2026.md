# 유방암 검진 — 한국 국가검진·NCCN·고위험 가이드 2026

## 개요
유방암 검진은 **조기 발견을 통한 생존율 향상**의 핵심 인프라다. 한국은 **40세 이상 여성 2년마다 무료 유방촬영술**을 국가검진으로 제공하며, 고위험군(BRCA·가족력·치밀유방)은 추가 검사가 필요하다. 본 페이지는 일반 검진·고위험 검진·자가검진·NCCN 가이드라인을 환자 관점에서 통합 정리한다. 진단 단계별 검사는 [[유방암진단체계]], 통계는 [[한국유방암통계]] 참조.

## 핵심 내용

### 한국 국가검진 — 2026 기준

| 항목 | 내용 |
|------|------|
| **대상** | 40세 이상 여성 |
| **주기** | **2년마다** |
| **검사** | 유방촬영술 (Mammography) |
| **비용** | **무료** (국가검진 일반·암검진) |
| **건강검진 결과지** | 양호 / 경계 (BI-RADS 0·3) / 의심 (BI-RADS 4·5) |
| **결과 통보** | 2~4주 내 우편·문자 |

> 💡 검진 결과 의심 → 즉시 유방외과 전문의 진료. 양성 의심도 6개월 추적 검사 권장.

### 국가검진 외 — 추가 권장 검사

| 검사 | 시기 | 비용 (자비) |
|------|------|-------------|
| **유방초음파** | 치밀유방·30대 권장 | 5~10만원 |
| **유방 MRI** | 고위험군·BRCA 변이 | 30~50만원 |
| **DBT (디지털 토모신세시스)** | 치밀유방 정확도 ↑ | 10~15만원 |
| **자가검진** | 매월 (월경 후 3~5일) | 무료 |

### 연령대별 권장 검진

| 연령 | 권장 검진 |
|------|-----------|
| **20대** | 자가검진 매월 + 임상의 진찰 (의심 증상 시) |
| **30대** | 자가검진 + 1~2년마다 유방초음파 (특히 가족력) |
| **40대** | **국가검진 (유방촬영술 2년마다)** + 치밀유방 시 초음파 추가 |
| **50대** | 국가검진 유방촬영술 2년마다 |
| **60대** | 국가검진 유방촬영술 2년마다 |
| **70대 이상** | 국가검진 지속 + 본인 건강 상태에 따라 결정 |

### 고위험군 검진 — NCCN v1.2026

**고위험 정의**:
- BRCA1·BRCA2 등 유전성 변이 보인자
- 가족력 (1차 친족 유방암 2명 이상)
- **5년 침습성 유방암 위험 ≥1.7%** (AI 모델·Tyrer-Cuzick)
- 흉부 방사선 노출 (10~30세, Hodgkin림프종 치료 등)
- 치밀유방 (Cat. C·D)

**고위험 검진 표준**:
| 검사 | 시작 연령 | 주기 |
|------|-----------|------|
| **유방촬영술** | 25~30세 (BRCA) / 가족력 환자 -10년 | 매년 |
| **유방 MRI** | BRCA: 25세부터 / 일반 고위험: 30세부터 | 매년 (촬영술과 6개월 간격) |
| **유방초음파** | 보조 | 매년 |
| **임상 진찰** | 25~30세 | 6~12개월마다 |

> ⚠️ 고위험 검진은 **NCCN v1.2026 권고** 기준. 한국 일부 보험 적용 (BRCA 확인 후).

### 치밀유방 — 한국 특이점

- 한국 여성 약 **70%** 치밀유방 (서구권 30~40%)
- 유방촬영술만으로 검출률 낮음 → **초음파 추가 필수**
- 미국·유럽 일부 주에서 "치밀유방 통지법" 시행 — 한국도 일부 검진기관 통지

**치밀유방 카테고리 (BI-RADS)**:
| 카테고리 | 설명 | 검진 권고 |
|----------|------|-----------|
| **A** | 거의 모두 지방 | 유방촬영술만 |
| **B** | 일부 분포된 섬유선 조직 | 유방촬영술 |
| **C** | 균일하게 치밀 (heterogeneously dense) | 초음파 추가 권장 |
| **D** | 극도로 치밀 (extremely dense) | 초음파 + MRI 검토 |

### 자가검진 — 월별 루틴

**시기**: 월경 후 3~5일 (호르몬 영향 최소)

**3단계 자가검진**:
1. **시진** (거울 앞)
   - 양손 옆구리·머리 위·골반에 손 댄 자세
   - 비대칭·함몰·붉음·진물 확인
2. **촉진** (서서)
   - 한 손 머리 뒤로, 다른 손 3·4·5지 모아 원형 압박
   - 겨드랑이 → 가슴 외측 → 유두 → 가슴 내측 순서
3. **촉진** (누워서)
   - 어깨 아래 베개·수건 받침
   - 같은 방식 더 깊이 압박

**의심 신호**:
- 새로 만져지는 멍울
- 유두 분비물 (혈성·일측성)
- 피부 함몰·오렌지 껍질
- 한쪽만 크기·모양 변화
- 유방 통증 + 멍울 (드물지만 가능)

> 💡 의심 신호 발견 시 **2주 이내** 유방외과 진료. 월경 주기에 따라 변동될 수 있으므로 다음 월경 후 재확인.

### 검진 후 BI-RADS 카테고리

| 카테고리 | 의미 | 다음 단계 |
|----------|------|-----------|
| **0** | 추가 평가 필요 | 초음파·MRI |
| **1** | 정상 | 정기 검진 |
| **2** | 양성 | 정기 검진 |
| **3** | 양성 가능성 ↑ (>98%) | 6개월 추적 |
| **4** | 의심 (2~95%) | 조직검사 |
| **4A** | 낮은 의심 (2~10%) | 조직검사 |
| **4B** | 중간 의심 (10~50%) | 조직검사 |
| **4C** | 높은 의심 (50~95%) | 조직검사 |
| **5** | 매우 의심 (>95%) | 조직검사 |
| **6** | 조직검사로 확진 | 치료 시작 |

### 한국 vs 글로벌 가이드 비교

| 항목 | 한국 (KBCS·국가검진) | NCCN | USPSTF (2024) | ACS |
|------|------------------------|------|------------------|-----|
| **시작 연령** | 40세 | 40세 | **40세** (2024 개정 — 50→40) | 45세 (선택) |
| **종료 연령** | 정해진 상한 없음 | 건강 상태 | 74세 | 건강 상태 |
| **주기** | 2년 | 매년 | 2년 | 45~54 매년 → 55+ 2년 |
| **자가검진** | 권장 | 선택 (필수 아님) | 권고 아님 | 권고 아님 |
| **초음파** | 치밀유방 권장 | 보조 | 표준 아님 | 표준 아님 |
| **MRI** | 고위험 | 고위험 | 고위험 | 고위험 |

> 💡 **USPSTF 2024 권고 변경**: 시작 연령 50→40세 (이전 미국 표준이었던 50세 시작을 한국과 동일하게 40세로 낮춤). 한국은 이미 40세 표준이므로 큰 변화 없음.

## 임상적 의의

- 한국 국가검진(유방촬영술 2년)으로 **0~1기 진단 비율 51%** 달성 — 세계 수준
- 그러나 한국 환자 **치밀유방 70%** → 유방촬영술만으로는 한계
- 30~40대 검진 미수검자 비율 높음 → 자가검진·임상 진찰 보완
- BRCA·가족력 환자는 별도 검진 트랙 필요 — 본인 위험도 알기가 출발점
- 디지털 토모신세시스(DBT)·AI 영상 분석 도입 진행 중 — 정확도 향상 기대
