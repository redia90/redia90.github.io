# 면역조직화학검사 (IHC) — ER·PR·HER2·Ki67 결과 해석

## 개요
면역조직화학검사(Immunohistochemistry, IHC)는 [[조직검사결과해석|조직검사]]로 얻은 종양 조직에 항체를 입혀 특정 단백질의 발현 정도를 색으로 시각화하는 검사다. 유방암에서는 **ER, PR, HER2, Ki67** 네 가지가 핵심이며, 이 결과가 [[유방암분자서브타입|서브타입]] 결정과 [[호르몬치료|호르몬치료]]·[[HER2표적치료|HER2 표적치료]]·[[항암화학요법|항암 추가 여부]] 결정의 1차 근거가 된다. 같은 종양도 부위·실험실·판독자에 따라 결과가 달라질 수 있어, **재발·전이 시 재검사**가 중요한 영역이다.

## 검사 방법

### IHC 원리
1. 종양 조직 절편을 슬라이드에 부착
2. 표적 단백질(ER·PR·HER2·Ki67)에 결합하는 **1차 항체** 적용
3. 색소 결합 **2차 항체**로 시각화
4. 병리과 전문의가 현미경으로 **염색 강도·세포 비율** 판독

### 검체 종류
- **수술 검체**: 가장 정확. 종양 전체에서 다양한 부위 평가 가능
- **총조직검사(CNB)**: 진단 시 표준. 일부 종양 이질성 놓칠 수 있음 ([[조직검사결과해석]])
- **전이 병소 조직검사**: 재발·전이 시 원발 대비 변화 확인 (서브타입 전환 약 20~30%)

## 핵심 내용 — 항목별 해석

### ER (Estrogen Receptor) / PR (Progesterone Receptor)

| 결과 | 의미 |
|------|------|
| **ER(+) ≥ 1%** | 호르몬 양성 — [[호르몬치료]] 적응증 |
| ER(+) 약양성 (1~10%) | 치료 반응 제한적, 더 공격적 가능성 |
| ER(+) 강양성 (≥70%) | 호르몬 치료 반응 우수, 예후 양호 |
| **ER(-) < 1%** | 호르몬 음성 |
| PR(+) | 호르몬 치료 효과 보조 지표, 25년 추적 효과는 PR 양성에서만 (스톡홀름 연구) |

**보고 형식**: 발현 비율(%) + 염색 강도

> 💡 ER 또는 PR 중 하나라도 양성이면 **호르몬 수용체 양성**으로 분류된다.

### HER2 (Human Epidermal Growth Factor Receptor 2)

**IHC 점수 체계 (0 / 1+ / 2+ / 3+)**:

| 점수 | 의미 | 후속 검사 |
|------|------|-----------|
| **0** | HER2 음성 | 없음 — 단, 최근 HER2-ultralow 개념 등장 |
| **1+** | HER2 음성 | 없음 — HER2-low로 분류, [[HER2-low치료\|엔허투]] 적응증 |
| **2+** | 애매한 중간값 | **[[FISH검사]] 필수** — 유전자 증폭 여부 확인 |
| **3+** | HER2 양성 | [[HER2표적치료\|허셉틴·퍼투주맙·엔허투]] 적응증 |

> ⚠️ **IHC 2+ 단독으로는 양성/음성 판정 불가**. 반드시 [[FISH검사]] 또는 다른 ISH로 확인.

#### HER2-low 등장 (2022~ DESTINY-Breast04 이후)

- 과거 "HER2 음성"이었던 **IHC 1+ 또는 2+/FISH-** 환자가 [[HER2-low치료|HER2-low]]로 재분류
- 전체 유방암의 **약 60%** 해당 추정
- 엔허투(T-DXd) 적응증 확대 — 전이성에서 화학요법 대비 PFS 개선

#### HER2-ultralow (2024~)
- IHC 0이지만 극미량 발현 (어떤 염색이라도 보이는 경우)
- 일부 임상에서 반응률 30~40% 보고
- 표준 치료 미확립 단계

### Ki67 (증식 지수)

| 결과 | 해석 |
|------|------|
| **<14%** (전통적) | 루미날 A — 호르몬치료 중심 |
| **20% 이상** | 루미날 B — 항암 추가 고려 |
| **30% 이상** | 분열·성장 활성 높음 |

**한계**:
- 같은 종양 안에서도 부위별 염색 결과 다름
- 실험자 숙련도에 따른 오차
- **Ki67 단독으로 항암 여부 결정 금지** — [[온코타입DX_RS점수|RS 점수]] 등 종합 평가 필요

> 💡 Ki67 50~60%여도 RS 13점이면 항암 패스 가능한 사례 보고됨 (카페 전문지식 #460229).

### E-cadherin (보조)
- E-cadherin(-) → **침윤성 소엽암(ILC)** 의심
- 침윤성 관암(IDC)과 형태·치료 반응 차이

## 판독 정밀도와 한계

### 판독자 간 일치도
- 병리의사 간 일치도 약 **70~80%**
- 20~30%는 다른 병리의사가 다르게 판독
- 특히 **HER2-low 경계 (0 vs 1+, 2+ vs 3+)** 판독 차이가 치료 기회를 결정

### 검체 한계
- 종양 이질성 — 같은 종양 안에서도 부위별 다름
- CNB(총조직검사)는 종양 일부만 채취

### 재발·전이 시 재검사
- 원발 대비 서브타입 **20~30% 전환** 가능
- 전이 병소 조직검사로 **현재 HER2·ER·PR 상태** 확인 권장
- [[2026임상연구업데이트|JNCI 2026]]: T-DXd 환자 524명에서 순차 생검 IHC 불일치 약 20%, 불일치군 치료 결과 더 나쁨

> 💡 재발·전이 시 **세컨드 오피니언**으로 슬라이드 재판독을 받는 것이 카페에서 자주 권장된다.

## 임상적 의의

- IHC는 비싸지 않고 빠르며 거의 모든 병원에서 가능 — 진단 1차 도구로 표준화됨
- ER·PR·HER2 4-항목 조합으로 **루미날 A/B, HER2+, TNBC, HER2-low** 5개 서브타입 결정
- HER2-low 개념 등장으로 ADC([[HER2-low치료|엔허투]]) 적응증이 60%까지 확대 — IHC 1+/2+ 환자에게도 새 옵션
- 재발·전이 시 재검사·재판독이 치료 선택을 바꿀 수 있어 환자가 적극 요청 가능

## 한국 임상 가이드라인 / 보험 적용 여부

- 모든 유방암 환자에서 ER·PR·HER2 IHC는 **기본 검사**, 산정특례 적용
- Ki67 IHC도 일반 시행, 보험 적용
- 재검사·재판독은 의료진 판단에 따라 가능
- 외부 슬라이드 판독 의뢰는 일부 비급여 가능

## 주의사항
> ⚠️ IHC 결과는 같은 종양이라도 부위·실험실·판독자에 따라 달라질 수 있다. 재발·전이 시 또는 결과가 임상 양상과 맞지 않으면 재판독·재검사를 의료진과 상의한다.
> ⚠️ Ki67 단독으로 항암 여부를 결정하지 않는다 — Grade·종양 크기·림프절·[[온코타입DX_RS점수|RS 점수]] 종합 평가 필요.
